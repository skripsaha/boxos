# painter::core::easing

## Назначение

Заголовок: [`painter/core/easing.h`](../../../../src/userspace/painter/include/painter/core/easing.h).
Реализация: [`src/core/easing.cpp`](../../../../src/userspace/painter/src/core/easing.cpp).

Как изменение идёт во времени: продвижение (0 в начале, 1 в конце) на
каждой доле времени — линейно, медленно вначале, с замедлением к концу,
оба, скачками, пружиной, по своей кривой. По этим кривым дисплей играет
анимации `painter::gui` (`ITEM_CURVE_*`); программа может спросить их же,
когда двигает что-то сама (например, на своём холсте).

## Spring

### `Spring`

**Краткое описание:** Описывает пружину: затухание и частоту.

**Параметры:**
- `Damping` (`float`): 1 — успокаивается, не проскакивая покой; меньше — с отскоком.
- `Frequency` (`float`): частота колебаний, радиан в секунду.

**Возвращает:** Неприменимо: агрегат.

**Побочные эффекты:** Нет.

**Как работает:** Груз на пружине: из текущего места, с текущей скоростью, к покою. Изменение, прерванное на пути, передаёт свою скорость пружине, которая продолжает от этого места.

**Пример:** См. `Spring::At`.

### `Spring::For`

**Краткое описание:** Возвращает пружину, которая успокаивается за заданное время с заданным отскоком.

**Параметры:**
- `Settle` (`float`): время, за которое пружина подходит к покою на тысячную долю пути, секунды.
- `Bounce` (`float`): насколько проскочить покой, доля пути 0–0,9; 0 — без отскока.

**Возвращает:** (`Spring`).

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "painter/core/easing.h"

const painter::core::Spring Bouncy = painter::core::Spring::For(0.5f, 0.3f);
```

### `Spring::At`

**Краткое описание:** Возвращает положение и скорость пружины через заданное время.

**Параметры:**
- `Offset` (`float`): начальное отклонение от покоя.
- `Speed` (`float`): начальная скорость в секунду.
- `T` (`float`): время, секунды.

**Возвращает:** (`Spring::State`) `{Offset, Speed}` в момент `T`.

**Побочные эффекты:** Нет.

**Типичное применение:** Своя физика: тянуть объект к цели пружиной, сохраняя скорость при смене цели.

**Пример:**
```cpp
#include "painter/core/easing.h"

// Где элемент через Time секунд, если он был в From, летел со скоростью Speed и тянется к To.
float Toward(float From, float To, float Speed, float Time)
{
    const painter::core::Spring Pull = painter::core::Spring::For(0.4f, 0.15f);
    return To + Pull.At(From - To, Speed, Time).Offset;
}
```

## Easing

### `Easing`

**Краткое описание:** Описывает кривую продвижения анимации.

**Параметры:**
- `What` (`Easing::Kind`): `Linear`, `In`, `Out`, `InOut`, `Steps`, `Spring`, `Own`.
- `Steps` (`int`): для `Steps` — число скачков.
- `Bounce` (`float`): для `Spring` — отскок.
- `X1`, `Y1`, `X2`, `Y2` (`float`): для `Own` — внутренние точки кубической Безье; X в 0–1.

**Возвращает:** Неприменимо: агрегат.

**Побочные эффекты:** Нет.

**Как работает:** `In` — Безье (0,4; 0; 1; 1), `Out` — (0; 0; 0,2; 1), `InOut` — (0,4; 0; 0,6; 1). `Steps` — `floor(доля × N) / N`, скачок в конце своей доли. `Spring` — пружина с заданным отскоком, успокаивающаяся за всё время анимации.

**Пример:** См. `Easing::At`.

### `Easing::At`

**Краткое описание:** Возвращает продвижение на заданной доле времени.

**Параметры:**
- `Share` (`float`): доля времени.

**Возвращает:** (`float`) 0 до начала, 1 от конца; между ними — значение кривой, которое выходит за 0–1 только у пружины с отскоком и у своей кривой с Y за пределами 0–1.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "painter/core/easing.h"

float Slide(float From, float To, float Share)
{
    const painter::core::Easing Out{painter::core::Easing::Kind::Out};
    return From + (To - From) * Out.At(Share);
}
```
