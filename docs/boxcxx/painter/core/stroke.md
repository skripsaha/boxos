# painter::core::stroke

## Назначение

Заголовок: [`painter/core/stroke.h`](../../../../src/userspace/painter/include/painter/core/stroke.h).
Построение обводки — `boxos_stroke.h`, рисование — `Canvas::Stroke` ([canvas](canvas.md)).

Описание линии, проведённой вдоль контура.

## Перечисления

### `LineCap`

**Краткое описание:** Называет вид концов открытой линии.

**Параметры:**
- `Butt`: линия кончается там же, где контур.
- `Round`: полукруг за концом.
- `Square`: квадрат на половину толщины за концом.

**Возвращает:** Неприменимо: перечисление.

**Побочные эффекты:** Нет.

**Пример:** См. `Stroke`.

### `LineJoin`

**Краткое описание:** Называет вид углов линии.

**Параметры:**
- `Miter`: стороны продолжаются до пересечения (обрезаются в скос за пределом `MiterLimit`).
- `Round`: скругление.
- `Bevel`: срез.

**Возвращает:** Неприменимо: перечисление.

**Побочные эффекты:** Нет.

**Пример:** См. `Stroke`.

### `StrokeAlign`

**Краткое описание:** Называет положение линии относительно края замкнутой фигуры.

**Параметры:**
- `Center`: поперёк края.
- `Inside`: целиком внутри.
- `Outside`: целиком снаружи.

**Возвращает:** Неприменимо: перечисление.

**Побочные эффекты:** Нет.

**Как работает:** Для `Inside` и `Outside` линия строится вдвое толще, и половина по другую сторону края отрезается заливкой самой фигуры.

**Пример:** См. `Stroke`.

## Stroke

### `Stroke`

**Краткое описание:** Описывает линию вдоль контура: толщину, концы, углы, пунктир и положение.

**Параметры:**
- `Width` (`float`): толщина в единицах контура, по умолчанию 1.
- `Cap` (`LineCap`): по умолчанию `Butt`.
- `Join` (`LineJoin`): по умолчанию `Miter`.
- `MiterLimit` (`float`): наибольшая длина острого угла в толщинах, по умолчанию 4.
- `Dashes` (`std::vector<float>`): штрих, пробел, штрих…; нечётное число повторяется дважды; пусто — сплошная.
- `DashOffset` (`float`): с какого места узора начинать в каждом контуре.
- `Align` (`StrokeAlign`): по умолчанию `Center`.

**Возвращает:** Неприменимо: агрегат.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "painter/core/canvas.h"

bool Outline(painter::core::Canvas &Out, const painter::core::Path &Shape)
{
    painter::core::Stroke Line;
    Line.Width  = 3;
    Line.Cap    = painter::core::LineCap::Round;
    Line.Join   = painter::core::LineJoin::Round;
    Line.Dashes = {8, 6};
    return Out.Stroke(Shape, Line, painter::core::Colors::Amber);
}
```
