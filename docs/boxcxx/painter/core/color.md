# painter::core::color

## Назначение

Заголовок: [`painter/core/color.h`](../../../../src/userspace/painter/include/painter/core/color.h).
Реализация: [`src/core/color.cpp`](../../../../src/userspace/painter/src/core/color.cpp).

`painter::core::Color` — цвет, которым рисуют все части Painter: ячейки
`painter::tui`, элементы `painter::gui`, холст `Canvas`. Цвет — это RGB
(#RRGGBB) с непрозрачностью 0–255, либо одно из двух особых значений:
собственный цвет экрана и прозрачный.

В системе два способа смешивать цвета, и `Color` использует оба так же,
как их используют ядро, загрузчик и дисплей
([`boxos_color.h`](../../../../src/include/boxos_color.h)), поэтому цвет
Painter даёт те же пиксели, кто бы его ни рисовал:

- наложение одного цвета на другой — смешивание как свет (линейная яркость sRGB): `Over`;
- шаг от одного цвета к другому — прямо по числам: `Between`;
- плавный переход во времени, как видит глаз, — через OKLab: `Transition`.

`Color` — тип значения без ресурсов: копируется свободно, всё объявлено
`noexcept`, создание и чтение — `constexpr`.

## Представление

### `Color`

**Краткое описание:** Хранит цвет RGB с непрозрачностью, собственный цвет экрана или прозрачный цвет.

**Параметры:** Создаётся конструктором по умолчанию и статическими функциями `Rgb`, `Rgba`, `FromRaw`, `Screen`, `Through`.

**Возвращает:** Неприменимо: класс.

**Побочные эффекты:** Нет.

**Как работает:** Внутри три поля: `Value` (#RRGGBB), `Alpha` (0–255) и признак «цвет экрана». У прозрачного цвета и у цвета экрана `Value` всегда 0, поэтому сравнение `==` поэлементное и честное: два прозрачных цвета равны независимо от того, из какого RGB их получили.

**Примечания:** Конструктор по умолчанию даёт непрозрачный чёрный.

**Пример:**
```cpp
#include "painter/core/color.h"

constexpr painter::core::Color Sky   = painter::core::Color::Rgb(0x40, 0x80, 0xE0);
constexpr painter::core::Color Glass = painter::core::Color::Rgba(0xFF, 0xFF, 0xFF, 64);
static_assert(Glass.IsTranslucent() && !Sky.IsTranslucent());
```

### `Color::Rgb` / `Color::Rgba`

**Краткое описание:** Создают цвет из трёх каналов, непрозрачный или с заданной непрозрачностью.

**Параметры:**
- `Red`, `Green`, `Blue` (`std::uint8_t`): каналы sRGB.
- `Alpha` (`std::uint8_t`): только `Rgba` — непрозрачность из 255; 0 даёт прозрачный цвет.

**Возвращает:** (`Color`) цвет; `Rgb` — с непрозрачностью 255.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "painter/core/color.h"

constexpr auto Shadow = painter::core::Color::Rgba(0, 0, 0, 96);
```

### `Color::FromRaw`

**Краткое описание:** Создаёт непрозрачный цвет из числа 0xRRGGBB.

**Параметры:**
- `Raw` (`std::uint32_t`): число; старший байт отбрасывается.

**Возвращает:** (`Color`) непрозрачный цвет.

**Побочные эффекты:** Нет.

**Примечания:** Особые коды проводника (`COLOR_DEFAULT`, `COLOR_THROUGH`, полупрозрачные) не распознаются — их старший байт просто отбрасывается. Обратное преобразование `Raw()` не симметрично.

**Пример:**
```cpp
#include "painter/core/color.h"

constexpr auto Amber = painter::core::Color::FromRaw(0xFFB040);
```

### `Color::Screen` / `Color::IsScreen`

**Краткое описание:** Возвращает собственный цвет экрана и проверяет, является ли цвет им.

**Параметры:** Нет.

**Возвращает:** `Screen` — (`Color`) особое значение; `IsScreen` — (`bool`).

**Побочные эффекты:** Нет.

**Как работает:** Как фон это цвет страницы, который рисует дисплей; как чернила — цвет текста. Он следует тому, что человек выбрал для экрана, и ни один цвет другого вида ему не равен. Непрозрачность у него всегда 255.

**Примечания:** Тройки RGB у него нет: `WithOpacity` возвращает его без изменений, а `Over`, `Between` и `Transition` возвращают тот конец, к которому вес ближе.

**Типичное применение:** Фон программы, который совпадает с фоном консоли в любой теме.

**Пример:**
```cpp
#include "painter/core/color.h"

constexpr auto Page = painter::core::Color::Screen();
static_assert(Page.IsScreen() && Page != painter::core::Colors::Black);
```

### `Color::Through` / `Color::IsThrough`

**Краткое описание:** Возвращает прозрачный цвет и проверяет, является ли цвет прозрачным.

**Параметры:** Нет.

**Возвращает:** `Through` — (`Color`) непрозрачность 0; `IsThrough` — (`bool`) непрозрачность 0 и это не цвет экрана.

**Побочные эффекты:** Нет.

**Как работает:** В этом месте видно то, что лежит ниже. Нужен рисунку, который оставляет часть ячейки ненарисованной: ненарисованная половина крайней ячейки не становится ни чёрной, ни каким-либо цветом программы.

**Пример:**
```cpp
#include "painter/core/color.h"

static_assert(painter::core::Color::Rgba(10, 20, 30, 0) == painter::core::Color::Through());
```

## Непрозрачность

### `Color::WithOpacity`

**Краткое описание:** Возвращает этот цвет с заданной непрозрачностью.

**Параметры:**
- `Opacity` (`std::uint8_t`): непрозрачность из 255.

**Возвращает:** (`Color`) тот же RGB с новой непрозрачностью; цвет экрана и прозрачный — без изменений.

**Побочные эффекты:** Нет.

**Примечания:** Прозрачный цвет нельзя «проявить» — RGB у него уже потерян. Заменяет непрозрачность, а не умножает её.

**Пример:**
```cpp
#include "painter/core/color.h"

constexpr auto Faint = painter::core::Colors::White.WithOpacity(80);
```

### `Color::Opacity` / `Color::IsTranslucent`

**Краткое описание:** Возвращает непрозрачность и проверяет, полупрозрачен ли цвет.

**Параметры:** Нет.

**Возвращает:** `Opacity` — (`std::uint8_t`) 0–255, у цвета экрана 255; `IsTranslucent` — (`bool`) непрозрачность строго между 0 и 255 и это не цвет экрана.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "painter/core/color.h"

bool Solid(painter::core::Color Ink) { return Ink.Opacity() == 255; }
```

## Смешивание

### `Color::Over`

**Краткое описание:** Накладывает один цвет на другой с заданным весом, смешивая как свет.

**Параметры:**
- `Below` (`Color`): нижний цвет.
- `Above` (`Color`): верхний цвет.
- `Weight` (`std::uint8_t`): доля из 255 от собственной непрозрачности `Above`.

**Возвращает:** (`Color`) видимый результат с суммарной непрозрачностью.

**Побочные эффекты:** Нет.

**Как работает:** Porter-Duff «over» в линейном свете (`BoxColorOverPart`): каналы переводятся из sRGB в свет по таблицам, смешиваются и переводятся обратно. Эффективная доля верхнего — `Above.Opacity() × Weight / 255`. Над непрозрачным низом результат непрозрачен; над прозрачным — это `Above` с непрозрачностью, равной доле; над полупрозрачным — композиция обоих.

**Примечания:** Если любой из цветов — цвет экрана, результат — `Below` при `Weight < 128`, иначе `Above`. Смешивание как свет даёт более светлые и правильные полутона, чем среднее чисел: половина чёрного и белого — #BCBCBC, а не #808080.

**Типичное применение:** Сглаживание краёв (доля покрытия как вес), тени, подсветка.

**Пример:**
```cpp
#include "painter/core/color.h"

painter::core::Color Shade(painter::core::Color Under) { return painter::core::Color::Over(Under, painter::core::Colors::Black, 103); }
```

### `Color::Between`

**Краткое описание:** Возвращает цвет на заданной доле пути от одного цвета к другому, по прямой в числах.

**Параметры:**
- `A` (`Color`): начало.
- `B` (`Color`): конец.
- `Weight` (`std::uint8_t`): доля пути из 255; 0 — `A`, 255 — `B`.

**Возвращает:** (`Color`) промежуточный цвет; каналы и непрозрачность интерполируются линейно с округлением к ближайшему.

**Побочные эффекты:** Нет.

**Примечания:** Если любой из цветов — цвет экрана, результат — ближайший по весу конец.

**Типичное применение:** Ступени градиента, оттенки палитры, шкалы.

**Пример:**
```cpp
#include <array>

#include "painter/core/color.h"

std::array<painter::core::Color, 5> Heat()
{
    namespace core = painter::core;
    std::array<core::Color, 5> Steps{};
    for (std::size_t I = 0; I < Steps.size(); I++)
        Steps[I] = core::Color::Between(core::Colors::DarkBlue, core::Colors::Amber, static_cast<std::uint8_t>(I * 255 / 4));
    return Steps;
}
```

### `Color::Transition`

**Краткое описание:** Возвращает цвет на заданной доле перехода от одного цвета к другому так, как этот переход видит глаз.

**Параметры:**
- `From` (`Color`): начальный цвет.
- `To` (`Color`): конечный цвет.
- `Share` (`float`): доля 0–1; значения вне диапазона ограничиваются.

**Возвращает:** (`Color`) промежуточный цвет; при нулевой итоговой непрозрачности — `Through()`.

**Побочные эффекты:** Нет.

**Как работает:** Оба цвета переводятся в OKLab, каждый конец взвешивается своей непрозрачностью, и интерполируются L, a, b; непрозрачность — линейно. Поэтому середина перехода от красного к зелёному не серая и не тёмная, а цвет, появляющийся из прозрачного, — это тот же цвет, только бледнее.

**Примечания:** С цветом экрана — ближайший конец (`Share < 0,5` — `From`). Дороже `Between` (кубические корни и степени).

**Типичное применение:** Анимация цвета по времени. Дисплей так же проводит цвета в анимациях `painter::gui`.

**Пример:**
```cpp
#include "painter/core/color.h"

painter::core::Color Pulse(float Phase)
{
    return painter::core::Color::Transition(painter::core::Colors::Ocean, painter::core::Colors::Coral, Phase);
}
```

## Чтение

### `Color::Red` / `Color::Green` / `Color::Blue`

**Краткое описание:** Возвращают каналы цвета.

**Параметры:** Нет.

**Возвращает:** (`std::uint8_t`) канал sRGB; у прозрачного цвета и цвета экрана — 0.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "painter/core/color.h"

int Brightness(painter::core::Color Ink) { return (Ink.Red() * 2 + Ink.Green() * 5 + Ink.Blue()) / 8; }
```

### `Color::Raw`

**Краткое описание:** Возвращает цвет в 32-битном виде, в котором его несёт ячейка к дисплею.

**Параметры:** Нет.

**Возвращает:** (`std::uint32_t`) `COLOR_DEFAULT` (0xFE000000) для цвета экрана; `COLOR_THROUGH` (0xFD000000) для прозрачного; 0x00RRGGBB для непрозрачного; полупрозрачный — RGB с кодом непрозрачности в старшем байте (`BoxColorTranslucent`).

**Побочные эффекты:** Нет.

**Как работает:** Непрозрачность переводится в 63 ступени (`COLOR_OPACITY_STEPS`) с округлением; 0 ступеней — прозрачный, 63 — непрозрачный. Поэтому очень малые и очень большие значения непрозрачности могут стать 0 и 255.

**Примечания:** Нужен при прямой работе с языком элементов (`ItemCell`) и с функциями boxlib; обычной программе не требуется.

**Пример:**
```cpp
#include "painter/core/color.h"

static_assert(COLOR_THROUGH == 0xFD000000u);
std::uint32_t Wire(painter::core::Color Ink) { return Ink.Raw(); }
```

## OKLab

### `Oklab`, `OklabOf`, `RgbOf`

**Краткое описание:** Переводят цвет из sRGB в OKLab и обратно.

**Параметры:**
- `Oklab` (структура): `L` — светлота, `A` — ось зелёный–красный, `B` — ось синий–жёлтый (`float`).
- `OklabOf(Red, Green, Blue)`: каналы sRGB как `float` 0–1.
- `RgbOf(Of, Red, Green, Blue)`: `Of` (`Oklab`, in); `Red`, `Green`, `Blue` (`float &`, out) — каналы sRGB 0–1, ограниченные этим диапазоном.

**Возвращает:** `OklabOf` — (`Oklab`); `RgbOf` — `void`.

**Побочные эффекты:** `RgbOf` записывает выходные параметры.

**Типичное применение:** Собственные переходы и палитры с равномерной на глаз светлотой.

**Пример:**
```cpp
#include "painter/core/color.h"

painter::core::Color Lighter(painter::core::Color Ink, float By)
{
    namespace core = painter::core;
    core::Oklab Lab = core::OklabOf(Ink.Red() / 255.0f, Ink.Green() / 255.0f, Ink.Blue() / 255.0f);
    Lab.L += By;
    float R = 0, G = 0, B = 0;
    core::RgbOf(Lab, R, G, B);
    return core::Color::Rgb(static_cast<std::uint8_t>(R * 255.0f + 0.5f), static_cast<std::uint8_t>(G * 255.0f + 0.5f),
                            static_cast<std::uint8_t>(B * 255.0f + 0.5f));
}
```

## Именованные цвета

### `Colors`

**Краткое описание:** Называет стандартную палитру консоли BoxOS.

**Параметры:**
- Основные: `Black` #000000, `White` #FFFFFF, `DarkGray` #555555, `LightGray` #AAAAAA.
- Яркие: `Red` #E04040, `Green` #40C040, `Blue` #4080E0, `Yellow` #E0C040, `Cyan` #40C0C0, `Magenta` #C040C0.
- Тёмные: `DarkRed` #A00000, `DarkGreen` #008000, `DarkBlue` #0000A0, `Brown` #A06000, `DarkCyan` #008080, `DarkMagenta` #800080.
- Акценты BoxOS: `Berry` #E04F90, `Ocean` #1080C0, `Leaf` #60C030, `Amber` #FFB040, `Violet` #9060FF, `Teal` #00B0A0, `Coral` #FF8070, `Slate` #607080.

**Возвращает:** Неприменимо: `inline constexpr Color`.

**Побочные эффекты:** Нет.

**Как работает:** Значения берутся из `box/color.h` — тех же констант, что использует консоль, поэтому цвет программы совпадает с цветом печати.

**Примечания:** На текстовой странице VGA любой RGB сводится к ближайшему из 16 цветов адаптера.

**Пример:**
```cpp
#include "painter/core/color.h"

constexpr painter::core::Color Accent = painter::core::Colors::Violet;
```
