# painter::core::color — цвета и непрозрачность

## Назначение

Модуль `src/userspace/painter/include/painter/core/color.h` определяет `painter::core::Color` и палитру `painter::core::Colors`. Подключение: `#include <painter/core/color.h>`. Представление согласовано с `src/userspace/boxlib/include/box/color.h` и `src/include/boxos_color.h`; непрозрачное смешивание использует `color_mix()` из `src/userspace/boxlib/src/color.c`.

Операции модуля не изменяют экран, текущий цвет вывода или глобальное состояние, не выделяют память и не выполняют системные вызовы. Все функции объявлены `noexcept`. Создание обычных цветов, специальных значений, чтение каналов, `Raw()`, сравнение и проверки `IsScreen()`/`IsThrough()` допускают константное вычисление; операции непрозрачности и `Mix()` не объявлены `constexpr`.

## Представление цвета

### `Color`

**Краткое описание:** Представляйте RGB-цвет, цвет экрана или пропускающий фон цвет одним значением.

**Параметры:** Нет обязательных параметров; создавайте значения через конструктор по умолчанию и статические методы.

**Возвращает:** Объект `Color` с закрытым полем `Value` типа `std::uint32_t`.

**Побочные эффекты:** Инициализация создаваемого объекта.

**Как работает:** Обычный цвет хранится как `0x00RRGGBB`. Старший байт кодирует специальные значения `Screen()`, `Through()` или непрозрачность RGB; такое представление передаётся через `Raw()`. Класс не хранит отдельный альфа-канал на 256 уровней: промежуточная непрозрачность имеет 62 значения между полностью прозрачным и полностью непрозрачным состояниями.

**Примечания:** Это тип значения без собственного ресурса; копирование и присваивание копируют представление. В классе нет блокировок: синхронизацию совместной записи обеспечивает вызывающий код. Разрешение специальных цветов и смешивание с нижним слоем выполняет дисплей при выводе ячейки слоя; `Color` самостоятельно ничего не рисует. Использование специальных кодов в произвольном канале обычного консольного вывода не гарантируется.

**Типичное применение:** Передавайте цвет в операции рисования Painter; используйте `Screen()` для цветов экрана, `Through()` для пропускающей части слоя и RGB для явно заданной окраски.

**Пример:**

```cpp
#include <painter/core/color.h>
constexpr auto Ink = painter::core::Color::Rgb(64, 128, 224);
constexpr auto Page = painter::core::Color::Screen();
constexpr auto Hole = painter::core::Color::Through();
static_assert(Ink.Raw() == 0x004080E0u && Page.IsScreen() && Hole.IsThrough());
```

### `Color::Color()`

**Краткое описание:** Создайте непрозрачный чёрный цвет.

**Параметры:** Нет.

**Возвращает:** `Color` с `Raw() == 0`.

**Побочные эффекты:** Инициализация `Value` нулём.

**Примечания:** Конструктор `constexpr`, `noexcept`, `= default`. Нулевое значение означает чёрный RGB, а не `Screen()` или `Through()`.

**Пример:**

```cpp
#include <painter/core/color.h>
constexpr painter::core::Color Ink{};
static_assert(Ink == painter::core::Colors::Black);
```

### `Color::Rgb`

**Краткое описание:** Соберите непрозрачный цвет из трёх каналов.

**Параметры:**

- `Red` (`std::uint8_t`, in): красный канал, `0..255`.
- `Green` (`std::uint8_t`, in): зелёный канал, `0..255`.
- `Blue` (`std::uint8_t`, in): синий канал, `0..255`.

**Возвращает:** `Color`: значение `0x00RRGGBB`.

**Побочные эффекты:** Нет.

**Как работает:** Метод расширяет каналы до `std::uint32_t`, сдвигает красный на 16 бит, зелёный на 8 бит и объединяет их с синим. Закрытый конструктор сохраняет младшие 24 бита.

**Примечания:** Метод `static constexpr`, `noexcept`. Значения большего целого типа преобразуются в `std::uint8_t` до входа в метод; насыщения до `255` нет.

**Пример:**

```cpp
#include <painter/core/color.h>
static_assert(painter::core::Color::Rgb(0x12, 0x34, 0x56).Raw() == 0x00123456u);
```

### `Color::FromRaw`

**Краткое описание:** Создайте непрозрачный RGB из младших 24 бит числа.

**Параметры:**

- `Raw` (`std::uint32_t`, in): число, из которого извлекается `0x00RRGGBB`.

**Возвращает:** `Color`: `Raw & 0x00FFFFFFu`.

**Побочные эффекты:** Нет.

**Как работает:** Метод маскирует старший байт и передаёт результат в закрытый RGB-конструктор. Специальный код или информация о непрозрачности в старшем байте теряются.

**Примечания:** Метод `static constexpr`, `noexcept`. Это не обратное преобразование для произвольного результата `Raw()`: `FromRaw(Color::Screen().Raw())` и `FromRaw(Color::Through().Raw())` дают чёрный. Публичного метода восстановления произвольного закодированного значения без маскирования нет.

**Типичное применение:** Преобразуйте обычные RGB-константы BoxLib в `Color`.

**Пример:**

```cpp
#include <painter/core/color.h>
static_assert(painter::core::Color::FromRaw(0xAB123456u).Raw() == 0x00123456u);
static_assert(painter::core::Color::FromRaw(COLOR_DEFAULT) == painter::core::Colors::Black);
```

### `Color::Screen`

**Краткое описание:** Получите специальное значение цвета экрана для роли ячейки.

**Параметры:** Нет.

**Возвращает:** `Color`: код `COLOR_DEFAULT`, равный `0xFE000000u`.

**Побочные эффекты:** Нет.

**Как работает:** Метод сохраняет специальный код через закрытый конструктор с `WireTag`, без RGB-маскирования. При выводе дисплей выбирает собственный цвет текста для переднего плана и цвет страницы для фона.

**Примечания:** Метод `static constexpr`, `noexcept`. Значение не содержит текущую RGB-тройку экрана и не равно никакому обычному RGB, даже если тот визуально совпадает с цветом экрана. `Opacity()` возвращает `255`, а `WithOpacity()` оставляет значение неизменным.

**Типичное применение:** Используйте вместе с `IsScreen()` для сохранения выбора пользователя вместо фиксированной RGB-тройки.

**Пример:**

```cpp
#include <painter/core/color.h>
constexpr auto Ink = painter::core::Color::Screen();
static_assert(Ink.IsScreen() && Ink.Raw() == COLOR_DEFAULT);
```

### `Color::IsScreen`

**Краткое описание:** Проверьте наличие специального кода цвета экрана.

**Параметры:** Нет; читает текущий объект.

**Возвращает:** `bool`: результат `Value == COLOR_DEFAULT`.

**Побочные эффекты:** Нет.

**Примечания:** Метод `constexpr`, `const`, `noexcept`; не сравнивает RGB с текущей палитрой дисплея.

**Пример:**

```cpp
#include <painter/core/color.h>
static_assert(painter::core::Color::Screen().IsScreen());
static_assert(!painter::core::Colors::White.IsScreen());
```

### `Color::Through`

**Краткое описание:** Получите специальное значение пропускающего цвета слоя.

**Параметры:** Нет.

**Возвращает:** `Color`: код `COLOR_THROUGH`, равный `0xFD000000u`.

**Побочные эффекты:** Нет.

**Как работает:** Метод сохраняет специальный код через конструктор с `WireTag`. В отдельном цвете ячейки слоя дисплей разрешает его в фон нижележащей ячейки; если оба цвета ячейки пропускающие, нижняя ячейка показывается без изменений.

**Примечания:** Метод `static constexpr`, `noexcept`. `Opacity()` возвращает `0`, `IsTranslucent()` — `false`; `WithOpacity()` не превращает это значение обратно в RGB.

**Типичное применение:** Оставляйте незакрашенную часть краевой ячейки прозрачной для нижнего слоя.

**Пример:**

```cpp
#include <painter/core/color.h>
constexpr auto Hole = painter::core::Color::Through();
static_assert(Hole.IsThrough() && Hole.Raw() == COLOR_THROUGH);
```

### `Color::IsThrough`

**Краткое описание:** Проверьте наличие специального пропускающего кода.

**Параметры:** Нет; читает текущий объект.

**Возвращает:** `bool`: результат `Value == COLOR_THROUGH`.

**Побочные эффекты:** Нет.

**Примечания:** Метод `constexpr`, `const`, `noexcept`. Обычный чёрный цвет не является пропускающим.

**Пример:**

```cpp
#include <painter/core/color.h>
static_assert(painter::core::Color::Through().IsThrough());
static_assert(!painter::core::Color{}.IsThrough());
```

## Непрозрачность и смешивание

### `Color::WithOpacity`

**Краткое описание:** Создайте цвет с заданной непрозрачностью, округлённой до формата дисплея.

**Параметры:**

- `Opacity` (`std::uint8_t`, in): требуемая непрозрачность `0..255`.

**Возвращает:** `Color`: исходный специальный цвет либо RGB с новой непрозрачностью.

**Побочные эффекты:** Нет; исходный объект не изменяется.

**Как работает:** Для `Screen()` и `Through()` метод сразу возвращает исходное значение. Для RGB вычисляется число шагов `(Opacity * 63 + 127) / 255` и вызывается `BoxColorTranslucent()`. Нулевое число шагов превращается в `Through()`, `63` — в обычный RGB; для `1..62` старший байт равен `0x80 + Steps`.

**Примечания:** Метод `const`, `noexcept`. Новая непрозрачность заменяет прежнюю, а не умножается на неё. Из-за округления значения `0..2` дают `Through()`, `253..255` дают полностью непрозрачный RGB. После преобразования в `Through()` исходная RGB-тройка теряется, поэтому последующий `WithOpacity(255)` её не восстанавливает.

**Типичное применение:** Преобразуйте долю покрытия из [coverage.md](coverage.md) в байт непрозрачности, затем передайте полученный цвет в рисунок слоя.

**Пример:**

```cpp
#include <painter/core/color.h>
bool CheckOpacity()
{
    const auto Half = painter::core::Colors::Red.WithOpacity(128);
    return Half.IsTranslucent() && Half.Opacity() == 130 &&
           painter::core::Colors::Red.WithOpacity(0).IsThrough() &&
           painter::core::Color::Screen().WithOpacity(0).IsScreen();
}
```

### `Color::Opacity`

**Краткое описание:** Получите непрозрачность в шкале `0..255`.

**Параметры:** Нет; читает текущий объект.

**Возвращает:** `std::uint8_t`: `0` для `Through()`, `255` для обычного RGB и `Screen()`, пересчитанное значение для полупрозрачного цвета.

**Побочные эффекты:** Нет.

**Как работает:** Метод получает число шагов через `BoxColorOpacity()` и вычисляет `(Steps * 255 + 31) / 63`. Поэтому результат после `WithOpacity()` может отличаться от входного байта: формат хранит только 63 интервала непрозрачности.

**Примечания:** Метод `const`, `noexcept`. Непрозрачность `Screen()` равна `255` по правилам кодирования, но это не даёт RGB-тройку экрана.

**Пример:**

```cpp
#include <painter/core/color.h>
bool CheckEndpoints()
{
    return painter::core::Color::Through().Opacity() == 0 &&
           painter::core::Colors::Blue.Opacity() == 255 &&
           painter::core::Color::Screen().Opacity() == 255;
}
```

### `Color::IsTranslucent`

**Краткое описание:** Проверьте, закодирован ли цвет как полупрозрачный RGB.

**Параметры:** Нет; читает текущий объект.

**Возвращает:** `bool`: результат проверки старшего байта через `BoxColorIsTranslucent()`.

**Побочные эффекты:** Нет.

**Как работает:** Вспомогательная функция проверяет диапазон старшего байта `0x80..0xBF`. Методы `Color` создают такие значения только для промежуточных шагов `1..62`: крайние шаги нормализуются в `Through()` и обычный RGB.

**Примечания:** Метод `const`, `noexcept`. Это проверка представления, а не общее условие `Opacity() < 255`: для `Through()` результат `false`.

**Пример:**

```cpp
#include <painter/core/color.h>
bool CheckTranslucency()
{
    return painter::core::Colors::Blue.WithOpacity(100).IsTranslucent() &&
           !painter::core::Color::Through().IsTranslucent();
}
```

### `Color::Mix`

**Краткое описание:** Наложите цвет `B` поверх `A` с заданным весом.

**Параметры:**

- `A` (`Color`, in): нижний цвет по значению.
- `B` (`Color`, in): накладываемый цвет по значению.
- `Weight` (`std::uint8_t`, in): доля собственной непрозрачности `B`, `0..255`.

**Возвращает:** `Color`: выбранный специальный цвет, непрозрачная смесь RGB или результат композиции с непрозрачностью.

**Побочные эффекты:** Нет.

**Как работает:** Если хотя бы один аргумент — `Screen()`, метод возвращает `A` при `Weight < 128`, иначе `B`, поскольку RGB экрана здесь неизвестен. Для двух полностью непрозрачных цветов вызывается `color_mix()`: каждый канал равен `(AChannel * (255 - Weight) + BChannel * Weight) / 255`, с отбрасыванием дробной части. В остальных случаях вычисляются `Laid = (B.Opacity() * Weight + 127) / 255`, `Kept = A.Opacity() * (255 - Laid) / 255` и `Total = Laid + Kept`; при `Laid == 0` возвращается `A`. Каналы результата равны `(BChannel * Laid + AChannel * Kept + Total / 2) / Total`, после чего `WithOpacity(Total)` кодирует итоговую непрозрачность.

**Примечания:** Метод `static`, `noexcept`. Операция соответствует композиции «поверх» с целочисленным округлением и последующим квантованием непрозрачности; порядок аргументов существенен. При наличии `Screen()` пороговое правило действует даже при нулевой непрозрачности другого цвета. Без `Screen()` вес `0` сохраняет `A`; вес `255` не обязательно возвращает `B`, если `B` пропускающий или полупрозрачный. Для вызова `Mix()` требуется реализация `color_mix()` из BoxLib; остальные определения этого модуля находятся в заголовках.

**Типичное применение:** Накладывайте цвет рисунка на уже имеющийся цвет; над `Through()` результат сохраняет пропускающую составляющую.

**Пример:**

```cpp
#include <painter/core/color.h>
bool CheckMix()
{
    using painter::core::Color;
    using namespace painter::core::Colors;
    const auto Gray = Color::Mix(Black, White, 128);
    const auto Half = Color::Mix(Color::Through(), Red, 128);
    return Gray == Color::Rgb(128, 128, 128) && Half.IsTranslucent() &&
           Color::Mix(Color::Screen(), Blue, 127).IsScreen() &&
           Color::Mix(Color::Screen(), Blue, 128) == Blue;
}
```

## Чтение и сравнение

### `Color::Raw`

**Краткое описание:** Получите полное закодированное значение цвета.

**Параметры:** Нет; читает текущий объект.

**Возвращает:** `std::uint32_t`: поле `Value`, включая специальный код или непрозрачность.

**Побочные эффекты:** Нет.

**Примечания:** Метод `constexpr`, `const`, `noexcept`. Для обычного цвета результат имеет вид `0x00RRGGBB`; для остальных значений старший байт значим. `FromRaw()` этот байт отбрасывает.

**Пример:**

```cpp
#include <painter/core/color.h>
static_assert(painter::core::Color::Through().Raw() == 0xFD000000u);
```

### `Color::Red`

**Краткое описание:** Извлеките красный канал из сохранённого значения.

**Параметры:** Нет; читает текущий объект.

**Возвращает:** `std::uint8_t`: биты `16..23` поля `Value`.

**Побочные эффекты:** Нет.

**Примечания:** Метод `constexpr`, `const`, `noexcept`. Для полупрозрачного RGB возвращает канал до смешивания с фоном; для `Screen()` и `Through()` возвращает `0`, не фактический цвет дисплея.

**Пример:**

```cpp
#include <painter/core/color.h>
static_assert(painter::core::Color::Rgb(12, 34, 56).Red() == 12);
```

### `Color::Green`

**Краткое описание:** Извлеките зелёный канал из сохранённого значения.

**Параметры:** Нет; читает текущий объект.

**Возвращает:** `std::uint8_t`: биты `8..15` поля `Value`.

**Побочные эффекты:** Нет.

**Примечания:** Метод `constexpr`, `const`, `noexcept`. Непрозрачность не применяется; для `Screen()` и `Through()` результат `0`.

**Пример:**

```cpp
#include <painter/core/color.h>
static_assert(painter::core::Color::Rgb(12, 34, 56).Green() == 34);
```

### `Color::Blue`

**Краткое описание:** Извлеките синий канал из сохранённого значения.

**Параметры:** Нет; читает текущий объект.

**Возвращает:** `std::uint8_t`: биты `0..7` поля `Value`.

**Побочные эффекты:** Нет.

**Примечания:** Метод `constexpr`, `const`, `noexcept`. Непрозрачность не применяется; для `Screen()` и `Through()` результат `0`.

**Пример:**

```cpp
#include <painter/core/color.h>
static_assert(painter::core::Color::Rgb(12, 34, 56).Blue() == 56);
```

### `operator==(Color, Color)`

**Краткое описание:** Сравните полные представления двух цветов.

**Параметры:**

- Первый операнд (`Color`, in): первый цвет по значению.
- Второй операнд (`Color`, in): второй цвет по значению.

**Возвращает:** `bool`: `true`, если поля `Value` равны.

**Побочные эффекты:** Нет.

**Примечания:** Дружественная функция `constexpr`, `noexcept`, `= default`. Учитывается непрозрачность; визуальное совпадение на экране не проверяется. `Screen()` не равен обычному RGB. `!=` доступно по правилам C++23 без отдельного определения.

**Пример:**

```cpp
#include <painter/core/color.h>
static_assert(painter::core::Color::Rgb(0, 0, 0) == painter::core::Colors::Black);
static_assert(painter::core::Color::Screen() != painter::core::Colors::Black);
```

**Краткое описание:** Используйте именованные непрозрачные RGB-константы палитры BoxLib.

| `Teal` | `COLOR_TEAL` | `#00B0A0` |
| `Coral` | `COLOR_CORAL` | `#FF8070` |
| `Slate` | `COLOR_SLATE` | `#607080` |

**Примечания:** Палитра содержит 24 константы. Имена не обозначают индексы ANSI или VGA и не меняются при смене цвета страницы. Для следования настройкам экрана используйте `Color::Screen()`.

**Типичное применение:** Выбирайте базовый цвет по имени; при необходимости создавайте его полупрозрачную копию через `WithOpacity()`.

**Пример:**

```cpp
#include <painter/core/color.h>
constexpr auto Accent = painter::core::Colors::Ocean;
static_assert(Accent.Raw() == 0x001080C0u);
```

## Закрытые элементы реализации

### `Color::WireTag`

**Краткое описание:** Различайте внутри класса конструирование RGB и полного кода дисплея.

**Параметры:** Нет; пустая закрытая структура.

**Возвращает:** `WireTag` при внутренней агрегатной инициализации.

**Побочные эффекты:** Нет.

**Примечания:** Внешнему коду тип недоступен. Его наличие выбирает перегрузку конструктора, сохраняющую старший байт.

**Пример:** Внутри методов `Color` используется выражение `WireTag{}`; отдельного примера внешнего вызова нет, поскольку доступ закрыт.

### `Color::Color(std::uint32_t Raw)`

**Краткое описание:** Сохраните внутри класса RGB с очищенным старшим байтом.

**Параметры:**

- `Raw` (`std::uint32_t`, in): исходное число.

**Возвращает:** `Color` с `Value = Raw & 0x00FFFFFFu`.

**Побочные эффекты:** Инициализация `Value` создаваемого объекта.

**Примечания:** Закрытый конструктор `explicit constexpr`, `noexcept`. Вызывается из `Rgb()` и `FromRaw()`; внешнему коду доступен через эти фабрики.

**Пример:**

```cpp
#include <painter/core/color.h>
constexpr auto Ink = painter::core::Color::FromRaw(0x00123456u);
static_assert(Ink.Raw() == 0x00123456u);
```

### `Color::Color(std::uint32_t Wire, WireTag)`

**Краткое описание:** Сохраните внутри класса полный код цвета без маскирования.

**Параметры:**

- `Wire` (`std::uint32_t`, in): полное представление цвета.
- Второй аргумент (`WireTag`, in): безымянная метка выбора перегрузки.

**Возвращает:** `Color` с `Value = Wire`.

**Побочные эффекты:** Инициализация `Value` создаваемого объекта.

**Примечания:** Закрытый конструктор `constexpr`, `noexcept`. Используется в `Screen()`, `Through()` и `WithOpacity()`; внешнему коду недоступен.

**Пример:**

```cpp
#include <painter/core/color.h>
constexpr auto Ink = painter::core::Color::Screen();
static_assert(Ink.Raw() == COLOR_DEFAULT);
```
