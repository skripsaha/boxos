# painter::core::geometry — геометрические типы

## Назначение

Модуль `src/userspace/painter/include/painter/core/geometry.h` определяет точки, размеры и прямоугольники без привязки к способу вывода. Подключение: `#include <painter/core/geometry.h>`. Все определения находятся в `painter::core` и реализованы в заголовке.

Единицы координат задаёт вызывающий код: сами типы не различают ячейки и пиксели. Модуль не выделяет память, не выполняет системные вызовы и не изменяет экран. Методы объявлены `noexcept`; все операции, кроме `Size::CellCount()`, допускают вычисление в константном выражении. Объекты не содержат блокировок: совместную запись в их открытые поля синхронизирует вызывающий код.

## Точки

### `Point`

**Краткое описание:** Храните целочисленные координаты точки.

**Параметры:**

- `X` (`std::int32_t`): открытое поле горизонтальной координаты, начальное значение `0`.
- `Y` (`std::int32_t`): открытое поле вертикальной координаты, начальное значение `0`.

**Возвращает:** `Point` при агрегатной инициализации.

**Побочные эффекты:** Инициализация полей создаваемого объекта.

**Примечания:** Отрицательные координаты допустимы; проверки принадлежности поверхности нет. Арифметические операторы для точек не определены.

**Типичное применение:** Передавайте положение ячейки или начала рисунка в интерфейсы Painter, принимающие `Point`.

**Пример:**

```cpp
#include <painter/core/geometry.h>
constexpr painter::core::Point Origin{};
constexpr painter::core::Point Position{12, -3};
static_assert(Origin.X == 0 && Position.Y == -3);
```

### `operator==(Point, Point)`

**Краткое описание:** Сравните обе координаты двух точек.

**Параметры:**

- Первый операнд (`Point`, in): первая точка, передаётся по значению.
- Второй операнд (`Point`, in): вторая точка, передаётся по значению.

**Возвращает:** `bool`: `true`, если совпадают `X` и `Y`.

**Побочные эффекты:** Нет.

**Примечания:** Дружественная функция с определением `= default`, объявлена `constexpr` и `noexcept`. В C++23 выражение `!=` использует это равенство; отдельного определения `operator!=` нет.

**Пример:**

```cpp
#include <painter/core/geometry.h>
static_assert(painter::core::Point{2, 3} == painter::core::Point{2, 3});
static_assert(painter::core::Point{2, 3} != painter::core::Point{3, 2});
```

### `PointF`

**Краткое описание:** Храните дробные координаты точки.

**Параметры:**

- `X` (`float`): открытое поле горизонтальной координаты, начальное значение `0.0f`.
- `Y` (`float`): открытое поле вертикальной координаты, начальное значение `0.0f`.

**Возвращает:** `PointF` при агрегатной инициализации.

**Побочные эффекты:** Инициализация полей создаваемого объекта.

**Примечания:** Нормализация, округление, проверка конечности и оператор равенства не определены. Тип не задаёт точность сравнения координат.

**Типичное применение:** Используйте дробные положения при построении фигур через `painter::tui::FineCanvas`.

**Пример:**

```cpp
#include <painter/core/geometry.h>
constexpr painter::core::PointF Position{1.5f, 2.25f};
static_assert(Position.X == 1.5f);
```

## Размеры

### `Size`

**Краткое описание:** Храните ширину и высоту области.

**Параметры:**

- `Width` (`std::int32_t`): открытое поле ширины, начальное значение `0`.
- `Height` (`std::int32_t`): открытое поле высоты, начальное значение `0`.

**Возвращает:** `Size` при агрегатной инициализации.

**Побочные эффекты:** Инициализация полей создаваемого объекта.

**Примечания:** Конструирование не отвергает отрицательные размеры. Используйте `Empty()` для проверки геометрии и `CellCount()` для получения количества элементов.

**Пример:**

```cpp
#include <painter/core/geometry.h>
constexpr painter::core::Size Extent{80, 25};
static_assert(Extent.Width == 80 && Extent.Height == 25);
```

### `Size::Empty`

**Краткое описание:** Проверьте, является ли хотя бы один размер неположительным.

**Параметры:** Нет; читает `Width` и `Height` текущего объекта.

**Возвращает:** `bool`: результат `Width <= 0 || Height <= 0`.

**Побочные эффекты:** Нет.

**Примечания:** Метод `constexpr`, `const`, `noexcept`. Отрицательный размер считается пустым, а не преобразуется в положительный.

**Пример:**

```cpp
#include <painter/core/geometry.h>
static_assert(painter::core::Size{0, 10}.Empty());
static_assert(painter::core::Size{-1, 10}.Empty());
static_assert(!painter::core::Size{1, 1}.Empty());
```

### `Size::CellCount`

**Краткое описание:** Получите число элементов непустой области с проверкой представимости в `std::size_t`.

**Параметры:** Нет; читает `Width` и `Height` текущего объекта.

**Возвращает:** `std::optional<std::size_t>`: произведение размеров либо `std::nullopt`, если область пуста или произведение превышает максимум `std::size_t`.

**Побочные эффекты:** Нет.

**Как работает:** Сначала метод вызывает `Empty()`, поэтому отрицательные размеры не превращаются в большие беззнаковые числа. Затем оба размера расширяются до `std::uint64_t` и перемножаются; произведение двух положительных `std::int32_t` помещается в этот тип. После сравнения с `std::numeric_limits<std::size_t>::max()` результат приводится к `std::size_t`.

**Примечания:** Метод `const`, `noexcept`, но не `constexpr`. На x86-64 произведение положительных размеров этого типа помещается в `std::size_t`. Метод не проверяет объём доступной памяти и не проверяет переполнение при последующем умножении количества на размер элемента.

**Типичное применение:** Проверяйте наличие значения перед использованием количества при создании буфера; допустимый размер буфера в байтах проверяйте отдельно.

**Пример:**

```cpp
#include <painter/core/geometry.h>
bool CheckCellCount()
{
    const auto Count = painter::core::Size{80, 25}.CellCount();
    return Count && *Count == 2000 &&
           !painter::core::Size{0, 25}.CellCount();
}
```

### `operator==(Size, Size)`

**Краткое описание:** Сравните ширину и высоту двух размеров.

**Параметры:**

- Первый операнд (`Size`, in): первый размер по значению.
- Второй операнд (`Size`, in): второй размер по значению.

**Возвращает:** `bool`: `true`, если совпадают оба поля.

**Побочные эффекты:** Нет.

**Примечания:** Дружественная функция `constexpr`, `noexcept`, `= default`. Пустые размеры с разными полями не равны; `!=` доступно через правила C++23.

**Пример:**

```cpp
#include <painter/core/geometry.h>
static_assert(painter::core::Size{80, 25} == painter::core::Size{80, 25});
static_assert(painter::core::Size{0, 1} != painter::core::Size{0, 2});
```

## Прямоугольники

### `Rect`

**Краткое описание:** Храните начало и размеры прямоугольной области.

**Параметры:**

- `X`, `Y` (`std::int32_t`): открытые поля положения начала, начальные значения `0`.
- `Width`, `Height` (`std::int32_t`): открытые поля размеров, начальные значения `0`.

**Возвращает:** `Rect` при агрегатной инициализации.

**Побочные эффекты:** Инициализация полей создаваемого объекта.

**Примечания:** Для положительных размеров область задаётся полуоткрытыми интервалами `[X, X + Width)` и `[Y, Y + Height)`. Правый и нижний края не входят в область. Поля не нормализуются; отрицательные размеры означают пустую область. Суммы координаты и размера могут выходить за диапазон `std::int32_t`; `Intersect()` учитывает это расширением арифметики.

**Типичное применение:** Задавайте границы обрезки, затем пересекайте их с размерами поверхности.

**Пример:**

```cpp
#include <painter/core/geometry.h>
constexpr painter::core::Rect Area{10, 5, 20, 8};
static_assert(Area.X == 10 && Area.Width == 20);
```

### `Rect::Empty`

**Краткое описание:** Проверьте, является ли ширина или высота прямоугольника неположительной.

**Параметры:** Нет; читает `Width` и `Height` текущего объекта.

**Возвращает:** `bool`: результат `Width <= 0 || Height <= 0`.

**Побочные эффекты:** Нет.

**Примечания:** Метод `constexpr`, `const`, `noexcept`. Начало прямоугольника на результат не влияет.

**Пример:**

```cpp
#include <painter/core/geometry.h>
static_assert(painter::core::Rect{10, 20, -1, 3}.Empty());
static_assert(!painter::core::Rect{-10, -20, 1, 3}.Empty());
```

### `Rect::Intersect(Rect Other)`

**Краткое описание:** Вычислите пересечение с другим прямоугольником.

**Параметры:**

- `Other` (`Rect`, in): второй прямоугольник по значению.

**Возвращает:** `Rect`: общая область либо `Rect{0, 0, 0, 0}`, если пересечение пусто.

**Побочные эффекты:** Нет; исходные прямоугольники не изменяются.

**Как работает:** Левый и верхний края выбираются как максимумы начал, правый и нижний — как минимумы сумм начала и размера. Все вычисления краёв выполняются в `std::int64_t`, чтобы сложение полей не переполняло `std::int32_t`. Если правый край не правее левого или нижний не ниже верхнего, возвращается `{}`; иначе ширина и высота ограничиваются максимумом `std::int32_t` перед приведением типа.

**Примечания:** Метод `constexpr`, `const`, `noexcept`. Касание границ даёт пустой результат. Прямоугольник с неположительным размером также даёт пустое пересечение; перестановки краёв не происходит.

**Типичное применение:** Пересекайте область рисунка с областью обрезки перед обходом её элементов.

**Пример:**

```cpp
#include <painter/core/geometry.h>
constexpr painter::core::Rect Area{2, 3, 8, 5};
static_assert(Area.Intersect(painter::core::Rect{6, 1, 8, 5}) ==
              painter::core::Rect{6, 3, 4, 3});
static_assert(Area.Intersect(painter::core::Rect{10, 3, 1, 1}) ==
              painter::core::Rect{});
```

### `Rect::Intersect(Size Bounds)`

**Краткое описание:** Обрежьте прямоугольник границами области с началом в нуле.

**Параметры:**

- `Bounds` (`Size`, in): ширина и высота области по значению.

**Возвращает:** `Rect`: пересечение с `Rect{0, 0, Bounds.Width, Bounds.Height}`.

**Побочные эффекты:** Нет.

**Как работает:** Метод создаёт прямоугольник границ и передаёт его в перегрузку `Intersect(Rect)`. Поэтому правила пустого результата и расширенной арифметики совпадают с основной перегрузкой.

**Примечания:** Метод `constexpr`, `const`, `noexcept`. При пустом `Bounds` результат пуст. Вызов с `{}` без указания типа неоднозначен между перегрузками; используйте `Size{}` или `Rect{}`.

**Типичное применение:** Ограничивайте рисунок размерами поверхности, чьи локальные координаты начинаются с `(0, 0)`.

**Пример:**

```cpp
#include <painter/core/geometry.h>
constexpr painter::core::Rect Area{-2, -1, 5, 4};
static_assert(Area.Intersect(painter::core::Size{2, 2}) ==
              painter::core::Rect{0, 0, 2, 2});
```

### `operator==(Rect, Rect)`

**Краткое описание:** Сравните начало и размеры двух прямоугольников.

**Параметры:**

- Первый операнд (`Rect`, in): первый прямоугольник по значению.
- Второй операнд (`Rect`, in): второй прямоугольник по значению.

**Возвращает:** `bool`: `true`, если совпадают все четыре поля.

**Побочные эффекты:** Нет.

**Примечания:** Дружественная функция `constexpr`, `noexcept`, `= default`. Равенство проверяет поля, поэтому две пустые области могут быть не равны. `!=` доступно через правила C++23.

**Пример:**

```cpp
#include <painter/core/geometry.h>
static_assert(painter::core::Rect{} == painter::core::Rect{0, 0, 0, 0});
static_assert(painter::core::Rect{1, 0, 0, 0} != painter::core::Rect{});
```
