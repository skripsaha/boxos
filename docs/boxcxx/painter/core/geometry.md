# painter::core::geometry

## Назначение

Заголовок: [`painter/core/geometry.h`](../../../../src/userspace/painter/include/painter/core/geometry.h).
Реализации нет: всё в заголовке.

Точки, размеры и прямоугольники, общие для всех частей Painter. В
`painter::tui` единица — ячейка (или полублочная точка), в
`painter::gui` — точка интерфейса или пиксель холста; сами типы единиц не
знают.

Прямоугольник всегда задаётся началом и размером: `{X, Y, Width, Height}`
охватывает X от `X` до `X + Width` не включительно. Ось Y направлена вниз.
Все операции `noexcept`, большинство — `constexpr`; арифметика
пересечения и объединения ведётся в 64 битах, поэтому прямоугольники у
края диапазона `int32_t` не переполняются.

## Точки

### `Point`

**Краткое описание:** Хранит целую точку.

**Параметры:**
- `X` (`std::int32_t`): столбец, по умолчанию 0.
- `Y` (`std::int32_t`): строка, по умолчанию 0.

**Возвращает:** Неприменимо: агрегат; определено `==`.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "painter/core/geometry.h"

constexpr painter::core::Point Corner{0, 0};
static_assert(Corner == painter::core::Point{});
```

### `PointF`

**Краткое описание:** Хранит точку с дробными координатами.

**Параметры:**
- `X` (`float`), `Y` (`float`): по умолчанию 0.

**Возвращает:** Неприменимо: агрегат; сравнения нет.

**Побочные эффекты:** Нет.

**Типичное применение:** Фигуры `painter::tui::FineCanvas`, места и размеры элементов `painter::gui` в точках, контуры `Path`.

**Пример:**
```cpp
#include "painter/core/geometry.h"

constexpr painter::core::PointF Middle{10.5f, 7.25f};
```

## Размеры

### `Size`

**Краткое описание:** Хранит целые ширину и высоту.

**Параметры:**
- `Width` (`std::int32_t`), `Height` (`std::int32_t`): по умолчанию 0.

**Возвращает:** Неприменимо: агрегат; определено `==`.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "painter/core/geometry.h"

constexpr painter::core::Size Board{10, 20};
```

### `Size::Empty`

**Краткое описание:** Сообщает, пуст ли размер.

**Параметры:** Нет.

**Возвращает:** (`bool`) `true`, если ширина или высота не больше нуля.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "painter/core/geometry.h"

static_assert(painter::core::Size{0, 5}.Empty() && !painter::core::Size{1, 1}.Empty());
```

### `Size::CellCount`

**Краткое описание:** Возвращает число ячеек в размере с проверкой переполнения.

**Параметры:** Нет.

**Возвращает:** (`std::optional<std::size_t>`) `Width × Height`; пусто, если размер пуст или произведение не помещается в `size_t`.

**Побочные эффекты:** Нет.

**Типичное применение:** Размер буфера под растр или кадр.

**Пример:**
```cpp
#include <vector>

#include "painter/core/color.h"
#include "painter/core/geometry.h"

std::vector<painter::core::Color> Raster(painter::core::Size Of)
{
    const auto Count = painter::core::Size{Of.Width, Of.Height * 2}.CellCount();
    return Count ? std::vector<painter::core::Color>(*Count) : std::vector<painter::core::Color>{};
}
```

## Прямоугольники

### `Rect`

**Краткое описание:** Хранит целый прямоугольник: начало и размер.

**Параметры:**
- `X`, `Y` (`std::int32_t`): левый верхний угол.
- `Width`, `Height` (`std::int32_t`): размер.

**Возвращает:** Неприменимо: агрегат; определено `==`.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "painter/core/geometry.h"

constexpr painter::core::Rect Panel{2, 1, 30, 8};   // столбцы 2..31, строки 1..8
```

### `Rect::Empty`

**Краткое описание:** Сообщает, пуст ли прямоугольник.

**Параметры:** Нет.

**Возвращает:** (`bool`) `true`, если ширина или высота не больше нуля.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "painter/core/geometry.h"

static_assert(painter::core::Rect{5, 5, 0, 3}.Empty());
```

### `Rect::Intersect`

**Краткое описание:** Возвращает пересечение с другим прямоугольником или с областью размера.

**Параметры:**
- `Other` (`Rect`): другой прямоугольник; или
- `Bounds` (`Size`): размер, который понимается как прямоугольник `{0, 0, Width, Height}`.

**Возвращает:** (`Rect`) общая часть; пустой `Rect{}`, если общей части нет.

**Побочные эффекты:** Нет.

**Типичное применение:** Обрезать область рисования границами кадра: `Area.Intersect(Out.Size())`.

**Пример:**
```cpp
#include "painter/core/geometry.h"

static_assert(painter::core::Rect{-2, -2, 5, 5}.Intersect(painter::core::Size{10, 10}) == painter::core::Rect{0, 0, 3, 3});
```

### `Rect::Join`

**Краткое описание:** Возвращает наименьший прямоугольник, содержащий оба.

**Параметры:**
- `Other` (`Rect`): другой прямоугольник.

**Возвращает:** (`Rect`) охватывающий прямоугольник; пустой прямоугольник ничего не добавляет — объединение с ним возвращает другой. Размер ограничен `INT32_MAX`.

**Побочные эффекты:** Нет.

**Типичное применение:** Накопить «грязную» область: всё, что изменилось за кадр.

**Пример:**
```cpp
#include "painter/core/geometry.h"

static_assert(painter::core::Rect{0, 0, 2, 2}.Join(painter::core::Rect{5, 5, 1, 1}) == painter::core::Rect{0, 0, 6, 6});
static_assert(painter::core::Rect{}.Join(painter::core::Rect{1, 1, 1, 1}) == painter::core::Rect{1, 1, 1, 1});
```

### `RectF`

**Краткое описание:** Хранит прямоугольник с дробными координатами — место и размер фигуры до рисования.

**Параметры:**
- `X`, `Y`, `Width`, `Height` (`float`): по умолчанию 0.

**Возвращает:** Неприменимо: агрегат; сравнения нет.

**Побочные эффекты:** Нет.

**Примечания:** `Empty()` возвращает `true`, если ширина или высота не больше нуля или равна NaN.

**Типичное применение:** Прямоугольники, скруглённые прямоугольники и эллипсы `painter::core::Path`.

**Пример:**
```cpp
#include "painter/core/geometry.h"

constexpr painter::core::RectF Card{8.0f, 8.0f, 240.0f, 120.5f};
static_assert(!Card.Empty());
```
