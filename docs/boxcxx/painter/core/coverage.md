# painter::core::coverage — покрытие пикселя

## Назначение

Модуль `src/userspace/painter/include/painter/core/coverage.h` содержит функции доли покрытия пикселя фигурой и полосой около её границы. Подключение: `#include <painter/core/coverage.h>`. Все три функции находятся непосредственно в `painter::core`, объявлены `inline` и `noexcept`, реализованы в заголовке и возвращают `float`; `constexpr` не используется.

Функции не выделяют память, не выполняют системные вызовы, не меняют экран и не обращаются к общему изменяемому состоянию. Они вычисляют только долю покрытия; выбор геометрической границы, цвета и перевод доли в непрозрачность выполняет вызывающий код.

## Модель покрытия

`Beyond` — знаковое расстояние от границы до центра пикселя в единицах пикселя. Отрицательная величина означает положение внутри фигуры, положительная — снаружи, ноль — центр на границе. Для вычисления используется интервал пикселя шириной `1`, то есть по `0.5` с каждой стороны его центра.

Это локальная модель прямой границы, а не интегрирование площади произвольной фигуры внутри единичного квадрата. Для углов, кривых и наклонных границ функции сами не вычисляют точную площадь пересечения. `BandShare()` измеряет длину пересечения интервалов в шкале расстояния.

Передавайте конечные значения и доли в ожидаемом диапазоне. Функции не проверяют `NaN` и не сообщают об ошибках отдельным результатом. В частности, `Snapped()` не ограничивает произвольную долю диапазоном `0..1`.

## Функции

### `InsideShare`

**Краткое описание:** Вычислите долю пикселя внутри фигуры по расстоянию до её границы.

**Параметры:**

- `Beyond` (`float`, in): знаковое расстояние от границы до центра пикселя; отрицательное внутри фигуры.

**Возвращает:** `float`: значение `std::clamp(0.5f - Beyond, 0.0f, 1.0f)`; для конечного входа находится в `0..1`.

**Побочные эффекты:** Нет.

**Как работает:** Функция вычитает расстояние из половины ширины пикселя и ограничивает результат единичным интервалом. При `Beyond <= -0.5f` пиксель считается полностью покрытым, при `Beyond >= 0.5f` — непокрытым. Между этими границами доля линейно убывает; центр на границе даёт `0.5f`.

**Примечания:** Функция не вычисляет само расстояние до фигуры и не определяет единицы координат за вызывающий код. Для согласованного результата расстояние должно измеряться в единицах ширины пикселя этой модели.

**Типичное применение:** Вычислите знаковое расстояние до края фигуры, передайте его в `InsideShare()`, затем при необходимости отключите сглаживание через `Snapped()` и преобразуйте долю в `Color::WithOpacity()`.

**Пример:**

```cpp
#include <painter/core/coverage.h>
bool CheckInsideShare()
{
    using painter::core::InsideShare;
    return InsideShare(-0.5f) == 1.0f &&
           InsideShare(0.0f) == 0.5f &&
           InsideShare(0.25f) == 0.25f &&
           InsideShare(0.5f) == 0.0f;
}
```

### `BandShare`

**Краткое описание:** Вычислите долю пикселя в полосе между двумя расстояниями от границы.

**Параметры:**

- `Beyond` (`float`, in): знаковое расстояние от границы до центра пикселя.
- `Near` (`float`, in): нижняя граница полосы в той же шкале расстояния.
- `Far` (`float`, in): верхняя граница полосы в той же шкале расстояния.

**Возвращает:** `float`: значение `std::clamp(std::min(Beyond + 0.5f, Far) - std::max(Beyond - 0.5f, Near), 0.0f, 1.0f)`; для конечных входов находится в `0..1`.

**Побочные эффекты:** Нет.

**Как работает:** Пиксель представлен интервалом `[Beyond - 0.5f, Beyond + 0.5f]`. Функция выбирает меньшую из верхних границ пикселя и полосы, вычитает большую из нижних границ и ограничивает результат диапазоном `0..1`. При отсутствии пересечения результат равен нулю; полное перекрытие интервала пикселя даёт единицу.

**Примечания:** Для непустой полосы передавайте `Near < Far`. При `Near >= Far` и конечных входах результат равен нулю; функция не переставляет границы. Отрицательные границы допустимы и задают полосу внутри фигуры. Для полосы уже пикселя максимальное покрытие может быть меньше `1`.

**Типичное применение:** Для обводки снаружи границы используйте полосу от `0` до её ширины; для обводки по обе стороны границы задайте отрицательную и положительную границы. При отключённом сглаживании обработайте долю через `Snapped()`.

**Пример:**

```cpp
#include <painter/core/coverage.h>
bool CheckBandShare()
{
    using painter::core::BandShare;
    return BandShare(0.0f, 0.0f, 1.0f) == 0.5f &&
           BandShare(0.5f, 0.0f, 1.0f) == 1.0f &&
           BandShare(2.0f, 0.0f, 1.0f) == 0.0f &&
           BandShare(0.0f, -0.125f, 0.125f) == 0.25f &&
           BandShare(0.0f, 1.0f, 0.0f) == 0.0f;
}
```

### `Snapped`

**Краткое описание:** Сохраните плавную долю покрытия либо преобразуйте её в двоичное покрытие по порогу `0.5`.

**Параметры:**

- `Share` (`float`, in): доля покрытия, обычно результат `InsideShare()` или `BandShare()` в `0..1`.
- `Smooth` (`bool`, in): `true` для сохранения доли, `false` для порогового преобразования положительных долей.

**Возвращает:** `float`: исходный `Share`, если `Smooth == true` или `Share <= 0`; иначе `1.0f` при `Share >= 0.5f`, `0.0f` при меньшей доле.

**Побочные эффекты:** Нет.

**Как работает:** Сначала проверяется `Smooth || Share <= 0.0f`: эта ветвь возвращает долю без изменений. Только для положительной доли при отключённом сглаживании применяется порог `0.5f`. Покрытие ровно половины пикселя считается полным.

**Примечания:** Отрицательная доля сохраняется даже при `Smooth == false`; при `Smooth == true` также сохраняются значения больше `1`. Поэтому это переключатель сглаживания для корректной доли, а не её проверка или нормализация. Узкая полоса, покрывающая меньше половины каждого пикселя, может полностью исчезнуть при отключённом сглаживании.

**Типичное применение:** Применяйте после расчёта покрытия, перед переводом результата в байт непрозрачности.

**Пример:**

```cpp
#include <painter/core/coverage.h>
bool CheckSnapped()
{
    using painter::core::Snapped;
    return Snapped(0.25f, true) == 0.25f &&
           Snapped(0.25f, false) == 0.0f &&
           Snapped(0.5f, false) == 1.0f &&
           Snapped(-0.25f, false) == -0.25f;
}
```

## Совместное использование с Color

Для конечной доли в `0..1` выражение `static_cast<std::uint8_t>(Share * 255.0f + 0.5f)` округляет непрозрачность до ближайшего байта. `Color::WithOpacity()` хранит её точно (0–255); до 63 ступеней формата дисплея она округляется только при передаче ячейки дисплею (`Color::Raw()`, см. [color.md](color.md)). Покрытие не умножается на непрозрачность исходного цвета автоматически: `WithOpacity()` заменяет её. Для `Screen()` и `Through()` этот метод сохраняет специальное значение при любом аргументе.

Пример создаёт цвет края без вывода на экран. При `Beyond == 0` и включённом сглаживании непрозрачность равна `128`, и `Opacity()` такого цвета возвращает `128`; на проводе она станет 32 ступенями из 63.

```cpp
#include <painter/core/color.h>
#include <painter/core/coverage.h>
painter::core::Color EdgeInk(float Beyond, bool Smooth)
{
    const float Share = painter::core::Snapped(
        painter::core::InsideShare(Beyond), Smooth);
    const auto Opacity = static_cast<std::uint8_t>(Share * 255.0f + 0.5f);
    return painter::core::Colors::Ocean.WithOpacity(Opacity);
}
```
