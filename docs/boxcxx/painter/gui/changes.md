# painter::gui::changes

## Назначение

Заголовок: [`painter/gui/changes.h`](../../../../src/userspace/painter/include/painter/gui/changes.h).
Реализация: [`src/gui/changes.cpp`](../../../../src/userspace/painter/src/gui/changes.cpp).

Здесь два слоя:

- **значения свойств** — типы, которыми программа описывает элемент: вид и роль элемента, заливки, обводка, тени, стиль текста, рамка текста, анимация;
- **`Changes`** — запись изменений элементов на языке элементов (`box/items.h`). Каждое сказанное свойство становится записью; при показе шага записи кладутся в кольцо области. `Area` наследует `Changes`, поэтому все методы ниже доступны у области по номеру элемента. Объекты элементов ([items](items.md)) вызывают их же.

Числа переводятся в язык так: места и размеры — в 1/256 точки (не дальше
`ITEM_REACH`), цвета — 16 бит на канал, доли (непрозрачность, позиции
остановок) — 0–65535, повороты — доли полного оборота.

## Вид и роль

### `Kind`

**Краткое описание:** Называет вид элемента.

**Параметры:**
- `Group` — группа: элементы лежат в ней, видны сквозь неё как одно целое и обрезаются ею, если она обрезает.
- `Text` — текст.
- `Shape` — фигура: прямоугольник (со скруглениями), эллипс, произвольный контур.
- `Picture` — картинка из блока.
- `Canvas` — холст собственных пикселей программы.
- `Cells` — сетка ячеек в виде консоли.

**Возвращает:** Неприменимо: перечисление `std::uint8_t` (= `ITEM_*`).

**Побочные эффекты:** Нет.

**Пример:** См. `Changes::Create`.

### `Role`

**Краткое описание:** Называет смысл элемента, по которому тема решает, как он выглядит.

**Параметры:** (для текста — размер и насыщенность шрифта, для фигуры — заливка, скругление, тень по умолчанию)
- `None` — ничего; свой вид программа говорит сама.
- `Page` — то, на чём стоит всё остальное: заливка цветом страницы.
- `Panel` — плашка над страницей: цвет панели, скругление 1,5 × «круглости» темы, мягкая тень.
- `Body` — обычный текст: Inter 15 pt, 400.
- `Heading` — заголовок: 22 pt, 600.
- `Code` — код: JetBrains Mono NL 14 pt.
- `Hint` — тихий текст: 13 pt, «тихий» цвет темы.
- `Label` — подпись: 14 pt, 500.
- `Button` — кнопка: текст в этой роли сам носит плашку акцентного цвета (поля 14×7 pt), 600, слова цветом «на акценте»; доступна клавиатуре.
- `Field` — поле ввода: текст носит плашку цвета панели (поля 10×7 pt), тонкую обводку внутрь и вдавленную тень; дисплей сам редактирует его текст; доступно клавиатуре.
- `Icon` — значок: цвет текста.
- `Separator` — разделитель: «тихий» цвет, полупрозрачный.
- `Selection` — выделение: акцентный цвет, около трети непрозрачности.

**Возвращает:** Неприменимо: перечисление `std::uint16_t` (= `ITEM_ROLE_*`).

**Побочные эффекты:** Нет.

**Примечания:** Значения по умолчанию взяты из [look](../items/look.md); тема человека меняет акцент, круглость и наличие теней. Если человек включил `theme insist`, вид темы стоит выше сказанного программой для всех элементов с ролью.

**Пример:**
```cpp
#include "painter/gui/area.h"
#include "painter/gui/items.h"

painter::gui::Text Hint(painter::gui::Area &Screen) { return Screen.Text("Esc — выйти", painter::gui::Role::Hint); }
```

### `ThemeColor`

**Краткое описание:** Называет цвет темы, который следует выбору человека.

**Параметры:**
- `Text` — цвет текста экрана.
- `Page` — цвет страницы.
- `Panel` — цвет панели (страница с примесью текста).
- `Accent` — акцентный цвет человека.
- `Quiet` — тихий текст.
- `OnAccent` — то, что рисуется на акценте (слова кнопки): тёмное на светлом акценте, светлое на тёмном.

**Возвращает:** Неприменимо: перечисление `std::uint16_t` (= `ITEM_THEME_*`).

**Побочные эффекты:** Нет.

**Типичное применение:** `Fill::OfTheme(ThemeColor::Accent)` — заливка, которая сменится вместе с темой без участия программы.

**Пример:** См. `Fill`.

## Значения свойств

### `Fill`

**Краткое описание:** Описывает одну заливку элемента: цвет, цвет темы, градиент или картинку.

**Параметры:**
- `What` (`Fill::Kind`): `Color`, `Theme`, `Linear`, `Radial`, `Conic`, `Picture`; по умолчанию `Color`.
- `Color` (`core::Color`): для `Color`.
- `Theme` (`ThemeColor`): для `Theme`.
- `From`, `To` (`core::PointF`): концы линейного градиента; `From` — центр радиального и конического. В точках элемента.
- `Radius` (`float`): радиус радиального.
- `Focus` (`core::PointF`): фокус радиального.
- `StartDegrees` (`float`): начало конического, 0 — вверх, по часовой.
- `Stops` (`std::vector<Stop>`): остановки градиента; `Stop{Offset 0–1, Color}`; не больше `ITEM_STOPS_MOST` (64).
- `Extend` (`std::uint8_t`): что за концами градиента или краем картинки — `ITEM_EXTEND_PAD`, `REPEAT`, `REFLECT`, `NONE`.
- `Block` (`std::uint32_t`): блок картинки; `At`, `Size` (`core::PointF`): где картинка лежит в элементе и какого размера; `Sharp` (`bool`): пиксели квадратами.
- `Opacity` (`float`): непрозрачность заливки 0–1, по умолчанию 1.

**Возвращает:** Неприменимо: агрегат. `Fill::Of(Color)` и `Fill::OfTheme(ThemeColor)` — готовые конструкторы.

**Побочные эффекты:** Нет.

**Примечания:** Заливок у элемента может быть несколько (до `ITEM_FILLS_MOST`, 16), первая — нижняя. Градиенты элемента описываются в его точках; движок рисования градиентов — [core/gradient](../core/gradient.md).

**Пример:**
```cpp
#include "painter/gui/items.h"

void Glow(painter::gui::Shape &Plate)
{
    namespace gui = painter::gui;
    gui::Fill Sky;
    Sky.What  = gui::Fill::Kind::Linear;
    Sky.From  = {0, 0};
    Sky.To    = {0, 120};
    Sky.Stops = {{0.0f, painter::core::Colors::Ocean}, {1.0f, painter::core::Colors::DarkBlue}};
    const gui::Fill Both[] = {Sky, gui::Fill::OfTheme(gui::ThemeColor::Accent)};
    Plate.SetFills(Both);
    Plate.SetFill(Sky);   // или одна заливка
}
```

### `Stroke`

**Краткое описание:** Описывает обводку фигуры или текста.

**Параметры:**
- `Width` (`float`): толщина в точках, по умолчанию 1.
- `Cap` (`std::uint8_t`): концы — `ITEM_CAP_BUTT`, `ROUND`, `SQUARE`.
- `Join` (`std::uint8_t`): углы — `ITEM_JOIN_MITER`, `ROUND`, `BEVEL`.
- `Align` (`std::uint8_t`): положение относительно края — `ITEM_ALIGN_CENTER`, `INSIDE`, `OUTSIDE`.
- `MiterLimit` (`float`): предел острого угла в толщинах, по умолчанию 4 (не меньше 1).
- `Dashes` (`std::vector<float>`): штрих, пробел, штрих…; не больше 64; пусто — сплошная.
- `DashOffset` (`float`): сдвиг узора.
- `With` (`Fill`): чем обводка закрашена.

**Возвращает:** Неприменимо: агрегат.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "painter/gui/items.h"

void Dashed(painter::gui::Shape &Frame)
{
    painter::gui::Stroke Line;
    Line.Width  = 2;
    Line.Align  = ITEM_ALIGN_INSIDE;
    Line.Dashes = {6, 4};
    Line.With   = painter::gui::Fill::OfTheme(painter::gui::ThemeColor::Quiet);
    Frame.SetStroke(Line);
}
```

### `Shadow`

**Краткое описание:** Описывает тень элемента, как `box-shadow` в CSS.

**Параметры:**
- `Offset` (`core::PointF`): сдвиг.
- `Blur` (`float`): размытие края в точках.
- `Spread` (`float`): расширение (отрицательное — сжатие).
- `Color` (`core::Color`): по умолчанию чёрный с непрозрачностью 96.
- `Inner` (`bool`): внутренняя (вдавленная) тень.

**Возвращает:** Неприменимо: агрегат. Теней — до `ITEM_SHADOWS_MOST` (8).

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "painter/gui/items.h"

void Lift(painter::gui::Shape &Card) { Card.SetShadow({{0, 6}, 20, 0, painter::core::Color::Rgba(0, 0, 0, 80), false}); }
```

### `TextStyle`

**Краткое описание:** Описывает, как набран текст или его отрезок; говорит только то, что задано.

**Параметры:** (все `std::optional`; несказанное берётся из роли)
- `Family` (`std::string_view`): семейство шрифта, до 1024 байт.
- `Size` (`float`): кегль в точках.
- `Weight` (`std::uint16_t`): насыщенность 100–900.
- `Italic` (`bool`).
- `LetterSpacing` (`float`): разрядка в точках.
- `LineHeight` (`float`): высота строки в долях кегля, 0–64.
- `Underline`, `Strike` (`bool`): подчёркивание и зачёркивание.
- `Color` (`core::Color`): цвет текста.

**Возвращает:** Неприменимо: агрегат.

**Побочные эффекты:** Нет.

**Примечания:** `Family` — `string_view`: строка должна жить до вызова `SetStyle` (значение копируется при записи).

**Пример:**
```cpp
#include "painter/gui/items.h"

void Big(painter::gui::Text &Clock)
{
    painter::gui::TextStyle Style;
    Style.Size   = 64;
    Style.Weight = 300;
    Clock.SetStyle(Style);
}
```

### `Span`

**Краткое описание:** Описывает отрезок текста с собственным стилем.

**Параметры:**
- `From`, `To` (`std::uint32_t`): границы отрезка в символах (кодовых точках Unicode) от начала текста, `[From, To)`; более поздний отрезок стоит над ранним там, где они пересекаются.
- `Style` (`TextStyle`): только то, что отрезок меняет.

**Возвращает:** Неприменимо: агрегат. Отрезков — до `ITEM_SPANS_MOST` (4096).

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "painter/gui/items.h"

void Bold(painter::gui::Text &Line)   // текст: "Файл: notes.txt"
{
    painter::gui::Span Name;
    Name.From         = 6;    // "Файл: " — 6 символов (10 байт UTF-8, но считаются символы)
    Name.To           = 15;
    Name.Style.Weight = 700;
    Line.SetSpans(std::span(&Name, 1));
}
```

### `TextBox`

**Краткое описание:** Описывает, как текст лежит в своём размере.

**Параметры:**
- `Align` (`std::uint8_t`): `ITEM_TEXT_LEFT`, `CENTER`, `RIGHT`, `JUSTIFY`.
- `Overflow` (`std::uint8_t`): что делать с лишним — `ITEM_OVERFLOW_GROW` (элемент растёт), `CLIP` (обрезать), `ELLIPSIS` (обрезать с многоточием).
- `Wrap` (`bool`): переносить строки, по умолчанию `true`.
- `MaxLines` (`std::uint32_t`): наибольшее число строк, 0 — любое.

**Возвращает:** Неприменимо: агрегат.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "painter/gui/items.h"

void OneLine(painter::gui::Text &Title)
{
    Title.SetSize({200, painter::gui::ByContent}).SetBox({ITEM_TEXT_LEFT, ITEM_OVERFLOW_ELLIPSIS, false, 1});
}
```

### `ByContent`

**Краткое описание:** Обозначает сторону размера, которую решает содержимое элемента.

**Параметры:** Нет; `constexpr float ByContent = -1.0f`. Любое отрицательное значение стороны размера означает то же.

**Возвращает:** Неприменимо: константа.

**Побочные эффекты:** Нет.

**Как работает:** Дисплей раскладывает содержимое и сообщает получившийся размер событием `Event::Kind::Size`.

**Пример:** См. `TextBox`.

### `Animation`

**Краткое описание:** Описывает, как изменение идёт во времени.

**Параметры:**
- `Duration` (`std::chrono::milliseconds`): длительность, по умолчанию 250 мс; не больше часа.
- `Curve` (`Animation::Ease`): `Linear`, `In` (медленно вначале), `Out` (замедление к концу, по умолчанию), `InOut`, `Steps`, `Spring`, `Own`.
- `Bounce` (`float`): для `Spring` — насколько проскочить конец, доля пути 0–1.
- `Steps` (`int`): для `Steps` — число скачков, 1–255.
- `Bend1`, `Bend2` (`core::PointF`): для `Own` — внутренние точки кубической кривой Безье; X в 0–1, Y в −8…8.
- `Delay` (`std::chrono::milliseconds`): задержка начала.
- `Number` (`std::uint32_t`): номер; когда последняя анимация с этим номером закончится, придёт `Event::Kind::AnimationEnd`.
- `After` (`std::uint32_t`): начать, когда закончатся все анимации с этим номером.
- `Repeats` (`std::uint32_t`): сколько раз повторить после первого, `Animation::Forever` — бесконечно.
- `Back` (`bool`): каждый повтор идёт обратно.

**Возвращает:** Неприменимо: агрегат. Готовые конструкторы: `Linear(ms)`, `In(ms)`, `Out(ms)`, `InOut(ms)`, `Spring(settle, bounce = 0)`. `Wire()` — значение в виде языка (`ItemAnimation`).

**Побочные эффекты:** Нет.

**Как работает:** Анимация идёт от того, где свойство находится в момент начала, к сказанному. Сказанное заново по пути продолжает оттуда, где свойство сейчас (пружина сохраняет скорость); сказанное без анимации — сразу становится сказанным. Элемент, который ещё ни разу не показывался, получает первые значения сразу — ничего не «прилетает из ниоткуда». Свойство, сказанное без анимации раньше анимации в том же шаге, задаёт её начало.

**Пример:**
```cpp
#include <chrono>

#include "painter/gui/area.h"
#include "painter/gui/items.h"

void FadeIn(painter::gui::Area &Screen, painter::gui::Text &Line)
{
    using namespace std::chrono_literals;
    Line.SetOpacity(0);                        // начало
    painter::gui::Animation How = painter::gui::Animation::Out(300ms);
    How.Delay = 100ms;
    Screen.Animate(How, [&] { Line.SetOpacity(1); });
    (void)Screen.Present();
}
```

## Класс Changes

### `Changes`

**Краткое описание:** Копит изменения элементов и кладёт их в кольцо области шагами.

**Параметры:** Конструктор по умолчанию; обычно используется как часть `Area`.

**Возвращает:** Неприменимо: класс.

**Побочные эффекты:** Нет до `Flush`.

**Как работает:** Хранит три вещи: упорядоченный список созданий, удалений, перестановок; для каждого свойства — ждущие слова (последнее обычное слово и после него анимации); последнее сказанное значение каждого свойства каждого элемента. Свойство, сказанное так же, как раньше, отбрасывается. Обычное слово отменяет все ждущие слова этого свойства; анимация отменяет ждущие анимации, но идёт после обычного слова, задающего её начало; анимация с `After` или `Delay` встаёт в очередь после всех. Ячейки сеток хранятся целиком, и у каждой строки отмечается отрезок изменившихся ячеек.

**Примечания:** Значение больше половины кольца (512 КиБ) не записывается: оно считается в `Refused()`.

**Пример:**
```cpp
#include "painter/gui/area.h"

void Move(painter::gui::Area &Screen, std::uint32_t Item) { Screen.Place(Item, {40, 40}); }
```

### `Changes::Create` / `Remove` / `Restack`

**Краткое описание:** Создают элемент, удаляют его и переставляют среди соседей.

**Параметры:**
- `Item` (`std::uint32_t`): номер элемента, выбранный программой (не 0).
- `Kind` (`gui::Kind`): вид — для `Create`.
- `Parent` (`std::uint32_t`): группа или `ITEM_AREA` (сама область).
- `Above` (`std::uint32_t`): над каким соседом лечь; `ITEM_TOP` — выше всех.
- `Role` (`gui::Role`): роль — для `Create`, по умолчанию `None`.

**Возвращает:** `void`.

**Побочные эффекты:** Добавляют запись в упорядоченный список. `Create` забывает всё сказанное раньше о номере; `Remove` отбрасывает ждущие слова и запомненные значения элемента (и его сетку).

**Примечания:** Удаление группы удаляет всё, что в ней. Элементов — до `ITEM_ITEMS_MOST` (65536), вложенность — до `ITEM_DEPTH_MOST` (64). Объекты элементов выбирают номера сами, начиная с 2²⁰; номера ниже свободны для программы.

**Пример:**
```cpp
#include "painter/gui/area.h"

void Plate(painter::gui::Area &Screen)
{
    namespace gui = painter::gui;
    Screen.Create(7, gui::Kind::Shape, ITEM_AREA, ITEM_TOP, gui::Role::Panel);
    Screen.Size(7, {240, 80});
    Screen.Rectangle(7);
}
```

### `Changes::Reset` / `Changes::Role`

**Краткое описание:** Возвращают свойство к значению роли и меняют роль элемента.

**Параметры:**
- `Item` (`std::uint32_t`).
- `Property` (`std::uint16_t`): `ITEM_PROP_*` — для `Reset`.
- `Role` (`gui::Role`): новая роль — для `Role`.

**Возвращает:** `void`.

**Побочные эффекты:** `Reset` забывает свойство и пишет запись «не сказано»; `Role` пишет свойство роли.

**Пример:**
```cpp
#include "painter/gui/area.h"

void PlainAgain(painter::gui::Area &Screen, std::uint32_t Item) { Screen.Reset(Item, ITEM_PROP_FILLS); }
```

### Свойства места: `Place`, `Size`, `Turn`, `Scale`, `Anchor`

**Краткое описание:** Задают место, размер, поворот, масштаб элемента и точку, вокруг которой он поворачивается и масштабируется.

**Параметры:**
- `Item` (`std::uint32_t`).
- `At` (`core::PointF`): место от угла родителя (`Place`) или точка от угла элемента (`Anchor`), в точках.
- `Size` (`core::PointF`): размер; сторона `ByContent` (отрицательная) — по содержимому.
- `Degrees` (`float`): поворот по часовой (берётся по модулю 360).
- `Scale` (`core::PointF`): масштаб по осям, −64…64.

**Возвращает:** `void`.

**Побочные эффекты:** Записывают свойство, если оно отличается от сказанного.

**Примечания:** Нечисловые значения (NaN, бесконечность) превращаются в 0 (масштаб — в 1).

**Пример:**
```cpp
#include "painter/gui/area.h"

void Tilt(painter::gui::Area &Screen, std::uint32_t Item)
{
    Screen.Anchor(Item, {50, 50});
    Screen.Turn(Item, 15);
}
```

### Свойства видимости: `Opacity`, `Hidden`, `Clip`, `Caption`

**Краткое описание:** Задают непрозрачность, скрытость, обрезку группой и словесное описание элемента.

**Параметры:**
- `Item` (`std::uint32_t`).
- `Opacity` (`float`): 0–1.
- `Hidden` (`bool`).
- `Clip` (`bool`): группа обрезает свои элементы своими границами (и скруглениями).
- `Utf8` (`std::string_view`): подпись — что это за элемент словами; видна на текстовой странице и для чтения вслух.

**Возвращает:** `void`.

**Побочные эффекты:** Записывают свойство.

**Пример:**
```cpp
#include "painter/gui/area.h"

void Describe(painter::gui::Area &Screen, std::uint32_t Chart) { Screen.Caption(Chart, "График загрузки: 40 %"); }
```

### Клавиатура: `Focusable`, `Disabled`, `Focus`

**Краткое описание:** Говорят, доступен ли элемент клавиатуре, можно ли им пользоваться, и переводят фокус.

**Параметры:**
- `Item` (`std::uint32_t`); для `Focus` — `ITEM_AREA` снимает фокус.
- `Reached` (`bool`): клавиатура доходит до элемента (кнопки и поля — без слов).
- `Disabled` (`bool`): виден, но недоступен: рисуется бледно (доля `Faint` темы) и клавиатурой не достигается.

**Возвращает:** `void`.

**Побочные эффекты:** `Focusable`, `Disabled` — свойства; `Focus` — запись в упорядоченный список.

**Пример:**
```cpp
#include "painter/gui/area.h"

void Lock(painter::gui::Area &Screen, std::uint32_t Save) { Screen.Disabled(Save, true); }
```

### Форма: `Corners`, `Rectangle`, `Ellipse`, `Outline`

**Краткое описание:** Задают скругления углов и форму фигуры.

**Параметры:**
- `Item` (`std::uint32_t`).
- `Round` (`const core::Corners &`): радиусы четырёх углов в точках (отрицательные — 0).
- `Shape` (`const core::Path &`): контур в точках элемента (для `Outline`).
- `EvenOdd` (`bool`): дырки по правилу чётности, иначе по обходу.

**Возвращает:** `void`.

**Побочные эффекты:** Записывают свойство `ITEM_PROP_SHAPE` (или `ITEM_PROP_CORNERS`).

**Как работает:** Готовые прямоугольники, скруглённые прямоугольники и эллипсы `Path` переводятся в линии и кубические кривые; квадратичные кривые — в кубические.

**Примечания:** Шагов контура — до `ITEM_PATH_MOST` (65536). Скругления группы обрезают её содержимое при `Clip`.

**Пример:**
```cpp
#include "painter/gui/area.h"

void Star(painter::gui::Area &Screen, std::uint32_t Item)
{
    if (auto Shape = painter::core::Path::FromSvg("M50 0 L61 35 L98 35 L68 57 L79 91 L50 70 L21 91 L32 57 L2 35 L39 35 Z"))
        Screen.Outline(Item, *Shape);
}
```

### Краска: `Fills`, `Stroke`, `Shadows`

**Краткое описание:** Задают заливки, обводку и тени.

**Параметры:**
- `Item` (`std::uint32_t`).
- `Fills` (`std::span<const Fill>`): заливки, первая — нижняя.
- `Line` (`const gui::Stroke &`): обводка; толщина 0 — без обводки.
- `Shadows` (`std::span<const Shadow>`): тени.

**Возвращает:** `void`.

**Побочные эффекты:** Записывают свойство.

**Пример:**
```cpp
#include "painter/gui/area.h"

void Red(painter::gui::Area &Screen, std::uint32_t Item)
{
    const painter::gui::Fill One = painter::gui::Fill::Of(painter::core::Colors::Red);
    Screen.Fills(Item, std::span(&One, 1));
}
```

### Текст: `Text`, `Style`, `Spans`, `Box`, `Secret`

**Краткое описание:** Задают текст элемента, его стиль, отрезки со своим стилем, раскладку и признак секрета.

**Параметры:**
- `Item` (`std::uint32_t`).
- `Utf8` (`std::string_view`): текст; до `ITEM_TEXT_MOST` (192 КиБ) на элемент и `ITEM_TEXTS_MOST` (16 МиБ) на программу.
- `Style` (`const TextStyle &`), `Spans` (`std::span<const Span>`), `Box` (`const TextBox &`).
- `Secret` (`bool`): показывать звёздочками; никогда не читается вслух и не копируется.

**Возвращает:** `void`.

**Побочные эффекты:** Записывают свойство.

**Пример:**
```cpp
#include "painter/gui/area.h"

void Password(painter::gui::Area &Screen, std::uint32_t Field) { Screen.Secret(Field, true); }
```

### Блоки: `Picture`, `Canvas`, `BlockChanged`

**Краткое описание:** Показывают блок картинки или холста в элементе и сообщают дисплею, что пиксели блока изменились.

**Параметры:**
- `Item` (`std::uint32_t`).
- `Block` (`std::uint32_t`): номер блока.
- `Fit` (`std::uint8_t`): как картинка заполняет размер — `ITEM_FIT_STRETCH` (растянуть), `CONTAIN` (вписать целиком), `COVER` (заполнить с обрезкой), `CENTER` (по центру без масштаба).
- `Sharp` (`bool`): пиксели квадратами (пиксель-арт).
- `Where` (`core::Rect`): изменившийся прямоугольник в пикселях блока — для `BlockChanged`.
- `Page` (`std::uint32_t`): для холста — страница, которая теперь показывается.

**Возвращает:** `void`.

**Побочные эффекты:** `Picture`, `Canvas` — свойства; `BlockChanged` — запись в упорядоченный список.

**Пример:**
```cpp
#include "painter/gui/area.h"

void Repainted(painter::gui::Area &Screen, std::uint32_t Block, painter::core::Rect Where) { Screen.BlockChanged(Block, Where); }
```

### Сетка ячеек: `Grid`, `Cells`, `Caret`

**Краткое описание:** Задают размер сетки ячеек, ячейки с заданной позиции и каретку.

**Параметры:**
- `Item` (`std::uint32_t`).
- `Cols`, `Rows` (`std::uint32_t`): размер, 1–4096 по стороне.
- `Row`, `Col` (`std::uint32_t`): начало отрезка.
- `Cells` (`std::span<const ItemCell>`): ячейки; лишнее за правым краем отбрасывается.
- `At` (`std::optional<core::Point>`): каретка; пусто — нет.

**Возвращает:** `void`.

**Побочные эффекты:** `Grid` делает все ячейки пустыми (здесь и у дисплея); `Cells` отмечает отличающиеся ячейки; `Caret` — свойство.

**Как работает:** Ячейки уходят после всех остальных изменений шага, по одному отрезку от первой до последней изменившейся ячейки на строку. Неверный размер сетки или позиция вне сетки не пишутся и считаются в `Refused()`.

**Примечания:** Всего ячеек у программы — до `ITEM_CELLS_MOST` (2²⁰). На этом построен весь `painter::tui`.

**Пример:**
```cpp
#include <array>

#include "painter/gui/area.h"

void Hello(painter::gui::Area &Screen, std::uint32_t Grid)
{
    std::array<ItemCell, 2> Run{};
    Run[0] = ItemCell{U'О', 0xFFFFFFu, COLOR_THROUGH, 0, ITEM_MARK_NONE, {0, 0, 0}};
    Run[1] = ItemCell{U'К', 0xFFFFFFu, COLOR_THROUGH, 0, ITEM_MARK_NONE, {0, 0, 0}};
    Screen.Cells(Grid, 0, 0, Run);
}
```

### `Changes::Animate` / `Changes::Animating`

**Краткое описание:** Проводят во времени всё, что сказано внутри функции, или всё, что сказано с этого момента.

**Параметры:**
- `How` (`const Animation &`) — для `Animate`; (`std::optional<Animation>`) — для `Animating`, пусто — снова сразу.
- `Change` (вызываемый объект без аргументов) — для `Animate`.

**Возвращает:** `void`.

**Побочные эффекты:** Пока действует, каждое свойство записывается как анимация (`ITEM_OP_ANIMATE`), а не обычное изменение.

**Как работает:** `Animate` запоминает прежний режим и восстанавливает его по выходу (в том числе при исключении). Работает и для объектов, и для кадров целиком.

**Примечания:** На текстовой странице дисплей применяет всё сразу. Анимаций в работе и ожидании — до `ITEM_ANIMATIONS_MOST` (16384).

**Пример:** См. `Animation`.

### `Changes::Flush`

**Краткое описание:** Кладёт ждущие записи в кольцо, пока есть место, и завершает шаг.

**Параметры:**
- `Ring` (`std::uint8_t *`), `Bytes` (`std::uint32_t`): кольцо и его размер.
- `Write` (`std::uint64_t &`, in-out): позиция записи.
- `Read` (`std::uint64_t`): позиция чтения дисплея.
- `Step` (`std::uint64_t`): номер шага для записи конца шага.

**Возвращает:** (`bool`) `true`, если ничего не ждёт.

**Побочные эффекты:** Пишет в кольцо и удаляет записанное из очередей.

**Примечания:** Вызывается из `Area::Present`; программе напрямую не нужен.

**Пример:** Не приводится: внутренний шаг `Area::Present`.

### `Changes::Empty` / `Waiting` / `Bytes` / `Written` / `Refused`

**Краткое описание:** Возвращают состояние очереди изменений.

**Параметры:** Нет.

**Возвращает:**
- `Empty` — (`bool`) ничего не ждёт.
- `Waiting` — (`std::size_t`) число ждущих записей (строки ячеек считаются по одной).
- `Bytes` — (`std::size_t`) байты ждущих записей.
- `Written` — (`std::uint64_t`) байты, записанные за всё время.
- `Refused` — (`std::uint64_t`) изменения, отвергнутые ещё до записи (слишком большие, неверная сетка).

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "painter/gui/area.h"

bool Behind(const painter::gui::Area &Screen) { return !Screen.Empty(); }
```

### `Changes::Said` / `SaidOf` / `EachSaid` / `Forget` / `Known` / `Say` / `RememberOnly`

**Краткое описание:** Дают доступ к запомненным значениям свойств и управляют ими.

**Параметры:**
- `Item` (`std::uint32_t`), `Property` (`std::uint16_t`).
- `Value` (`std::span<const std::uint8_t>`): значение в байтах языка — для `Known` и `Say`.
- `Visit` (вызываемый объект `(std::uint16_t, std::span<const std::uint8_t>)`) — для `EachSaid`.

**Возвращает:** `Said` — указатель на байты последнего значения или `nullptr`; `SaidOf` — список сказанных свойств; остальные — `void`.

**Побочные эффекты:** `Forget` — свойство больше не считается сказанным (дисплей его отверг); `Known` — запоминает значение, сказанное другой рукой (человеком в поле), без записи; `Say` — пишет готовые байты, если они отличаются; `RememberOnly` — дальше только запоминать, ничего не писать (так описывается кадр).

**Примечания:** Служебные методы для `Frame`, `Measure` и интерфейса C. Программе обычно не нужны.

**Пример:**
```cpp
#include "painter/gui/area.h"

bool HasText(const painter::gui::Area &Screen, std::uint32_t Item) { return Screen.Said(Item, ITEM_PROP_TEXT) != nullptr; }
```
