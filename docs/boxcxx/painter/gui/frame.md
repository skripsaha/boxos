# painter::gui::frame

## Назначение

Заголовок: [`painter/gui/frame.h`](../../../../src/userspace/painter/include/painter/gui/frame.h).
Реализация: [`src/gui/frame.cpp`](../../../../src/userspace/painter/src/gui/frame.cpp).

Кадр, описанный целиком. Внутри `Area::Draw` программа каждый раз
описывает всё, что показывает, — так, как создаёт элементы в области
(`Text`, `Rectangle`, `Group`…), — а Painter сравнивает описание с прошлым
кадром и отправляет только разницу одним шагом:

- новое — создаётся;
- изменившееся — говорится;
- то, что элемент больше не говорит, — возвращается к значению роли;
- исчезнувшее — удаляется;
- переставленное среди соседей — переставляется.

Кадр, совпавший с прошлым, не отправляет ничего. Программа, которая не
рисует кадрами, не носит в себе этот код.

Этот способ удобен, когда интерфейс — функция состояния программы
(списки, таблицы, панели настроек): не нужно помнить, какие элементы уже
созданы. Элементы-объекты ([items](items.md)) удобнее, когда меняется
одно-два свойства (часы, счётчик).

## Как находятся элементы

Каждый элемент кадра ищется среди элементов прошлого кадра:

- под тем же родителем, того же вида, на том же месте среди соседей;
- или, если он сказал `Key`, — под тем же родителем, того же вида, с тем же ключом.

Элементы лежат в порядке описания: первый — нижний. Без ключа элемент,
сдвинувшийся в списке, считается другим элементом (меняются его свойства,
а не место), — поэтому строкам списков, которые вставляются, удаляются или
сортируются, давайте ключи.

Роль — часть элемента: если у найденного элемента сменилась роль, она
говорится как изменение.

Структуры сравнения (прошлый кадр, номера, порядок) хранятся между кадрами,
поэтому кадр не выделяет память на них заново.

## Класс Frame

### `Frame`

**Краткое описание:** Описывает один кадр: элементы, созданные в нём, и что они говорят.

**Параметры:** Создаётся только `Area::Draw`, который передаёт его в функцию описания по ссылке.

**Возвращает:** Неприменимо: класс. Копировать нельзя.

**Побочные эффекты:** Нет до окончания `Draw`.

**Как работает:** Методы создания (`Text`, `Rectangle`, `Ellipse`, `Outline`, `Group`, `Picture`) — те же, что у области (`Makes<Frame>`). Возвращённые объекты пишут свойства не в область, а во внутренние `Changes` кадра в режиме «только запоминать». По окончании описания `detail::Drawer` сопоставляет элементы и пишет разницу в изменения области, затем `Area::Draw` вызывает `Present()`.

**Примечания:**
- Объекты элементов кадра действуют только внутри функции описания; хранить их бессмысленно — после `Draw` они ничего не делают.
- В кадре нельзя создать `Canvas` и `Cells` (возвращается пустой объект): их держат как хранимые элементы.
- Хранимые элементы и кадры могут жить в одной области одновременно.
- Анимации работают и в кадре: опишите кадр внутри `Screen.Animate(…, [&] { Screen.Draw(…); })`.

**Типичное применение:** Список, который пересобирается при каждом изменении данных.

**Пример:**
```cpp
#include <string>
#include <vector>

#include "painter/gui/area.h"
#include "painter/gui/frame.h"

struct Task {
    std::uint64_t Id;
    std::string   Title;
    bool          Done;
};

void Draw(painter::gui::Area &Screen, const std::vector<Task> &Tasks)
{
    namespace gui = painter::gui;
    Screen.Draw([&](gui::Frame &F) {
        gui::Group List = F.Group();
        List.SetPlace({16, 16});
        float Y = 0;
        for (const Task &Each : Tasks) {
            gui::Text Line = List.Text(Each.Title, Each.Done ? gui::Role::Hint : gui::Role::Body);
            Line.Key(Each.Id).SetPlace({0, Y});
            if (Each.Done) {
                gui::TextStyle Crossed;
                Crossed.Strike = true;
                Line.SetStyle(Crossed);
            }
            Y += 24;
        }
    });
}
```

### `detail::Drawer` (внутренний)

**Краткое описание:** Хранит прошлый кадр и записывает разницу с новым.

**Параметры:**
- `Where` (`std::shared_ptr<detail::Anchor>`): куда писать изменения и откуда брать номера.

**Возвращает:** Неприменимо: класс. `Begin()` возвращает новый `Frame`, `End()` сопоставляет и пишет разницу.

**Побочные эффекты:** `End` пишет создания, удаления, перестановки и свойства в изменения якоря.

**Как работает:** Найденный элемент сохраняет свой номер в области; его свойства сравниваются байт в байт с запомненными (`Changes::Say`); несказанные теперь свойства сбрасываются (`Reset`). Ненайденные элементы прошлого кадра удаляются, новые получают номера из пула области.

**Примечания:** Используется `Area::Draw` и стендом проверки Painter; программе напрямую не нужен.

**Пример:** Не приводится: внутренний класс.
