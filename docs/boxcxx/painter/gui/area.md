# painter::gui::area

## Назначение

Заголовок: [`painter/gui/area.h`](../../../../src/userspace/painter/include/painter/gui/area.h).
Реализация: [`src/gui/area.cpp`](../../../../src/userspace/painter/src/gui/area.cpp),
кадры — [`src/gui/area_frames.cpp`](../../../../src/userspace/painter/src/gui/area_frames.cpp).

`Area` — область программы на экране и всё, что в ней показано. Через неё
создаются элементы ([items](items.md)), уходят изменения (`Present`),
приходят ответы дисплея и клавиши (`Wait`, `Next`), открываются блоки
памяти для картинок, холстов и шрифтов.

Устройство обмена: дисплей создаёт для области общую память (Bay) с двумя
кольцами. В первое программа пишет записи изменений и в конце шага —
запись `ITEM_OP_STEP`, затем одним сообщением (`DISP_CMD_AREA_STEP`)
говорит дисплею, что шаг готов. Во второе дисплей пишет события: размер
области, размер элемента по содержимому, отказ, показанный шаг,
освободившуюся страницу холста, конец анимации, фокус, нажатие, текст
поля. О новых событиях дисплей сообщает Touch-сигналом (`Bell()`).

`Area` наследует [Changes](changes.md) (все методы свойств по номеру
элемента) и `Makes<Area>` (создание элементов-объектов).

## Типы

### `Placement`

**Краткое описание:** Называет, где программа хочет видеть область.

**Параметры:**
- `Over` (= `DISPLAY_AREA_OVER`): поверх всего, желаемого размера, место выбирает дисплей.
- `Whole` (= `DISPLAY_AREA_WHOLE`): весь экран, пока программа впереди.
- `Flow` (= `DISPLAY_AREA_FLOW`): в потоке консоли от строки курсора, шириной с консоль и желаемой высоты; консоль освобождает место, её текст продолжается ниже, а область прокручивается вместе с ней.

**Возвращает:** Неприменимо: перечисление `std::uint8_t`.

**Побочные эффекты:** Нет.

**Как работает:** Порядок снизу вверх: консоль, области в её потоке, области на весь экран, области поверх всего, области «всегда» — внутри каждого слоя по возрасту.

**Пример:** См. `Area::Open`.

### `Glass`

**Краткое описание:** Называет вид стекла области.

**Параметры:**
- `Text` (= `ITEM_GLASS_TEXT`): текстовая страница; текст пишется в ячейки 8×16 точек, остальные элементы видны подписью.
- `Pixels` (= `ITEM_GLASS_PIXELS`): framebuffer.

**Возвращает:** Неприменимо: перечисление.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "painter/gui/area.h"

bool Pixels(const painter::gui::Area &Screen) { return Screen.On() == painter::gui::Glass::Pixels; }
```

### `Event`

**Краткое описание:** Описывает то, что сообщил дисплей, или то, что услышал `Wait`.

**Параметры:**
- `What` (`Event::Kind`): вид события (ниже).
- `Item` (`std::uint32_t`): элемент, к которому относится событие (или блок для `PageFree`).
- `Size` (`core::PointF`): размер области (`Area`) или элемента (`Size`), в точках.
- `Scale` (`float`): пикселей на точку (`Area`).
- `On` (`gui::Glass`): вид стекла (`Area`).
- `Seen` (`bool`): область видна, а не позади (`Area`).
- `LessMotion` (`bool`), `MotionSpeed` (`std::uint32_t`, проценты): как человек хочет движения (`Area`).
- `Op`, `Property` (`std::uint16_t`), `Reason` (`error_t`): какая операция и какое свойство отвергнуты и почему (`Refused`).
- `Step` (`std::uint64_t`), `Micros`, `Pixels`, `Bytes`, `Records`, `Own` (`std::uint32_t`): номер показанного шага и его цена — микросекунды компоновки, пиксели, байты и записи; `Own` — пиксели, которые потребовали изменения этой области (`Shown`).
- `Page` (`std::uint32_t`): освободившаяся страница холста (`PageFree`).
- `Number` (`std::uint32_t`), `Finished` (`bool`): номер анимации и признак, что все её части дошли до конца, ни одна не прервана (`AnimationEnd`).
- `Came` (`bool`): фокус пришёл к элементу (`true`) или ушёл (`Focus`).
- `Text` (`std::string`): текст поля в UTF-8 так, как его отредактировал человек (`Text`).
- `Key` (`tui::KeyEvent`): клавиша (`Key`).
- `Moment` (`std::uint64_t`): время будильника в микросекундах от запуска (`Alarm`).

Виды `Event::Kind`:
- `Area` — размер, масштаб, стекло области или её видимость изменились (приходит и при изменении настроек движения).
- `Size` — элемент с размером по содержимому получил размер.
- `Refused` — изменение не принято.
- `Shown` — шаг показан на стекле.
- `PageFree` — страница холста снова свободна.
- `Key` — клавиша (только при `Wait` с клавиатурой).
- `Alarm` — сработал будильник потока (`box/alarm.h`).
- `Gone` — клавиатуры больше нет, ввод закончен.
- `EndAsked` — программу просят завершиться (если клавиатура объявила `HearEnd`).
- `AnimationEnd` — закончилась последняя анимация с данным `Number`.
- `Focus` — фокус клавиатуры пришёл к элементу или ушёл.
- `Press` — человек нажал элемент (Enter или Space на нём, или его меткой).
- `Text` — текст поля после правки человеком.

**Возвращает:** Неприменимо: агрегат.

**Побочные эффекты:** Нет.

**Примечания:** Поля, не относящиеся к виду события, имеют значения по умолчанию.

**Пример:** См. `Area::Wait`.

## Класс Area

### `Area`

**Краткое описание:** Владеет областью дисплея, её элементами и обменом с дисплеем.

**Параметры:** Создаётся через `Area::Open`.

**Возвращает:** Неприменимо: класс.

**Побочные эффекты:** Пока объект жив, область открыта; деструктор закрывает её (`DISP_CMD_AREA_CLOSE`), и дисплей убирает все её элементы.

**Как работает:** Объекты элементов держат общий «якорь» области. При перемещении `Area` якорь перенаправляется на новый объект, при уничтожении — обнуляется: объекты, пережившие область, ничего не делают.

**Примечания:** Копировать и перемещающе присваивать нельзя. Перемещающий конструктор есть, но **не переносит `LessMotion()` и `MotionSpeed()`**: после перемещения они имеют значения по умолчанию (`false`, 100), пока не придёт событие `Area`. Поэтому держите область в `std::expected`, который вернул `Open`, и работайте через ссылку (`gui::Area &Screen = *Opened;`). Областью говорит один поток — тот, что её открыл.

**Пример:** См. [README](README.md), «Первая программа».

### `Area::Open`

**Краткое описание:** Просит у дисплея область.

**Параметры:**
- `Where` (`Placement`): где.
- `Wish` (`core::PointF`): желаемый размер в точках; 0 по стороне — на выбор дисплея. По умолчанию `{}`.
- `Always` (`bool`): видна и тогда, когда программа позади (часы в углу, спутник). По умолчанию `false`.

**Возвращает:** (`std::expected<Area, box::error>`) открытая область или ошибка: ошибка запроса к дисплею, ошибка, которую вернул дисплей, `errc::corrupted` — ответ или общая память не прошли проверку, `errc::tag_not_found` — память области не открылась.

**Побочные эффекты:** Запрос `DISP_CMD_AREA_OPEN`; открывает общую память; начинает слушать Touch-сигнал области.

**Как работает:** Из ответа берутся номер области, размер в точках, масштаб, вид стекла, точные мозаики ячеек, настройки движения и место курсора консоли на момент открытия (после всего, что программа напечатала раньше). Вместе с запросом уходит метка порядка консоли, поэтому область в потоке встаёт после уже напечатанного текста.

**Примечания:** Размер, который выбрал дисплей, может отличаться от желаемого; читайте `Size()` и следите за событиями `Area`. У одной программы одновременно открыто не больше `ITEM_AREAS_MOST` (16) областей.

**Пример:**
```cpp
#include "painter/gui/area.h"

int Run()
{
    auto Opened = painter::gui::Area::Open(painter::gui::Placement::Flow, {0, 120});
    if (!Opened) return 1;
    painter::gui::Area &Screen = *Opened;
    painter::gui::Text Line = Screen.Text("В потоке консоли");   // объект держит элемент
    Line.SetPlace({8, 8});
    Screen.PresentAll();
    return 0;
}
```

### `Area::Present`

**Краткое описание:** Кладёт накопленные изменения в кольцо одним шагом и сообщает о нём дисплею, не дожидаясь места.

**Параметры:** Нет.

**Возвращает:** (`bool`) `true`, если ушло всё; `false`, если кольцо заполнено (остаток ждёт следующего `Present`) или область закрыта.

**Побочные эффекты:** Пишет записи в кольцо; при записи хотя бы одной — увеличивает номер шага (`Step()`) и отправляет `DISP_CMD_AREA_STEP`.

**Как работает:** Порядок: сначала создания, удаления и перестановки в том порядке, как сказаны; затем каждое свойство с его последним словом; затем изменившиеся отрезки сеток ячеек. Запись попадает в кольцо, только если после неё остаётся место для конца шага. Шаг уходит целиком; лишь шаг, который один больше кольца, делится на части.

**Примечания:** Ничего не изменилось — ничего не уходит, возвращается `true`. Анимации требуют `Present` так же, как обычные изменения.

**Типичное применение:** После каждой порции изменений в цикле событий.

**Пример:**
```cpp
#include "painter/gui/area.h"
#include "painter/gui/items.h"

void Tick(painter::gui::Area &Screen, painter::gui::Text &Clock, std::string_view Now)
{
    Clock.SetText(Now);
    (void)Screen.Present();
}
```

### `Area::PresentAll`

**Краткое описание:** Кладёт в кольцо все накопленные изменения, дожидаясь места.

**Параметры:** Нет.

**Возвращает:** `void`.

**Побочные эффекты:** Может блокировать поток, пока дисплей не прочитает кольцо.

**Как работает:** Повторяет `Present`, пока всё не уйдёт, ожидая Touch-сигнала дисплея (он звонит, показав шаг). На время ожидания включает слух области, если тот был выключен.

**Примечания:** Программа, которая никогда не читает события, должна забирать их (`Next()`) перед ожиданием — иначе у дисплея нет места сказать и позвонить.

**Типичное применение:** Последний шаг перед `Commit` или перед выходом; программы, которым важно, чтобы шаг ушёл полностью (ячейки `painter::tui`).

**Пример:**
```cpp
#include "painter/gui/area.h"

void Flush(painter::gui::Area &Screen)
{
    while (Screen.Next()) {
    }
    Screen.PresentAll();
}
```

### `Area::Commit`

**Краткое описание:** Вкладывает сетки ячеек области в текст консоли и закрывает область.

**Параметры:**
- `ScrollRows` (`std::uint32_t`): на сколько строк прокрутить консоль перед вкладыванием; по умолчанию 0.

**Возвращает:** (`box::status`) успех; `errc::invalid_state` — область уже закрыта; ошибка запроса; ошибка дисплея.

**Побочные эффекты:** Разбирает ждущие события, отправляет всё накопленное (`PresentAll`), затем запрос `DISP_CMD_AREA_COMMIT`. При успехе область закрыта.

**Примечания:** Вкладываются только элементы-сетки; область с чем-то ещё дисплей не вложит. Этим пользуется `painter::tui::ConsoleSurface`.

**Пример:**
```cpp
#include "painter/gui/area.h"

bool Keep(painter::gui::Area &Screen) { return Screen.Commit().has_value(); }
```

### `Area::Next`

**Краткое описание:** Возвращает самое старое непрочитанное событие дисплея, не ожидая.

**Параметры:** Нет.

**Возвращает:** (`std::optional<Event>`) событие или пусто.

**Побочные эффекты:** Сдвигает указатель чтения кольца событий; события, отложенные во время ожидания страницы холста, отдаются первыми.

**Как работает:** Событие `Refused` для изменения свойства заставляет Painter забыть это свойство как сказанное: повторённое, оно уйдёт снова. Событие `Text` запоминает текст поля как уже сказанный: программа, сказав его ещё раз, ничего не отправит.

**Пример:**
```cpp
#include "painter/gui/area.h"

int Refusals(painter::gui::Area &Screen)
{
    int Count = 0;
    while (auto Told = Screen.Next())
        if (Told->What == painter::gui::Event::Kind::Refused) Count++;
    return Count;
}
```

### `Area::Wait`

**Краткое описание:** Ждёт, что произойдёт дальше: событие дисплея, клавишу или будильник.

**Параметры:**
- `Keys` (`tui::Keyboard *`): клавиатура, клавиши которой тоже ждать; `nullptr` — без клавиш.

**Возвращает:** (`Event`) первое, что произошло.

**Побочные эффекты:** Блокирует поток без таймаута. Включает слух области навсегда.

**Как работает:** В цикле: ставит метку, собирает все события дисплея, отдаёт первое; иначе опрашивает клавиатуру (`Key`, `Gone`, `EndAsked`); иначе проверяет будильник потока (`alarm_heard_us`); иначе засыпает до следующего сигнала. Таймаута нет: программа, которой нужно время, ставит будильник (`box/alarm.h`) и получает `Event::Kind::Alarm`.

**Типичное применение:** Главный цикл программы.

**Пример:**
```cpp
#include "painter/gui/area.h"
#include "painter/tui/keyboard.h"

int Loop(painter::gui::Area &Screen, painter::tui::Keyboard &Keys)
{
    namespace gui = painter::gui;
    for (;;) {
        const gui::Event Heard = Screen.Wait(&Keys);
        switch (Heard.What) {
        case gui::Event::Kind::Gone:
        case gui::Event::Kind::EndAsked: return 0;
        case gui::Event::Kind::Area: /* разложить заново под Heard.Size */ break;
        case gui::Event::Kind::Key:
            if (Heard.Key.Character == painter::tui::KeyCodes::Escape) return 0;
            break;
        default: break;
        }
        (void)Screen.Present();
    }
}
```

### `Area::Draw`

**Краткое описание:** Описывает кадр целиком и отправляет только его отличие от прошлого кадра.

**Параметры:**
- `Describe` (вызываемый объект `void(gui::Frame &)`): описывает все элементы кадра.

**Возвращает:** `void`.

**Побочные эффекты:** Сравнивает кадр с прошлым, записывает разницу в изменения и вызывает `Present()`.

**Примечания:** Подробности — [frame](frame.md). Программа, не вызывающая `Draw`, не носит в себе код сравнения кадров.

**Пример:** См. [README](README.md), «Кадр целиком».

### Создание элементов: `Text`, `Rectangle`, `Ellipse`, `Outline`, `Group`, `Picture`, `Canvas`, `Cells`

**Краткое описание:** Создают элементы-объекты прямо в области.

**Параметры:** См. `Makes` в [items](items.md).

**Возвращает:** Объект элемента.

**Побочные эффекты:** Записывают создание элемента.

**Примечания:** У `Area` одноимённые методы есть и в `Changes` — они меняют свойство уже существующего элемента по номеру (`Screen.Text(Number, "…")`). Перегрузки различаются аргументами.

**Пример:**
```cpp
#include "painter/gui/area.h"
#include "painter/gui/items.h"

painter::gui::Text Title(painter::gui::Area &Screen) { return Screen.Text("Заголовок", painter::gui::Role::Heading); }
```

### `Area::Bell` / `Area::Listen`

**Краткое описание:** Возвращают Touch-тег, которым звонит дисплей, и включают или выключают его слух.

**Параметры:**
- `On` (`bool`): для `Listen` — слушать или нет.

**Возвращает:** `Bell` — (`TouchTag`) тег или `TOUCH_TAG_INVALID`, если не слушается; `Listen` — `void`.

**Побочные эффекты:** `Listen(false)` забирает уже пришедшие сигналы и освобождает тег.

**Как работает:** Область слушается с открытия. Программа, которая никогда не ждёт на нём, выключает слух: Touch, который никто не забирает, не даёт потоку уснуть.

**Пример:**
```cpp
#include "painter/gui/area.h"

void Quiet(painter::gui::Area &Screen) { Screen.Listen(false); }
```

### `Area::Step`

**Краткое описание:** Возвращает номер последнего шага, положенного в кольцо.

**Параметры:** Нет.

**Возвращает:** (`std::uint64_t`) номер; этот номер назовёт событие `Shown`, когда шаг окажется на стекле.

**Побочные эффекты:** Нет.

**Типичное применение:** Замер задержки: запомнить `Step()` после `Present` и ждать `Shown` с тем же номером.

**Пример:**
```cpp
#include "painter/gui/area.h"

bool Arrived(const painter::gui::Area &Screen, const painter::gui::Event &Heard)
{
    return Heard.What == painter::gui::Event::Kind::Shown && Heard.Step == Screen.Step();
}
```

### `Area::Size` / `Scale` / `On` / `Id` / `Mosaics` / `ConsoleCaret`

**Краткое описание:** Возвращают размер области, масштаб, вид стекла, номер, точные мозаики ячеек и место курсора консоли на момент открытия.

**Параметры:** Нет.

**Возвращает:**
- `Size` — (`core::PointF`) размер в точках.
- `Scale` — (`float`) пикселей на точку.
- `On` — (`gui::Glass`).
- `Id` — (`std::uint32_t`) номер области у дисплея.
- `Mosaics` — (`std::uint8_t`) флаги `ITEM_MOSAIC_*`.
- `ConsoleCaret` — (`core::Point`) столбец и строка курсора консоли при открытии.

**Побочные эффекты:** Нет.

**Как работает:** Размер, масштаб и стекло обновляются, когда `Next`/`Wait` читает событие `Area`.

**Примечания:** У `Size` и `Scale` есть одноимённые методы `Changes` с аргументами — они задают размер и масштаб элемента.

**Пример:**
```cpp
#include "painter/gui/area.h"

float WidthInPixels(const painter::gui::Area &Screen) { return Screen.Size().X * Screen.Scale(); }
```

### `Area::LessMotion` / `Area::MotionSpeed`

**Краткое описание:** Возвращают, как человек хочет движения.

**Параметры:** Нет.

**Возвращает:** `LessMotion` — (`bool`) человек просит меньше движения; `MotionSpeed` — (`std::uint32_t`) скорость всех анимаций в процентах.

**Побочные эффекты:** Нет.

**Примечания:** Анимации, которые проигрывает дисплей, уже учитывают оба значения. Эти методы нужны тому, кто двигает что-то сам (например, перерисовывает холст по будильнику): при `LessMotion` такое движение должно происходить сразу. Обновляются событием `Area`. См. примечание к классу о перемещении.

**Пример:**
```cpp
#include <chrono>

#include "painter/gui/area.h"

std::chrono::milliseconds Pace(const painter::gui::Area &Screen, std::chrono::milliseconds Wanted)
{
    if (Screen.LessMotion()) return std::chrono::milliseconds{0};
    return Wanted * 100 / static_cast<long long>(Screen.MotionSpeed() ? Screen.MotionSpeed() : 100);
}
```

### `Area::OpenPicture`

**Краткое описание:** Открывает блок памяти под картинку заданного размера.

**Параметры:**
- `Width`, `Height` (`std::uint32_t`): размер в пикселях.

**Возвращает:** (`std::expected<PictureBlock, box::error>`) блок или ошибка дисплея / `corrupted` / `tag_not_found`.

**Побочные эффекты:** Запрос `DISP_CMD_BLOCK_OPEN`; общая память, которую дисплей создал для программы.

**Примечания:** Пиксели заполняются через `PictureBlock::Pixels()` (RGBA, непрозрачность не умножена). Изменения после показа сообщают `BlockChanged`. Пределы: `ITEM_BLOCKS_MOST` (1024) блоков, `ITEM_BLOCK_BYTES_MOST` (64 МиБ) на блок, `ITEM_BLOCKS_BYTES_MOST` (256 МиБ) всего. Подробности — [blocks](blocks.md).

**Пример:** См. [blocks](blocks.md).

### `Area::OpenCanvas`

**Краткое описание:** Открывает блок с двумя страницами пикселей для холста.

**Параметры:**
- `Width`, `Height` (`std::uint32_t`): размер в пикселях.

**Возвращает:** (`std::expected<CanvasBlock, box::error>`) блок или ошибка.

**Побочные эффекты:** Как у `OpenPicture`.

**Примечания:** Обычно не нужен напрямую: `Area::Canvas(size)` создаёт и блок, и элемент, и ведёт страницы сам.

**Пример:**
```cpp
#include "painter/gui/area.h"

bool HasRoom(painter::gui::Area &Screen) { return Screen.OpenCanvas(64, 64).has_value(); }
```

### `Area::OpenFont`

**Краткое описание:** Передаёт дисплею свой шрифт для текстов программы.

**Параметры:**
- `Bytes` (`std::span<const std::uint8_t>`): файл шрифта целиком (TrueType/OpenType).

**Возвращает:** (`std::expected<std::uint32_t, box::error>`) номер блока или ошибка.

**Побочные эффекты:** Открывает блок, копирует в него байты, сообщает об изменении блока (дисплей прочитает шрифт со следующим шагом). Если программа измеряет текст (`Measure`), шрифт добавляется и в её собственную книгу шрифтов.

**Примечания:** Семейство шрифта затем называют в `TextStyle::Family`. Файл шрифта с диска читает `core::ReadFontFile`.

**Пример:**
```cpp
#include "painter/core/system_fonts.h"
#include "painter/gui/area.h"

bool UseOwnFont(painter::gui::Area &Screen)
{
    auto Bytes = painter::core::ReadFontFile("Inter-Bold.ttf");
    return Bytes && Screen.OpenFont(*Bytes).has_value();
}
```

### `Area::CloseBlock`

**Краткое описание:** Закрывает блок памяти.

**Параметры:**
- `Block` (`std::uint32_t`): номер блока.

**Возвращает:** `void`.

**Побочные эффекты:** Сообщение `DISP_CMD_BLOCK_CLOSE`.

**Примечания:** Объект `gui::Canvas` закрывает свой блок сам.

**Пример:**
```cpp
#include "painter/gui/area.h"

void Drop(painter::gui::Area &Screen, std::uint32_t Block) { Screen.CloseBlock(Block); }
```
