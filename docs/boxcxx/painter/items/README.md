# painter::items (внутренний)

## Назначение

`painter::items` — общая часть дисплея и `painter::gui`: чтение языка
элементов (`box/items.h`), внешний вид ролей по теме, промежуточные
значения для анимаций и раскладка текстового элемента. Один код для того,
кто рисует (дисплей), и того, кто измеряет заранее (`gui::Measure`), —
поэтому они никогда не расходятся.

Программам эти заголовки напрямую не нужны: элементы описываются через
[painter::gui](../gui/README.md). Страницы здесь — для тех, кто
сопровождает дисплей и Painter, и для тех, кто хочет точно знать, как
выглядит роль по умолчанию.

## Модули

- [properties](properties.md) — `Properties` и разбор байтов свойства с проверкой каждого числа.
- [look](look.md) — `Theme`: как выглядит каждая роль; порядок «система < тема < программа < человек».
- [between](between.md) — числа между двумя значениями свойства для анимации.
- [text](text.md) — `LayText`: текстовый элемент, разложенный так, как его кладёт дисплей.

Исходники: `include/painter/items/*.h`, `src/items/*.cpp` в
[src/userspace/painter](../../../../src/userspace/painter/README.md).
