# painter::tui::text — текст в ячейках

## Назначение

Модуль измеряет текст, выбирает помещающийся префикс, сокращает строки и
записывает их в `painter::tui::Frame`. Входные строки содержат байты UTF-8;
каждая ячейка результата хранит один символ Unicode.

Painter — семейство графических API. Общие типы координат и цвета находятся
в `painter::core`, текстовая и псевдографическая отрисовка — в `painter::tui`.
`painter::gui` обозначает направление для пиксельного GUI; в текущем дереве
его реализации нет. Этот модуль относится к `painter::tui`.

Заголовок: [`painter/tui/text.h`](../../../../src/userspace/painter/include/painter/tui/text.h).
Реализация: [`text.cpp`](../../../../src/userspace/painter/src/tui/text.cpp).
Глиф для символа выбирает дисплей при рисовании. На кадровом буфере —
наборщик дисплея (Typecase): рамки, блоки, мозаики и брайль вычисляются под
клетку, буквы берутся из шрифта, названного в настройках дисплея (по умолчанию
JetBrains Mono, с кириллицей), затем из шрифта 8×16; символ, которого нет
нигде, рисуется своим кодом в клетке. На текстовой странице VGA — шрифт
видеокарты через таблицу
[`boxos_glyph_fold.h`](../../../../src/include/boxos_glyph_fold.h); символ без
глифа там — сплошной квадрат ■.

Подключение: `#include "painter/tui/text.h"`. Функции находятся в пространстве
имён `painter::tui` и входят в `src/userspace/painter/libpainter.a`.
Примеры ниже рассчитаны на C++23 и заголовки BoxOS `boxcxx` и `boxlib`.

## Байты, кодовые точки и ячейки

Размер строки в байтах не определяет её ширину на экране. `Length` описывает
число прочитанных байтов, `Width` — число занимаемых ячеек. Координаты
`core::Point` в этом модуле также измеряются в ячейках: `X` — столбец,
`Y` — строка; начало координат кадра — `{0, 0}`.

| Вход | Обработка | Ячейки | `Odd` |
| --- | --- | --- | --- |
| Печатный ASCII, U+0020–U+007E | Сам символ | 1 | `false` |
| `é` (U+00E9) | Одна ячейка с U+00E9 | 1 | `false` |
| `≠` (U+2260) | Одна ячейка с U+2260; замены `!=` нет | 1 | `false` |
| Любая другая корректная кодовая точка от U+00A0 | Сама кодовая точка | 1 | `false` |
| Табуляция `\t` | Пробелы до следующего шага табуляции | 1–4 | `false` |
| U+0000–U+001F, кроме табуляции, U+007F и U+0080–U+009F | U+FFFD | 1 | `true` |
| Недопустимый байт UTF-8 | U+FFFD, продвижение на один байт | 1 | `true` |

`TabStop` — константа типа `std::size_t`, равная `4`. Табуляция занимает
`TabStop - Column % TabStop` ячеек: на границе шага она занимает четыре
ячейки, а не ноль. `CellsOf`, `BytesWithin` и `PutText` начинают отсчёт
столбцов с нуля для каждого вызова. В `PutText` этот отсчёт не зависит от
`At.X`; два последовательных вызова не разделяют состояние табуляции.

`OddInk` — константа типа `core::Color` со значением
`core::Color::Rgb(0xE0, 0x9A, 0x30)`. `PutText` использует её для элементов
с `Odd == true`. Корректно закодированный символ, которого нет в шрифтах
дисплея, ячейка хранит как есть, а дисплей рисует обычным цветом `Ink`: на
кадровом буфере — его кодом в клетке, на текстовой странице VGA — квадратом.

Декодер отвергает оборванные последовательности, лишние байты продолжения,
избыточные кодировки, суррогаты и значения выше U+10FFFF. Он не объединяет
кодовые точки в графемы и не выполняет нормализацию. Комбинируемые знаки
обрабатываются отдельно: каждый занимает свою ячейку.

Модуль не разбирает ANSI-последовательности и не переносит строки.
`\n` и `\r` становятся U+FFFD, а не командами перемещения курсора.
Нулевой байт внутри явно заданного `std::string_view` также обрабатывается
как управляющий символ, а не как конец текста.

## Константы

### `TabStop`

**Краткое описание:** Используйте шаг табуляции модуля.

**Параметры:** Нет; `inline constexpr std::size_t TabStop = 4`.

**Возвращает:** Неприменимо: константа.

**Побочные эффекты:** Нет.

**Пример:**

```cpp
#include "painter/tui/text.h"

namespace tui = painter::tui;
namespace core = painter::core;

std::size_t Stop = tui::TabStop;
```

### `OddInk`

**Краткое описание:** Используйте цвет управляющего или недопустимого элемента текста.

**Параметры:** Нет; `inline constexpr core::Color OddInk = core::Color::Rgb(0xE0, 0x9A, 0x30)`.

**Возвращает:** Неприменимо: константа.

**Побочные эффекты:** Нет.

**Примечания:** Неизвестная, но корректная кодовая точка Unicode не получает признак Odd и не выбирает этот цвет автоматически.

**Пример:**

```cpp
#include "painter/tui/text.h"

namespace tui = painter::tui;
namespace core = painter::core;

core::Color Ink = tui::OddInk;
```

## Справочник

### `Glyph`

**Краткое описание:** Используйте структуру для представления одного элемента текста в ячейках BoxOS.

**Поля:**

| Поле | Тип | Значение по умолчанию | Назначение |
| --- | --- | --- | --- |
| `Length` | `std::size_t` | `1` | Число байтов входа, на которое следует продвинуться |
| `Width` | `std::size_t` | `1` | Число ячеек, занимаемых элементом |
| `Character` | `char32_t` | `U' '` | Символ, который хранит каждая из `Width` ячеек |
| `Odd` | `bool` | `false` | Признак управляющего символа или недопустимого байта UTF-8; тогда `Character` — U+FFFD |

**Параметры:** У агрегата нет пользовательского конструктора; поля можно
задать агрегатной инициализацией.

**Возвращает:** Неприменимо: структура данных.

**Побочные эффекты:** Нет.

**Как работает:** `GlyphAt` заполняет структуру по одному элементу входа.
У корректной последовательности `Length` равен числу её байтов; у ошибки
он остаётся равным одному. Каждая из `Width` ячеек элемента хранит
`Character`; у табуляции это пробел `U' '`.

**Примечания:** При самостоятельном обходе записывайте `Character` в
каждую из `Width` ячеек; отдельно распознавать табуляцию не нужно.

**Типичное применение:** Получайте структуру через `GlyphAt` для обхода
строки с одновременным учётом байтового смещения и экранного столбца.

**Пример:**

```cpp
#include "painter/tui/text.h"

int main()
{
    const painter::tui::Glyph Shape{};
    return Shape.Length == 1 && Shape.Width == 1 && !Shape.Odd ? 0 : 1;
}
```

### `GlyphAt`

```cpp
Glyph GlyphAt(std::string_view Text, std::size_t Byte,
              std::size_t Column = 0) noexcept;
```

**Краткое описание:** Получите представление элемента текста по байтовому смещению и текущему столбцу.

**Параметры:**

- `Text` (`std::string_view`, in): входные байты; завершающий нуль не требуется.
- `Byte` (`std::size_t`, in): смещение начала элемента; обязательно `Byte < Text.size()`.
- `Column` (`std::size_t`, in): текущий столбец для расчёта табуляции; по умолчанию `0`.

**Возвращает:** `Glyph` с длиной входного элемента, шириной и символом.

**Побочные эффекты:** Нет; память не выделяется.

**Как работает:** Табуляция обрабатывается до декодирования UTF-8.
Для остальных байтов функция декодирует одну кодовую точку; она и
становится `Character` при ширине 1. Недопустимый UTF-8, управляющие
символы C0, DEL и C1 дают U+FFFD с `Odd == true`. Замены и свёртки в глифы
нет: кодовая точка, которой нет в шрифте дисплея, остаётся сама собой и
не получает этот признак.

**Примечания:** Функция не проверяет границы `Byte`; для пустого текста
вызывать её нельзя. Если `Byte` указывает внутрь многобайтовой
последовательности, байт продолжения обрабатывается как отдельная ошибка.
Значение `Column` влияет только на табуляцию.

**Типичное применение:** После вызова увеличивайте байтовое смещение на
`Length`, а столбец — на `Width`; продолжайте, пока смещение меньше размера
входа.

**Пример:**

```cpp
#include "painter/tui/text.h"

int main()
{
    const auto Shape = painter::tui::GlyphAt("\u2260", 0);
    return Shape.Length == 3 && Shape.Width == 1 &&
           Shape.Character == U'\u2260' && !Shape.Odd ? 0 : 1;
}
```

### `CellsOf`

```cpp
std::size_t CellsOf(std::string_view Text) noexcept;
```

**Краткое описание:** Вычислите ширину текста в ячейках при отсчёте столбцов с нуля.

**Параметры:**

- `Text` (`std::string_view`, in): измеряемые байты.

**Возвращает:** `std::size_t` — сумму ширин элементов; `0` для пустого текста.

**Побочные эффекты:** Нет; память не выделяется.

**Как работает:** Функция проходит весь вход через `GlyphAt`, передавая
накопленную ширину как `Column`. Байтовое смещение увеличивается на
`Length`, ширина — на `Width`, поэтому многобайтовые символы и табуляция
измеряются по тем же правилам, что и при `PutText`.

**Примечания:** Функция измеряет одну последовательность ячеек, даже если
вход содержит переводы строк. Суммирование ширины не проверяет переполнение
`std::size_t`.

**Типичное применение:** Используйте для выравнивания надписей и расчёта
места перед вызовом `PutText`. Для строк с табуляцией сумма результатов
отдельных измерений может отличаться от ширины объединённой строки.

**Пример:**

```cpp
#include "painter/tui/text.h"

int main()
{
    // A: 1, табуляция: 3, ≠: 1.
    return painter::tui::CellsOf("A\t\u2260") == 5 ? 0 : 1;
}
```

### `BytesWithin`

```cpp
std::size_t BytesWithin(std::string_view Text, std::size_t Cells) noexcept;
```

**Краткое описание:** Найдите длину префикса в байтах, который помещается в заданное число ячеек.

**Параметры:**

- `Text` (`std::string_view`, in): исходные байты.
- `Cells` (`std::size_t`, in): допустимая ширина в ячейках от столбца `0`.

**Возвращает:** `std::size_t` — число байтов префикса от `0` до
`Text.size()`; `0` для пустого текста или нулевого бюджета.

**Побочные эффекты:** Нет; память не выделяется.

**Как работает:** Функция последовательно получает элементы через
`GlyphAt`. Если следующий элемент целиком превышает оставшуюся ширину,
обход заканчивается перед ним. Корректная последовательность UTF-8 и
табуляция не делятся на части.

**Примечания:** Недопустимый UTF-8 уже считается отдельными ошибочными
байтами, поэтому функция не исправляет вход и не гарантирует корректный
UTF-8 в результате. Сложение накопленной ширины с шириной следующего
элемента не проверяет переполнение `std::size_t`.

**Типичное применение:** Передавайте результат в `Text.substr(0, Bytes)`
для обрезки без многоточия. Если нужен признак сокращения, используйте
`Shortened`.

**Пример:**

```cpp
#include "painter/tui/text.h"

int main()
{
    const std::string_view Text = "A\u2260B";
    // A и ≠ — две ячейки и четыре байта; B уже не помещается.
    const auto Bytes = painter::tui::BytesWithin(Text, 2);
    return Bytes == 4 && Text.substr(0, Bytes) == "A\u2260" ? 0 : 1;
}
```

### `Shortened`

```cpp
std::string Shortened(std::string_view Text, std::size_t Width);
```

**Краткое описание:** Получите копию текста с многоточием при превышении заданной ширины.

**Параметры:**

- `Text` (`std::string_view`, in): исходные байты.
- `Width` (`std::size_t`, in): максимальная ширина результата в ячейках.

**Возвращает:** `std::string` — исходный текст, если он помещается;
иначе префикс с тремя ASCII-точками, а при `Width <= 3` — `Width` точек.
При `Width == 0` результат пуст.

**Побочные эффекты:** Создаёт строку; её хранение может потребовать
выделения памяти. Исключения строковых операций передаются вызывающему коду.

**Как работает:** Сначала `CellsOf` измеряет весь вход. Если требуется
сокращение и `Width > 3`, функция резервирует три ячейки под `...`,
выбирает префикс через `BytesWithin(Text, Width - 3)` и добавляет точки.
Из-за неделимости элементов результат может занять меньше `Width` ячеек;
пробелами он не дополняется.

**Примечания:** Результат сохраняет исходные байты префикса, включая
табуляции и ошибки UTF-8; преобразование в ячейки здесь не выполняется.
Условие `Width <= 3` применяется только при сокращении: например,
`Shortened("A", 2)` возвращает `"A"`, а не `".."`.

**Типичное применение:** Для надписи ограниченной ширины сначала вызовите
`Shortened`, затем передайте результат в `PutText`.

**Пример:**

```cpp
#include "painter/tui/text.h"

int main()
{
    const auto Label = painter::tui::Shortened("abcdef", 5);
    return Label == "ab..." ? 0 : 1;
}
```

### `PutText`

```cpp
std::int32_t PutText(Frame &Out, core::Point At, std::string_view Text,
                     std::int32_t Width, core::Color Ink, core::Color Under);
```

**Краткое описание:** Запишите текст в одну строку кадра с ограничением ширины в ячейках.

**Параметры:**

- `Out` (`Frame &`, in-out): кадр, ячейки которого изменяются.
- `At` (`core::Point`, in): начальные столбец и строка в координатах кадра.
- `Text` (`std::string_view`, in): входные байты UTF-8.
- `Width` (`std::int32_t`, in): бюджет ячеек от `At.X`, а не конечный столбец.
- `Ink` (`core::Color`, in): цвет глифов без признака `Odd`.
- `Under` (`core::Color`, in): фон каждой записываемой ячейки.

**Возвращает:** `std::int32_t` — ширину обработанного префикса до отсечения
границами кадра. Для пустого текста и `Width <= 0` возвращает `0`.
Это не число успешно изменённых ячеек.

**Побочные эффекты:** Заменяет ячейки `Out`, до которых доходит вывод;
новые ячейки имеют `Visibility::Opaque` и `CellMark::None`. Фон заменяется
на `Under`, цвет ошибочных элементов — на `OddInk`. Остаток строки кадра
не очищается. Позиция `Frame::Caret()` не изменяется; память не выделяется,
вывод на экран сам по себе не выполняется.

**Как работает:** Локальный столбец начинается с `0`; `GlyphAt` получает
его для расчёта табуляции. Если очередной элемент превышает `Width`, он
целиком пропускается вместе с оставшимся текстом. Остальные элементы
записываются через `Frame::Put`, а табуляция разворачивается в пробелы.
Результат `Frame::Put` игнорируется, поэтому невидимые ячейки за границами
кадра всё равно учитываются в возвращаемой ширине.

**Примечания:**

- Отрицательный `At.X` отсекает левую часть вывода; строка `At.Y` за
  границами кадра не изменяет кадр, но также не обнуляет результат.
- Целая табуляция проверяется относительно `Width`, однако граница самого
  кадра может отсечь только часть её ячеек.
- Многоточие, перенос и заполнение остатка фоном отсутствуют. При замене
  длинной надписи короткой предварительно очистите её область через `Frame::Fill`.
- Функция не проверяет переполнение знаковых вычислений столбца.
  Выбирайте координаты и бюджет так, чтобы суммы локального столбца с
  шириной следующего элемента (до четырёх) и с `At.X` помещались в `std::int32_t`.
- Для одновременного изменения одного кадра несколькими потоками
  вызывающий код должен обеспечить синхронизацию: блокировок здесь нет.

**Типичное применение:** Измеряйте надпись через `CellsOf`, при
необходимости сокращайте через `Shortened`, затем рисуйте через `PutText`.
Чтобы показать изменения кадра открытого `Stage`, отдельно вызовите
`Stage::Present()` и обработайте его результат.

**Пример:** Самостоятельный пример создаёт кадр в памяти; экран не открывается.

```cpp
#include "painter/tui/text.h"

int main()
{
    namespace tui = painter::tui;
    namespace core = painter::core;

    auto Created = tui::Frame::Create({12, 1});
    if (!Created) return 1;
    tui::Frame &Out = *Created;
    Out.Clear();

    // A занимает столбец 1, табуляция — 2–4, ≠ — 5.
    const auto Used = tui::PutText(Out, {1, 0}, "A\t\u2260", 6,
                                   core::Colors::White, core::Colors::Black);
    return Used == 5 && Out.Read({5, 0}).Glyph == U'\u2260' ? 0 : 1;
}
```

## Выбор способа записи

`Frame::Write` раскладывает UTF-8 по тем же правилам `GlyphAt`, но без
бюджета ширины: его ограничивает только кадр. U+FFFD он пишет цветом
`Style.Foreground`, а не `OddInk`, и возвращает число записанных ячеек.
`PutText` нужен, когда надпись ограничена шириной или ошибки текста нужно
выделить цветом.

`PutText` изменяет только буфер кадра. Оно не открывает поверхность,
не получает клавиши и не публикует слой в DisplayServer. Этим занимаются
другие модули Painter.
