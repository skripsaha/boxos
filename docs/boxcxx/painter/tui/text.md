# painter::tui::text

## Назначение

Заголовок: [`painter/tui/text.h`](../../../../src/userspace/painter/include/painter/tui/text.h).
Реализация: [`src/tui/text.cpp`](../../../../src/userspace/painter/src/tui/text.cpp).

Текст UTF-8 в ячейках: разбор на символы, измерение ширины в ячейках,
обрезка по ширине и вывод в [Frame](frame.md). Те же правила использует
`Frame::Write` и `Frame::Centre`, поэтому ширина, посчитанная здесь, всегда
совпадает с тем, что займёт текст в кадре.

## Байты, символы, ячейки

- Символ — одна корректная последовательность UTF-8. Он занимает одну ячейку, и ячейка хранит этот символ.
- Табуляция занимает ячейки до следующей позиции, кратной `TabStop` (4), считая от начала текста; ячейки табуляции — пробелы.
- Управляющий символ (U+0000–U+001F, U+007F–U+009F) или байт, не начинающий корректную последовательность (лишний байт продолжения, слишком длинная форма, суррогат, обрыв в конце строки, значение больше U+10FFFF), становится U+FFFD и занимает одну ячейку. Испорченный байт поглощается один, следующий разбирается заново.
- Символы двойной ширины (иероглифы, эмодзи) тоже занимают одну ячейку: ширина по Unicode East Asian Width не учитывается.

Как выглядит символ, решает дисплей:

- на framebuffer — наборщик дисплея через Typecase: геометрия BoxOS (рамки, блоки, мозаики, Брайль) стыкуется с соседними ячейками при любом шрифте; буквы берутся из шрифта, заданного настройкой `settings display text font` (по умолчанию JetBrains Mono NL, с кириллицей), затем из встроенного оттиска 8×16; символ, которого нет нигде, рисуется своим кодом в ячейке;
- на текстовой странице VGA — шрифтом адаптера через таблицу [`boxos_glyph_fold.h`](../../../../src/include/boxos_glyph_fold.h); символ без глифа — сплошной квадрат ■.

Число байтов строки не равно её ширине на экране: для «Привет» это 12 байт
и 6 ячеек. Ширину всегда считайте `CellsOf`.

## Константы и типы

### `TabStop`

**Краткое описание:** Задаёт шаг позиций табуляции в ячейках.

**Параметры:** Нет; `inline constexpr std::size_t TabStop = 4`.

**Возвращает:** Неприменимо: константа.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "painter/tui/text.h"

static_assert(painter::tui::TabStop == 4);
```

### `OddInk`

**Краткое описание:** Задаёт цвет, которым `PutText` рисует U+FFFD на месте управляющего символа или испорченного байта.

**Параметры:** Нет; `core::Color::Rgb(0xE0, 0x9A, 0x30)` — янтарный.

**Возвращает:** Неприменимо: константа.

**Побочные эффекты:** Нет.

**Как работает:** Отдельный цвет отличает испорченное место от самого текста, в том числе от настоящего U+FFFD, написанного программой.

**Примечания:** Используется только `PutText`; `Frame::Write` пишет U+FFFD цветом стиля.

**Пример:**
```cpp
#include "painter/tui/text.h"

bool Odd(const painter::tui::Cell &Here) { return Here.Foreground == painter::tui::OddInk; }
```

### `Glyph`

**Краткое описание:** Описывает один символ текста так, как его покажет стекло.

**Параметры:**
- `Length` (`std::size_t`): сколько байтов текста он занимает, по умолчанию 1.
- `Width` (`std::size_t`): сколько ячеек, по умолчанию 1; у табуляции — до следующей позиции.
- `Character` (`char32_t`): символ для каждой из ячеек; у табуляции — пробел, у испорченного места — U+FFFD.
- `Odd` (`bool`): управляющий символ или испорченный байт.

**Возвращает:** Неприменимо: агрегат.

**Побочные эффекты:** Нет.

**Пример:** См. `GlyphAt`.

## Функции

### `GlyphAt`

**Краткое описание:** Разбирает символ, начинающийся с заданного байта текста.

**Параметры:**
- `Text` (`std::string_view`): текст в UTF-8.
- `Byte` (`std::size_t`): индекс байта; должен быть меньше `Text.size()`.
- `Column` (`std::size_t`): столбец, на котором стоит символ относительно начала текста; нужен для ширины табуляции. По умолчанию 0.

**Возвращает:** (`Glyph`) длину в байтах, ширину в ячейках, символ и признак `Odd`.

**Побочные эффекты:** Нет.

**Примечания:** `Byte` вне строки — неопределённое поведение (проверки нет). `Length` всегда не меньше 1, поэтому цикл `Byte += Length` всегда продвигается.

**Типичное применение:** Собственный обход текста: подсветка, перенос строк, поиск позиции курсора.

**Пример:**
```cpp
#include <vector>

#include "painter/tui/text.h"

// Номера ячеек, с которых начинается каждый символ строки.
std::vector<std::size_t> Starts(std::string_view Text)
{
    std::vector<std::size_t> Out;
    std::size_t Column = 0;
    for (std::size_t Byte = 0; Byte < Text.size();) {
        const painter::tui::Glyph One = painter::tui::GlyphAt(Text, Byte, Column);
        Out.push_back(Column);
        Column += One.Width;
        Byte += One.Length;
    }
    return Out;
}
```

### `CellsOf`

**Краткое описание:** Возвращает, сколько ячеек займёт текст.

**Параметры:**
- `Text` (`std::string_view`): текст в UTF-8.

**Возвращает:** (`std::size_t`) ширина в ячейках с учётом табуляции.

**Побочные эффекты:** Нет.

**Типичное применение:** Выравнивание по центру или справа, расчёт ширины колонки и окна.

**Пример:**
```cpp
#include "painter/tui/text.h"

std::int32_t RightAligned(const painter::tui::Frame &Out, std::string_view Text)
{
    return Out.Size().Width - static_cast<std::int32_t>(painter::tui::CellsOf(Text));
}
```

### `BytesWithin`

**Краткое описание:** Возвращает, сколько начальных байтов текста помещается в заданное число ячеек.

**Параметры:**
- `Text` (`std::string_view`): текст в UTF-8.
- `Cells` (`std::size_t`): доступная ширина.

**Возвращает:** (`std::size_t`) длина самого длинного префикса из целых символов, ширина которого не больше `Cells`.

**Побочные эффекты:** Нет.

**Как работает:** Символ, который не помещается целиком (например табуляция шире остатка), в префикс не входит. Последовательность UTF-8 никогда не разрезается.

**Пример:**
```cpp
#include "painter/tui/text.h"

std::string_view Fit(std::string_view Text, std::size_t Width) { return Text.substr(0, painter::tui::BytesWithin(Text, Width)); }
```

### `Shortened`

**Краткое описание:** Возвращает текст, укороченный до заданной ширины с многоточием в конце.

**Параметры:**
- `Text` (`std::string_view`): текст в UTF-8.
- `Width` (`std::size_t`): наибольшая ширина в ячейках.

**Возвращает:** (`std::string`) сам текст, если он помещается; иначе префикс из целых символов и `"..."` (три точки ASCII); при `Width ≤ 3` — `Width` точек.

**Побочные эффекты:** Выделяет память; может бросить `std::bad_alloc`.

**Пример:**
```cpp
#include "painter/tui/text.h"

std::string Title(std::string_view Name) { return painter::tui::Shortened(Name, 24); }
```

### `PutText`

**Краткое описание:** Пишет текст в строку кадра, не шире заданного числа ячеек.

**Параметры:**
- `Out` (`Frame &`, out): кадр.
- `At` (`core::Point`): ячейка первого символа.
- `Text` (`std::string_view`): текст в UTF-8.
- `Width` (`std::int32_t`): наибольшая ширина в ячейках.
- `Ink` (`core::Color`): цвет символов.
- `Under` (`core::Color`): цвет фона.

**Возвращает:** (`std::int32_t`) сколько ячеек занял текст (включая ячейки за краем кадра, если `At` у края).

**Побочные эффекты:** Пишет ячейки через `Frame::Put`; ячейки вне кадра пропускаются.

**Как работает:** Вывод останавливается на первом символе, который не помещается в `Width` целиком. Испорченные места пишутся U+FFFD цветом `OddInk`.

**Примечания:** Многоточие не добавляется — для этого сначала примените `Shortened`. Ячейки создаются непрозрачными, без отметок.

**Типичное применение:** Подписи в колонках таблиц и в рамках окон, где текст не должен заходить на соседние элементы.

**Пример:**
```cpp
#include "painter/tui/text.h"

void Row(painter::tui::Frame &Out, std::int32_t Y, std::string_view Name, std::string_view Size)
{
    namespace core = painter::core;
    (void)painter::tui::PutText(Out, {1, Y}, painter::tui::Shortened(Name, 30), 30, core::Colors::White, core::Colors::Black);
    (void)painter::tui::PutText(Out, {32, Y}, Size, 10, core::Colors::DarkGray, core::Colors::Black);
}
```
