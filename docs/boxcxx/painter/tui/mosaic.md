# painter::tui::mosaic — подъячеечные цвета и подбор глифа

## Назначение

[Заголовок](../../../../src/userspace/painter/include/painter/tui/mosaic.h),
[реализация](../../../../src/userspace/painter/src/tui/mosaic.cpp).

Модуль приближает рисунок сетки подъячеек (по две в ширину и по две, три или
четыре в высоту) средствами одной текстовой ячейки. Он используется
[FineCanvas](fine_canvas.md). Это преобразование цветов в глифы; модуль не
владеет кадром и не обращается к DisplayServer.

Какие сетки стекло рисует точно, говорит дисплей: флаги `DisplayMosaic`
(`DISPLAY_MOSAIC_QUADRANTS`, `DISPLAY_MOSAIC_SEXTANTS`, `DISPLAY_MOSAIC_OCTANTS`
в `box/display.h`), байт `mosaics` ответа на открытие слоя; кадр хранит его как
`Frame::Mosaics()`. Символы берутся из общей таблицы `boxos_mosaic.h`.

Для полупрозрачных подъячеек средний RGB вычисляется с весом непрозрачности,
а непрозрачность группы усредняется по всем её позициям. Полностью невидимая
группа становится `Color::Through()`. Штриховки для таких Mosaic отключены,
поскольку затронули бы всю ячейку. Квантование непрозрачности определяется
`core::Color`.

Для расчётов передавайте RGB-цвета, при необходимости с непрозрачностью,
или `Through()`. Отдельного разрешения `Color::Screen()` в RGB здесь нет:
специальное значение не содержит фактический цвет экрана.
Приближение на неточных сетках необратимо: `MosaicOf(ResolveMosaic(...))`
не обязано совпасть с входом.

## Справочник

### `Mosaic`

**Краткое описание:** Представьте ячейку цветами подъячеек.

**Параметры:** Структура: `Rows` (`std::uint8_t`, 2, 3 или 4; по умолчанию 2) и `At` (`std::array<core::Color, 8>`). Подъячейки идут в порядке чтения от верхней левой, по две в строке: место подъячейки — строка × 2 + столбец. Используются первые `Count()` = `Rows × 2` элементов.

**Возвращает:** Неприменимо: структура.

**Побочные эффекты:** Нет.

**Примечания:** Это промежуточное представление: шрифт дисплея не даёт независимо окрашенных четвертей.

**Пример:**

```cpp
#include "painter/tui/mosaic.h"

namespace tui = painter::tui;
namespace core = painter::core;

tui::Mosaic Example()
{
    tui::Mosaic Wanted;
    Wanted.At = {core::Colors::Red, core::Colors::Red, core::Colors::Blue, core::Colors::Blue};
    return Wanted;
}
```

### `MosaicOf`

**Краткое описание:** Разложите изображение ячейки на цвета подъячеек сетки из `Rows` строк.

**Параметры:** `Shown` (`const Cell &`, in); `Rows` (`std::uint8_t`, in): 2, 3 или 4; `Mosaic MosaicOf(const Cell &Shown, std::uint8_t Rows) noexcept`.

**Возвращает:** `Mosaic`: цвета подъячеек.

**Побочные эффекты:** Нет; память не выделяется.

**Как работает:** Пробел, полный блок, половины и любой другой символ мозаики из `boxos_mosaic.h` — прямоугольники ячейки: цвет подъячейки есть `Color::Mix(фон, цвет глифа, доля её площади под символом)`, целиком под символом или вне его — точно цвет глифа или фон. Для трёх штриховок возвращает одинаковую смесь цветов во всех позициях: доля краски — четверть, половина и три четверти, как их называет Unicode. Для остальных глифов, включая буквы, возвращает фон во всех позициях.

**Примечания:** Игнорирует `VisibilityMode`, отметку и каретку; прозрачность учитывается только в самих значениях цвета. Произвольная ячейка с флагом `Transparent` и обычными цветами не превращается здесь в `Through`. При `Rows` = 2 результат совпадает с прежним разбором на четверти для всех глифов, кроме символов мозаики, которых нет среди пробела, блоков и половин: четверти, восьмые и секстанты теперь читаются точно, а не как фон.

**Пример:**

```cpp
#include "painter/tui/mosaic.h"

namespace tui = painter::tui;
namespace core = painter::core;

tui::Mosaic Example(const tui::Cell &Value) { return tui::MosaicOf(Value, 2); }
```

### `ResolveMosaic`

**Краткое описание:** Выберите глиф и два цвета для приближённого изображения подъячеек.

**Параметры:** `Wanted` (`const Mosaic &`, in); `Glass` (`GlassKind`, in); `Mosaics` (`std::uint8_t`, in): флаги `DisplayMosaic`; `Cell ResolveMosaic(const Mosaic &Wanted, GlassKind Glass, std::uint8_t Mosaics) noexcept`.

**Возвращает:** `Cell`: непрозрачная по флагу ячейка без отметки; цвета могут быть прозрачными или полупрозрачными.

**Побочные эффекты:** Нет; память не выделяется.

**Как работает:** Для одинаковых цветов возвращает пробел с этим цветом. Если Glass — Pixels и сетка из `Wanted.Rows` строк есть среди `Mosaics`, результат точен: перебираются все 2^(n−1) разбиений подъячеек (n = `Rows × 2`) на передний план и остальное, каждая сторона считается теми же средним с весом непрозрачности и `ErrorOver`, побеждает наименьшая ошибка; глиф — `BoxMosaicQuadrants/Sextants/Octants[шаблон]`. Штриховок здесь нет. Иначе сетка из 3 или 4 строк сначала сводится к двум по средним с весом площади и непрозрачности, затем сравниваются верхний полублок, левый полублок и один цвет; ошибка учитывает взвешенное RGB-расстояние и различие непрозрачности. В режиме Pixels при полностью непрозрачных цветах дополнительно проверяются штриховки; штраф за текстуру уменьшает их предпочтительность. Доли штриховок — по смыслу символов Unicode: четверть, половина и три четверти; так их рисуют и дисплей, и ПЗУ VGA.

**Примечания:** На точной сетке последняя подъячейка всегда в фоне, поэтому разбиение и его дополнение — один ответ; при равенстве ошибок выигрывает один цвет, затем меньший номер шаблона. На прежних сетках при равенстве ошибок сохраняется более ранний кандидат: верхний полублок, затем левый, затем один цвет. Для Text средний RGB заменяется ближайшим цветом из соответствующей группы входа; при равенстве предпочитается более редкий в Mosaic. Это не общий квантователь в VGA-палитру. Дисплей на кадровом буфере отвечает всеми тремя сетками — их рисует геометрия Typecase, — на текстовой странице VGA отвечает 0.

**Типичное применение:** Используйте через `FineCanvas::PutMosaic` или самостоятельно передайте результат в `Frame::Put`.

**Пример:**

```cpp
#include "painter/tui/mosaic.h"

namespace tui = painter::tui;
namespace core = painter::core;

tui::Cell Example(const tui::Mosaic &Wanted, const tui::Frame &Out)
{
    return tui::ResolveMosaic(Wanted, tui::GlassKind::Pixels, Out.Mosaics());
}
```
