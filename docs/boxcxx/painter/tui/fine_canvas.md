# painter::tui::fine_canvas

## Назначение

Заголовок: [`painter/tui/fine_canvas.h`](../../../../src/userspace/painter/include/painter/tui/fine_canvas.h).
Реализация: [`src/tui/fine_canvas.cpp`](../../../../src/userspace/painter/src/tui/fine_canvas.cpp);
шаблон `Cover` — в заголовке.

`FineCanvas` рисует фигуры точнее ячейки, но символами самих ячеек. Каждая
ячейка делится на подпиксели: два по горизонтали и по вертикали столько,
сколько стекло рисует точно — четыре при октантах, три при секстантах,
иначе два. Фигура покрывает каждый подпиксель на какую-то долю, её цвет
смешивается с тем, что ячейка уже показывает, и ячейка заменяется лучшим
символом с двумя цветами ([ResolveMosaic](mosaic.md)). Край фигуры
получается квадрантом, октантом, половиной, блоком или штриховкой — что
есть на этом стекле, — а не лесенкой целых ячеек.

`FineCanvas` состояния не хранит: это лёгкая обёртка над ссылкой на
[Frame](frame.md). Она сосуществует с `PutPixel` на одном кадре.

## Единицы

Фигуры задаются в единицах `PutPixel`: ячейка — 1 по горизонтали и 2 по
вертикали. Ячейка обычно примерно вдвое выше своей ширины, поэтому круг в
этих единицах выглядит на экране круглым. Подпиксель — 0,5 по горизонтали
и `2 / строк сетки` по вертикали. Дробные координаты допустимы: `{2.5f, 3.0f}`
— середина третьего столбца, нижняя половина второй строки.

## Правила наложения

- Каждая ячейка, которой достигла фигура, сразу становится непрозрачной с подобранным символом; ячейки, которых фигура не коснулась, не меняются.
- Фигуры, нарисованные одна поверх другой, накладываются по порядку, каждая поверх ячеек, какими они стали.
- Над прозрачным подпикселем (кадр после `ClearTransparent`, где ничего не нарисовано) цвет фигуры кладётся с непрозрачностью, равной её доле покрытия (`Color::Over`). Поэтому край к неизвестному фону всё равно мягкий: дисплей смешает его с тем, что ниже, а то, что фигура не покрыла, остаётся прозрачным.
- На текстовой странице смесей цветов нет: подпиксель покрывается целиком, если доля не меньше половины, иначе не покрывается.
- Текст — тоже ячейки: буква, на которую легла фигура, пропадает. Сначала рисуйте фигуры, потом текст.

Перед рисованием на отдельном кадре передайте ему вид стекла и мозаики
поверхности (`SetGlass`, `SetMosaics`); кадр `Stage` уже их знает.

## Класс FineCanvas

### `FineCanvas`

**Краткое описание:** Рисует сглаженные фигуры в ячейках кадра.

**Параметры:**
- `Target` (`Frame &`): кадр, в котором рисуются фигуры; конструктор `explicit`, `noexcept`.

**Возвращает:** Неприменимо: класс.

**Побочные эффекты:** Конструктор ничего не меняет.

**Примечания:** Хранит указатель на кадр: кадр должен жить дольше холста и не перемещаться. Копирование холста копирует указатель.

**Пример:**
```cpp
#include "painter/tui/fine_canvas.h"

void Sun(painter::tui::Frame &Out)
{
    painter::tui::FineCanvas Fine(Out);
    Fine.Disc(10.0f, 8.0f, 5.0f, painter::core::Colors::Amber);
}
```

### `FineCanvas::Disc`

**Краткое описание:** Рисует закрашенный круг.

**Параметры:**
- `Across` (`float`), `Down` (`float`): центр.
- `Radius` (`float`): радиус в единицах `PutPixel`.
- `Ink` (`core::Color`): цвет.
- `Opacity` (`float`): непрозрачность 0–1, по умолчанию 1.

**Возвращает:** `void`.

**Побочные эффекты:** Перерисовывает ячейки, которых достигает круг.

**Пример:**
```cpp
#include "painter/tui/fine_canvas.h"

void Bubble(painter::tui::FineCanvas &Fine, float X, float Y) { Fine.Disc(X, Y, 1.5f, painter::core::Colors::Cyan, 0.6f); }
```

### `FineCanvas::Ellipse`

**Краткое описание:** Рисует закрашенный эллипс.

**Параметры:**
- `Across`, `Down` (`float`): центр.
- `ReachAcross`, `ReachDown` (`float`): полуоси; не меньше 0,25 и 0,5 соответственно (меньшие значения поднимаются до них).
- `Ink` (`core::Color`), `Opacity` (`float`, по умолчанию 1).

**Возвращает:** `void`.

**Побочные эффекты:** Перерисовывает ячейки, которых достигает эллипс.

**Как работает:** Расстояние до края приближается делением неявной функции эллипса на длину её градиента; точно у края, где это нужно для сглаживания.

**Пример:**
```cpp
#include "painter/tui/fine_canvas.h"

void Eye(painter::tui::FineCanvas &Fine) { Fine.Ellipse(12.0f, 10.0f, 6.0f, 3.0f, painter::core::Colors::White); }
```

### `FineCanvas::Ring`

**Краткое описание:** Рисует кольцо между двумя радиусами.

**Параметры:**
- `Across`, `Down` (`float`): центр.
- `Outer` (`float`): внешний радиус.
- `Inner` (`float`): внутренний радиус.
- `Ink` (`core::Color`), `Opacity` (`float`, по умолчанию 1).

**Возвращает:** `void`.

**Побочные эффекты:** Перерисовывает ячейки, которых достигает кольцо; внутри `Inner` ячейки не трогаются, если кольцо до них не дотягивается.

**Пример:**
```cpp
#include "painter/tui/fine_canvas.h"

void Target(painter::tui::FineCanvas &Fine) { Fine.Ring(20.0f, 12.0f, 8.0f, 6.5f, painter::core::Colors::Red); }
```

### `FineCanvas::Rounded`

**Краткое описание:** Рисует прямоугольник со скруглёнными углами.

**Параметры:**
- `Left`, `Top` (`float`): левый верхний угол.
- `Across`, `Down` (`float`): ширина и высота.
- `Radius` (`float`): радиус углов; 0 — прямые углы.
- `Ink` (`core::Color`), `Opacity` (`float`, по умолчанию 1).

**Возвращает:** `void`.

**Побочные эффекты:** Перерисовывает ячейки, которых достигает прямоугольник.

**Примечания:** Радиус больше половины меньшей стороны не ограничивается и даёт искажённую фигуру — выбирайте его не больше `min(Across, Down) / 2`.

**Пример:**
```cpp
#include "painter/tui/fine_canvas.h"

void Button(painter::tui::FineCanvas &Fine) { Fine.Rounded(4.0f, 4.0f, 16.0f, 6.0f, 2.0f, painter::core::Colors::Ocean); }
```

### `FineCanvas::Fill`

**Краткое описание:** Рисует прямоугольник с прямыми углами.

**Параметры:**
- `Left`, `Top` (`float`): левый верхний угол.
- `Across`, `Down` (`float`): ширина и высота.
- `Ink` (`core::Color`), `Opacity` (`float`, по умолчанию 1).

**Возвращает:** `void`.

**Побочные эффекты:** Как у `Rounded` с радиусом 0.

**Пример:**
```cpp
#include "painter/tui/fine_canvas.h"

void Level(painter::tui::FineCanvas &Fine, float Share) { Fine.Fill(2.0f, 2.0f, 30.0f * Share, 2.0f, painter::core::Colors::Leaf); }
```

### `FineCanvas::Line`

**Краткое описание:** Рисует отрезок заданной толщины со скруглёнными концами.

**Параметры:**
- `From`, `To` (`core::PointF`): концы.
- `Thick` (`float`): толщина.
- `Ink` (`core::Color`), `Opacity` (`float`, по умолчанию 1).

**Возвращает:** `void`.

**Побочные эффекты:** Перерисовывает ячейки, которых достигает отрезок.

**Как работает:** Расстояние от точки до отрезка минус половина толщины; поэтому концы скруглены.

**Пример:**
```cpp
#include "painter/tui/fine_canvas.h"

void Hand(painter::tui::FineCanvas &Fine, painter::core::PointF Centre, painter::core::PointF Tip)
{
    Fine.Line(Centre, Tip, 0.8f, painter::core::Colors::White);
}
```

### `FineCanvas::Polygon`

**Краткое описание:** Рисует закрашенный многоугольник.

**Параметры:**
- `Corners` (`std::span<const core::PointF>`): вершины по порядку; замыкается автоматически. Меньше трёх вершин — ничего не рисуется.
- `Ink` (`core::Color`), `Opacity` (`float`, по умолчанию 1).

**Возвращает:** `void`.

**Побочные эффекты:** Перерисовывает ячейки, которых достигает многоугольник.

**Как работает:** Внутренность определяется правилом чётности пересечений (even-odd), расстояние до края — наименьшее расстояние до сторон. Самопересекающиеся многоугольники закрашиваются по правилу чётности.

**Примечания:** Каждая точка проверяется против всех сторон: для многоугольника с сотнями вершин это медленно.

**Пример:**
```cpp
#include <array>

#include "painter/tui/fine_canvas.h"

void Arrow(painter::tui::FineCanvas &Fine)
{
    const std::array<painter::core::PointF, 3> Tip{{{10.0f, 4.0f}, {16.0f, 10.0f}, {10.0f, 16.0f}}};
    Fine.Polygon(Tip, painter::core::Colors::Amber);
}
```

### `FineCanvas::Cover`

**Краткое описание:** Рисует любую фигуру, заданную функцией расстояния до её края.

**Параметры:**
- `Cells` (`core::Rect`): ячейки, которых может достичь фигура; ограничивает работу и обрезается кадром.
- `Ink` (`core::Color`): цвет.
- `Outside` (шаблонный вызываемый объект `float(float Across, float Down)`): насколько точка вне фигуры, в единицах `PutPixel` — отрицательно внутри, 0 на краю.
- `Opacity` (`float`): непрозрачность 0–1, по умолчанию 1.

**Возвращает:** `void`.

**Побочные эффекты:** Перерисовывает ячейки `Cells`, хотя бы один подпиксель которых получил цвет.

**Как работает:** Для каждого подпикселя вычисляется расстояние от его середины. Дальше высоты подпикселя снаружи — не покрыт; глубже высоты подпикселя внутри — покрыт целиком; между ними доля равна `0,5 − расстояние / ширина`, где ширина подпикселя считается вдоль направления края (по численному градиенту функции). Доля, умноженная на `Opacity`, становится весом `Color::Over`. Затронутая ячейка заменяется `ResolveMosaic`.

**Примечания:** Функция должна быть точной только в пределах ячейки от края — дальше важен лишь знак. Все остальные фигуры класса реализованы через `Cover`.

**Типичное применение:** Фигуры, которых нет среди готовых: полумесяц, звезда, капля, объединение и пересечение фигур (`max`/`min` расстояний).

**Пример:**
```cpp
#include <algorithm>
#include <cmath>

#include "painter/tui/fine_canvas.h"

// Полумесяц: круг без смещённого круга.
void Moon(painter::tui::FineCanvas &Fine, float X, float Y, float R)
{
    const auto Outside = [=](float A, float D) {
        const float Lit    = std::hypot(A - X, D - Y) - R;
        const float Shadow = std::hypot(A - X - R * 0.5f, D - Y) - R * 0.8f;
        return std::max(Lit, -Shadow);
    };
    Fine.Cover(painter::tui::FineCanvas::Reaching(X - R, Y - R, X + R, Y + R), painter::core::Colors::Yellow, Outside);
}
```

### `FineCanvas::Reaching`

**Краткое описание:** Возвращает ячейки, которых касается прямоугольник в единицах `PutPixel`, с запасом в одну ячейку для мягкого края.

**Параметры:**
- `Left`, `Top`, `Right`, `Bottom` (`float`): границы в единицах `PutPixel`.

**Возвращает:** (`core::Rect`) ячейки от `floor(Left) − 1` до `floor(Right) + 1` по горизонтали и от `floor(Top / 2) − 1` до `floor(Bottom / 2) + 1` по вертикали.

**Побочные эффекты:** Нет; статическая функция.

**Типичное применение:** Первый аргумент `Cover` для своей фигуры.

**Пример:** См. `FineCanvas::Cover`.

### `FineCanvas::PutMosaic`

**Краткое описание:** Записывает в ячейку лучшее приближение заданных подпикселей на стекле кадра.

**Параметры:**
- `Cell` (`core::Point`): ячейка.
- `Wanted` (`const Mosaic &`): подпиксели.

**Возвращает:** (`bool`) `false`, если ячейка вне кадра.

**Побочные эффекты:** Заменяет одну ячейку результатом `ResolveMosaic(Wanted, Glass(), Mosaics())`.

**Примечания:** В отличие от фигур, не смешивает с текущим содержимым ячейки: подпиксели записываются как заданы.

**Пример:**
```cpp
#include "painter/tui/fine_canvas.h"

bool Checker(painter::tui::FineCanvas &Fine, painter::core::Point At)
{
    namespace core = painter::core;
    painter::tui::Mosaic Wanted;
    Wanted.At = {core::Colors::White, core::Colors::Black, core::Colors::Black, core::Colors::White};
    return Fine.PutMosaic(At, Wanted);
}
```
