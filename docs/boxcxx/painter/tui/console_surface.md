# painter::tui::console_surface

## Назначение

Заголовок: [`painter/tui/console_surface.h`](../../../../src/userspace/painter/include/painter/tui/console_surface.h).
Реализация: [`src/tui/console_surface.cpp`](../../../../src/userspace/painter/src/tui/console_surface.cpp),
общая часть — [KeptCells](internal/kept_cells.md).

`ConsoleSurface` — рисунок, который становится частью текста консоли.
Пока рисунок собирается, он показывается как временная область поверх
консоли. `Commit()` одной операцией вкладывает ячейки в текст консоли,
ставит курсор консоли и закрывает область. После этого рисунок остаётся в
выводе, прокручивается вместе с ним и попадает в журнал консоли — как
обычный напечатанный текст. Если программа завершилась без `Commit`,
рисунок просто исчезает.

Так выводят QR-коды (`qr`), карточки (`passport`), таблицы и всё, что
должно остаться на экране после завершения программы.

Своей клавиатуры у `ConsoleSurface` нет — при необходимости откройте
[Keyboard](keyboard.md).

## Координаты и прокрутка

Координаты — это ячейки консоли от её левого верхнего угла. `Cursor()`
сообщает, где стоит курсор консоли: сразу после всего, что поток напечатал
до открытия. Рисунок обычно кладут, начиная с этой строки.

Если рисунок не помещается ниже курсора, консоль нужно прокрутить.
`ScrollUp()` не прокручивает консоль сразу, а заказывает прокрутку на одну
строку при `Commit`. С каждым вызовом `Cursor()` возвращает строку на одну
выше (не ниже 0), и все координаты `Paint` и `SetCursor` задаются уже в
прокрученной консоли. До `Commit` рисунок показывается в этих координатах
поверх ещё не прокрученной консоли; при `Commit` консоль сначала
прокручивается на заказанное число строк, затем в неё вкладываются ячейки.

При вкладывании в текст:

- непрозрачные ячейки заменяют текст консоли под собой; прозрачные оставляют его как был (поэтому `Paint` делает переносимые ячейки непрозрачными);
- отметки ячеек (`CellMark`) не сохраняются — это только часть рисунка;
- курсор консоли встаёт в каретку области, если она поставлена (её ставит `SetCursor`), иначе остаётся на месте.

## Класс ConsoleSurface

### `ConsoleSurface`

**Краткое описание:** Владеет рисунком, который собирается поверх консоли и затем фиксируется в её текст.

**Параметры:** Создаётся только через `ConsoleSurface::Open`.

**Возвращает:** Неприменимо: класс.

**Побочные эффекты:** Пока объект открыт, его ячейки видны поверх консоли, когда программа впереди.

**Как работает:** Внутри — `KeptCells` в области `Placement::Over` и счётчик заказанной прокрутки. `Commit` передаёт область дисплею командой `DISP_CMD_AREA_COMMIT`; дисплей прокручивает консоль, вкладывает ячейки и закрывает область.

**Примечания:** Копировать нельзя, перемещать можно; перемещающее присваивание сначала закрывает прежний рисунок получателя. Деструктор вызывает `Close()`: незафиксированный рисунок исчезает.

**Типичное применение:** Открыть, узнать `Cursor()`, при нехватке места вызвать `ScrollUp()`, нарисовать `Paint`, поставить `SetCursor` под рисунком, `Commit()`.

**Пример:** См. `ConsoleSurface::Commit`.

### `ConsoleSurface::Open`

**Краткое описание:** Открывает рисунок поверх консоли.

**Параметры:**
- `LeastCols` (`std::int32_t`): минимальная ширина консоли; по умолчанию 0.
- `LeastRows` (`std::int32_t`): минимальная высота консоли; по умолчанию 0.

**Возвращает:** (`std::expected<ConsoleSurface, StageError>`) рисунок размером с консоль или ошибка (см. [stage](stage.md)).

**Побочные эффекты:** Запрашивает размер консоли и положение её курсора, открывает область, выделяет кадр.

**Примечания:** Открывайте после того, как напечатано всё, что должно стоять выше рисунка: `Cursor()` запоминается при открытии.

**Пример:**
```cpp
#include "painter/tui/console_surface.h"

auto OpenCard() { return painter::tui::ConsoleSurface::Open(30, 10); }
```

### `ConsoleSurface::Size` / `IsOpen` / `Glass` / `Mosaics`

**Краткое описание:** Возвращают размер консоли, признак открытости, вид стекла и точно рисуемые мозаики.

**Параметры:** Нет.

**Возвращает:**
- `Size` — (`core::Size`) размер консоли на момент открытия; `{0, 0}` у перемещённого объекта.
- `IsOpen` — (`bool`) `false` после `Close()`, после успешного `Commit()` и у перемещённого объекта.
- `Glass` — (`GlassKind`); `Pixels` у перемещённого объекта.
- `Mosaics` — (`std::uint8_t`) флаги `ITEM_MOSAIC_*`; 0 у перемещённого объекта.

**Побочные эффекты:** Нет.

**Примечания:** Рисунок, вложенный в текст консоли, станет обычным текстом: на текстовой странице и в журнале консоли он должен читаться и без сглаживания. Мягкие края `FineCanvas` для таких рисунков обычно не нужны.

**Пример:**
```cpp
#include "painter/tui/console_surface.h"

bool Fits(const painter::tui::ConsoleSurface &Out, std::int32_t Width) { return Out.Size().Width >= Width; }
```

### `ConsoleSurface::Cursor`

**Краткое описание:** Возвращает положение курсора консоли с учётом заказанной прокрутки.

**Параметры:** Нет.

**Возвращает:** (`std::expected<core::Point, box::error>`) курсор на момент открытия, или последний поставленный `SetCursor`, со строкой, уменьшенной на число вызовов `ScrollUp` (не ниже 0); `errc::invalid_state` — объект закрыт или перемещён.

**Побочные эффекты:** Нет.

**Примечания:** Вычитание прокрутки применяется и к точке, поставленной `SetCursor`, хотя та уже задана в прокрученных координатах: после `ScrollUp` и `SetCursor({X, Y})` вызов `Cursor()` вернёт строку `Y − число прокруток`. Полагайтесь на `Cursor()` до `SetCursor`, а своё место курсора храните сами.

**Пример:** См. `ConsoleSurface::ScrollUp`.

### `ConsoleSurface::Paint`

**Краткое описание:** Переносит прямоугольник кадра в рисунок непрозрачными ячейками и показывает его.

**Параметры:**
- `Origin` (`core::Point`): ячейка консоли (в прокрученных координатах), куда ляжет левый верхний угол.
- `FrameBuffer` (`const Frame &`): источник.
- `Region` (`core::Rect`): прямоугольник источника; во второй перегрузке. Первая переносит весь кадр.

**Возвращает:** (`box::status`) успех; `errc::invalid_state` — закрыт; `errc::out_of_range` — прямоугольник пуст или не помещается в источник либо в консоль от `Origin`; `errc::no_memory`.

**Побочные эффекты:** Заменяет ячейки рисунка в прямоугольнике; каждая перенесённая ячейка становится непрозрачной. Переносит каретку источника внутри `Region`. Показывает рисунок.

**Как работает:** Видимость каждой перенесённой ячейки принудительно ставится в `Opaque`: прозрачная ячейка источника станет пробелом своих цветов (у ячейки после `ClearTransparent` это цвета `Through()` — при вкладывании в текст на их месте будет цвет страницы).

**Примечания:** Обрезки нет: при ошибке диапазона ничего не меняется.

**Пример:** См. `ConsoleSurface::Commit`.

### `ConsoleSurface::SetCursor`

**Краткое описание:** Задаёт место, откуда консоль продолжит вывод после `Commit`.

**Параметры:**
- `At` (`core::Point`): ячейка консоли в прокрученных координатах.

**Возвращает:** (`box::status`) успех; `errc::out_of_range` — точка вне консоли; `errc::invalid_state` — закрыт.

**Побочные эффекты:** Ставит каретку рисунка в `At` и показывает рисунок (каретка видна сразу); запоминает курсор для `Cursor()`.

**Примечания:** Каретка рисунка — это и есть будущий курсор консоли. Последующий `Paint` прямоугольника, который содержит каретку источника или накрывает текущую каретку, её изменит — вызывайте `SetCursor` последним перед `Commit`.

**Пример:** См. `ConsoleSurface::Commit`.

### `ConsoleSurface::ScrollUp`

**Краткое описание:** Заказывает прокрутку консоли на одну строку при фиксации.

**Параметры:** Нет.

**Возвращает:** (`box::status`) успех; `errc::out_of_range` — уже заказано столько строк, сколько в консоли; `errc::invalid_state` — закрыт.

**Побочные эффекты:** Увеличивает счётчик прокрутки. Консоль и рисунок на экране сейчас не меняются.

**Типичное применение:** Освободить место под рисунок у нижнего края консоли.

**Пример:**
```cpp
#include "painter/tui/console_surface.h"

// Строка, с которой помещается рисунок высотой Rows (и строка подсказки под ним).
std::expected<std::int32_t, box::error> MakeRoom(painter::tui::ConsoleSurface &Out, std::int32_t Rows)
{
    auto Cursor = Out.Cursor();
    if (!Cursor) return std::unexpected(Cursor.error());
    std::int32_t Top = Cursor->Y;
    const std::int32_t Lowest = Out.Size().Height - Rows - 1;
    for (; Top > Lowest; Top--)
        if (auto Scrolled = Out.ScrollUp(); !Scrolled) return std::unexpected(Scrolled.error());
    return Top;
}
```

### `ConsoleSurface::Commit`

**Краткое описание:** Вкладывает рисунок в текст консоли и закрывает область.

**Параметры:** Нет.

**Возвращает:** (`box::status`) успех; `errc::invalid_state` — уже закрыт или зафиксирован; `errc::out_of_range` — заказанная прокрутка больше высоты консоли; `errc::no_memory`; ошибка дисплея.

**Побочные эффекты:** Отправляет несохранённые изменения, затем дисплей прокручивает консоль на заказанное число строк, кладёт непрозрачные ячейки в текст, ставит курсор консоли в каретку и закрывает область. При успехе объект закрыт (`IsOpen() == false`).

**Как работает:** Операция атомарна на стороне дисплея: человек не видит промежуточного состояния, где рисунок уже исчез как область, но ещё не стал текстом.

**Примечания:** При ошибке объект остаётся открытым: можно повторить `Commit` или закрыть без фиксации.

**Пример:**
```cpp
#include "painter/tui/console_surface.h"
#include "painter/tui/text.h"

bool PrintBadge(std::string_view Name)
{
    namespace tui  = painter::tui;
    namespace core = painter::core;

    auto Out = tui::ConsoleSurface::Open(24, 4);
    if (!Out) return false;
    auto Top = Out->Cursor();
    if (!Top) return false;
    std::int32_t Row = Top->Y;
    while (Row > Out->Size().Height - 4)
        if (!Out->ScrollUp()) return false; else Row--;

    auto Badge = tui::Frame::Create({24, 3});
    if (!Badge) return false;
    Badge->Clear({core::Colors::White, core::Colors::DarkBlue});
    (void)Badge->Write({2, 1}, tui::Shortened(Name, 20), {core::Colors::White, core::Colors::DarkBlue});

    if (!Out->Paint({0, Row}, *Badge)) return false;
    if (!Out->SetCursor({0, Row + 3})) return false;
    return Out->Commit().has_value();
}
```

### `ConsoleSurface::Close`

**Краткое описание:** Закрывает рисунок без фиксации; он исчезает с экрана.

**Параметры:** Нет.

**Возвращает:** (`box::status`) всегда успех; повторный вызов и вызов после `Commit` ничего не делают.

**Побочные эффекты:** Закрывает область дисплея.

**Пример:**
```cpp
#include "painter/tui/console_surface.h"

void Cancel(painter::tui::ConsoleSurface &Out) { (void)Out.Close(); }
```
