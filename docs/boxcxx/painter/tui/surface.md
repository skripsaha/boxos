# painter::tui::surface

## Назначение

Заголовок: [`painter/tui/surface.h`](../../../../src/userspace/painter/include/painter/tui/surface.h).
Реализация: [`src/tui/surface.cpp`](../../../../src/userspace/painter/src/tui/surface.cpp),
общая часть — [KeptCells](internal/kept_cells.md).

`Surface` — ячейки, которые программа держит поверх консоли: собственная
область на экране размером с консоль. Сначала все её ячейки прозрачны —
сквозь них видна консоль или то, что ниже. Программа переносит в неё
прямоугольники своих кадров (`Composite`); дисплей накладывает их поверх
нижележащего. При закрытии или уничтожении объекта ячейки исчезают, и
консоль под ними остаётся как была.

Своей клавиатуры у `Surface` нет — для ввода откройте [Keyboard](keyboard.md).

## Типы

### `SurfaceRole`

**Краткое описание:** Выбирает, когда видна поверхность.

**Параметры:**
- `Overlay`: поверх всего, пока программа впереди.
- `Notice`: поверх всего всегда, даже когда программа позади — часы в углу, спутник, уведомление.

**Возвращает:** Неприменимо: перечисление.

**Побочные эффекты:** Нет.

**Как работает:** `Overlay` открывает область `Placement::Over`, `Notice` — ту же область с признаком «всегда» (`Always`).

**Пример:**
```cpp
#include "painter/tui/surface.h"

auto OpenClock() { return painter::tui::Surface::Open(0, 0, painter::tui::SurfaceRole::Notice); }
```

## Класс Surface

### `Surface`

**Краткое описание:** Владеет сохраняемыми ячейками программы поверх консоли.

**Параметры:** Создаётся только через `Surface::Open`.

**Возвращает:** Неприменимо: класс.

**Побочные эффекты:** Пока объект открыт, его непрозрачные ячейки видны поверх консоли.

**Как работает:** Внутри — `KeptCells`: кадр размером с консоль (изначально прозрачный) и область дисплея с одной сеткой ячеек. Каждый `Composite` меняет этот кадр и показывает его; дисплею уходят только изменившиеся отрезки строк.

**Примечания:** Копировать нельзя, перемещать можно; перемещающее присваивание сначала закрывает прежнюю поверхность получателя. Деструктор вызывает `Close()`.

**Типичное применение:** Временные фигуры и панели: QR-код поверх вывода, анимированный спутник, подсказка.

**Пример:** См. [README](README.md), «Фигура поверх консоли».

### `Surface::Open`

**Краткое описание:** Открывает прозрачную поверхность поверх консоли.

**Параметры:**
- `LeastCols` (`std::int32_t`): минимальная ширина консоли; по умолчанию 0.
- `LeastRows` (`std::int32_t`): минимальная высота консоли; по умолчанию 0.
- `Role` (`SurfaceRole`): по умолчанию `Overlay`.

**Возвращает:** (`std::expected<Surface, StageError>`) поверхность размером с консоль или ошибка (см. `StageErrorKind` в [stage](stage.md)).

**Побочные эффекты:** Запрашивает размер консоли, открывает область дисплея, выделяет кадр.

**Примечания:** Минимум относится ко всей консоли, а не к рисунку. На экран ничего не отправляется до первого `Composite`.

**Пример:**
```cpp
#include "painter/tui/surface.h"

auto OpenOverlay() { return painter::tui::Surface::Open(30, 10); }
```

### `Surface::Size` / `IsOpen` / `Glass` / `Mosaics`

**Краткое описание:** Возвращают размер поверхности, признак открытости, вид стекла и точно рисуемые мозаики.

**Параметры:** Нет.

**Возвращает:**
- `Size` — (`core::Size`) размер консоли на момент открытия; `{0, 0}` у перемещённого объекта.
- `IsOpen` — (`bool`) `false` после `Close()` и у перемещённого объекта.
- `Glass` — (`GlassKind`) вид стекла; `Pixels` у перемещённого объекта.
- `Mosaics` — (`std::uint8_t`) флаги `ITEM_MOSAIC_*`; 0 у перемещённого объекта.

**Побочные эффекты:** Нет.

**Типичное применение:** Передать `Glass()` и `Mosaics()` отдельному кадру перед рисованием в нём `FineCanvas`; вычислить позицию рисунка по `Size()`.

**Пример:**
```cpp
#include "painter/tui/surface.h"

painter::core::Point BottomRight(const painter::tui::Surface &Screen, painter::core::Size Picture)
{
    return {Screen.Size().Width - Picture.Width, Screen.Size().Height - Picture.Height};
}
```

### `Surface::Composite`

**Краткое описание:** Переносит прямоугольник кадра в поверхность и показывает её.

**Параметры:**
- `Origin` (`core::Point`): ячейка поверхности, куда ляжет левый верхний угол прямоугольника.
- `FrameBuffer` (`const Frame &`): источник.
- `Region` (`core::Rect`): прямоугольник источника; во второй перегрузке. Первая перегрузка переносит весь кадр.

**Возвращает:** (`box::status`) успех; `errc::invalid_state` — поверхность закрыта или перемещена; `errc::out_of_range` — `Region` пуст или не помещается в источник, или прямоугольник не помещается в поверхность от `Origin`; `errc::no_memory` — не хватило памяти при показе.

**Побочные эффекты:** Заменяет ячейки поверхности в прямоугольнике `{Origin, размер Region}` ячейками источника, включая прозрачные; переносит каретку; показывает поверхность одним шагом.

**Как работает:** Ячейки копируются как есть: непрозрачная ячейка источника закрывает место, прозрачная — снимает прежнее покрытие и открывает нижележащее. Каретка поверхности, стоявшая внутри заменённого прямоугольника, снимается; каретка источника, стоящая внутри `Region`, переносится в соответствующее место поверхности. Затем вся поверхность показывается (`CellsArea::Present`).

**Примечания:** Обрезки нет: при ошибке диапазона ничего не меняется. Ячейки вне прямоугольника остаются как были — старое положение движущейся фигуры нужно очистить самим (см. пример).

**Типичное применение:** Анимированная фигура: каждый шаг — прозрачный кадр с фигурой, перенесённый в её текущее место.

**Пример:**
```cpp
#include "painter/tui/surface.h"

// Сдвигает рисунок: старое место очищается, новое заполняется одним показом.
box::status Move(painter::tui::Surface &Screen, const painter::tui::Frame &Picture, painter::core::Point To)
{
    if (auto Cleared = Screen.Clear(); !Cleared) return Cleared;
    return Screen.Composite(To, Picture);
}
```

### `Surface::Clear`

**Краткое описание:** Делает все ячейки поверхности прозрачными, не показывая промежуточный пустой кадр.

**Параметры:** Нет.

**Возвращает:** (`box::status`) успех или `errc::invalid_state` для закрытой/перемещённой поверхности.

**Побочные эффекты:** Очищает внутренний кадр и снимает каретку. Дисплею ничего не отправляется.

**Как работает:** Изменение уйдёт вместе со следующим `Composite`: дисплей сразу увидит новую картинку, без мигания пустым экраном.

**Примечания:** Если после `Clear` не последует `Composite`, на экране останется прежнее изображение. Чтобы убрать всё немедленно, закройте поверхность или перенесите прозрачный кадр.

**Пример:** См. `Surface::Composite`.

### `Surface::Close`

**Краткое описание:** Закрывает поверхность и убирает её ячейки с экрана.

**Параметры:** Нет.

**Возвращает:** (`box::status`) всегда успех; повторный вызов ничего не делает.

**Побочные эффекты:** Закрывает область дисплея.

**Примечания:** После `Close` `Composite` и `Clear` возвращают `invalid_state`.

**Пример:**
```cpp
#include "painter/tui/surface.h"

void Hide(painter::tui::Surface &Screen) { (void)Screen.Close(); }
```
