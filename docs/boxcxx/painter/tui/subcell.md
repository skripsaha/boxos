# painter::tui::subcell — четыре подъячеечных цвета

## Назначение

[Заголовок](../../../../src/userspace/painter/include/painter/tui/subcell.h),
[реализация](../../../../src/userspace/painter/src/tui/subcell.cpp).

Модуль приближает рисунок сетки 2 × 2 средствами одной текстовой ячейки.
Он используется [FineCanvas](fine_canvas.md). Это преобразование цветов в
глифы; модуль не владеет кадром и не обращается к DisplayServer.

Для полупрозрачных подъячеек средний RGB вычисляется с весом непрозрачности,
а непрозрачность группы усредняется по всем её позициям. Полностью невидимая
группа становится `Color::Through()`. Штриховки для таких Quad отключены,
поскольку затронули бы всю ячейку. Квантование непрозрачности определяется
`core::Color`.

Для расчётов передавайте RGB-цвета, при необходимости с непрозрачностью,
или `Through()`. Отдельного разрешения `Color::Screen()` в RGB здесь нет:
специальное значение не содержит фактический цвет экрана.
Приближение необратимо: `QuadOf(ResolveQuad(...))` не обязано совпасть с входом.

## Справочник

### `Quad`

**Краткое описание:** Представьте ячейку четырьмя цветами подъячеек.

**Параметры:** Псевдоним `std::array<core::Color, 4>`; порядок: верхняя левая, верхняя правая, нижняя левая, нижняя правая.

**Возвращает:** Неприменимо: тип массива.

**Побочные эффекты:** Нет.

**Примечания:** Это промежуточное представление: шрифт не даёт четыре независимо окрашенных четверти.

**Пример:**

```cpp
#include "painter/tui/subcell.h"

namespace tui = painter::tui;
namespace core = painter::core;

tui::Quad Wanted{core::Colors::Red, core::Colors::Red,
                 core::Colors::Blue, core::Colors::Blue};
```

### `QuadPlace`

**Краткое описание:** Выберите индекс подъячеечной позиции.

**Параметры:** `TopLeft = 0`, `TopRight = 1`, `BottomLeft = 2`, `BottomRight = 3`; все `inline constexpr std::size_t`.

**Возвращает:** Неприменимо: пространство имён констант.

**Побочные эффекты:** Нет.

**Пример:**

```cpp
#include "painter/tui/subcell.h"

namespace tui = painter::tui;
namespace core = painter::core;

core::Color Example(const tui::Quad &Wanted) { return Wanted[tui::QuadPlace::TopLeft]; }
```

### `QuadOf`

**Краткое описание:** Разложите изображение ячейки в четыре приблизительных цвета.

**Параметры:** `Shown` (`const Cell &`, in); `Quad QuadOf(const Cell &Shown) noexcept`.

**Возвращает:** `Quad`: цвета подъячеек.

**Побочные эффекты:** Нет; память не выделяется.

**Как работает:** Для полного блока использует цвет глифа везде; для половин — соответствующее разделение foreground/background. Для трёх штриховок возвращает одинаковую смесь цветов во всех позициях, вычисляя долю краски по битам шрифта. Для остальных глифов, включая буквы, возвращает фон во всех четырёх позициях.

**Примечания:** Игнорирует `VisibilityMode`, отметку и каретку; прозрачность учитывается только в самих значениях цвета. Произвольная ячейка с флагом `Transparent` и обычными цветами не превращается здесь в четыре `Through`.

**Пример:**

```cpp
#include "painter/tui/subcell.h"

namespace tui = painter::tui;
namespace core = painter::core;

tui::Quad Example(const tui::Cell &Value) { return tui::QuadOf(Value); }
```

### `ResolveQuad`

**Краткое описание:** Выберите глиф и два цвета для приближённого изображения четырёх подъячеек.

**Параметры:** `Wanted` (`const Quad &`, in); `Glass` (`GlassKind`, in); `Cell ResolveQuad(const Quad &Wanted, GlassKind Glass) noexcept`.

**Возвращает:** `Cell`: непрозрачная по флагу ячейка без отметки; цвета могут быть прозрачными или полупрозрачными.

**Побочные эффекты:** Нет; память не выделяется.

**Как работает:** Для четырёх одинаковых цветов возвращает пробел с этим цветом. Иначе сравнивает верхний полублок, левый полублок и один цвет; ошибка учитывает взвешенное RGB-расстояние и различие непрозрачности. В режиме Pixels при полностью непрозрачных цветах дополнительно проверяет штриховки; штраф за текстуру уменьшает их предпочтительность. Плотность штриховок читается из фактического шрифта.

**Примечания:** При равенстве ошибок сохраняется более ранний кандидат: верхний полублок, затем левый, затем один цвет. Для Text средний RGB заменяется ближайшим цветом из соответствующей группы входа; при равенстве предпочитается более редкий в Quad. Это не общий квантователь в VGA-палитру.

**Типичное применение:** Используйте через `FineCanvas::PutQuad` или самостоятельно передайте результат в `Frame::Put`.

**Пример:**

```cpp
#include "painter/tui/subcell.h"

namespace tui = painter::tui;
namespace core = painter::core;

tui::Cell Example(const tui::Quad &Wanted) { return tui::ResolveQuad(Wanted, tui::GlassKind::Pixels); }
```
