# Painter

## Назначение

Painter — семейство библиотек BoxOS для всего, что программа показывает
человеку. Оно стоит над boxcxx и boxlib и говорит с DisplayServer
(`display.elf`) — единственным, кто рисует на экране. Ядро ничего не
рисует.

Исходники: [src/userspace/painter](../../../src/userspace/painter/README.md),
архив `libpainter.a`.

## Части

- [painter::tui](tui/README.md) — программы из текстовых ячеек: сцена на весь экран, панели поверх консоли, рисунки, которые остаются в выводе. Работает и на текстовой странице VGA, и на framebuffer.
- [painter::gui](gui/README.md) — программы из элементов: текст, фигуры, картинки, холсты своих пикселей. Программа говорит, *что* показывает; дисплей сам рисует, анимирует, ведёт фокус клавиатуры и следит за темой.
- [painter::core](core/README.md) — общие типы (геометрия, цвет) и движок рисования пикселей: `Canvas`, `Path`, градиенты, картинки, маски, тени, текст. Им рисует дисплей, им же программа рисует на своём холсте.
- [painter::items](items/README.md) — чтение языка элементов и внешний вид ролей; общая часть дисплея и `painter::gui`. Программам напрямую не нужна.

Текст набирает [Typecase](../typecase/README.md) (`src/userspace/typecase`):
шрифты, раскладка строк, кернинг. Painter его рисует.

## Что выбрать

- Игра, утилита, редактор в стиле терминала, всё, что должно работать и на текстовой странице, — `painter::tui`.
- Интерфейс с кнопками, полями, плавными анимациями, крупным текстом разных размеров — `painter::gui` (элементы как объекты или кадр целиком).
- Своя растровая графика (фракталы, эффекты, игры с пикселями) — холст `painter::gui::Canvas`, на котором рисует `painter::core::Canvas`.

Части можно сочетать: клавиатура `painter::tui::Keyboard` передаётся в
`painter::gui::Area::Wait`; сетка ячеек — тоже элемент `painter::gui`.

## Слои системы

- boxlib — интерфейс C и низкоуровневые вызовы BoxOS;
- boxcxx — среда выполнения C++ и стандартная библиотека;
- DisplayServer — консоль, маршрутизация клавиатуры, компоновка экрана;
- Painter — графика для программ и клиент языка элементов;
- программы — свои модели данных поверх Painter.
