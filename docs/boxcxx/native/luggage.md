# box::luggage

## Назначение

Заголовок: [`box/cxx/luggage.h`](../../../src/userspace/boxcxx/include/box/cxx/luggage.h).
C-основа: `box/luggage.h`.

**Luggage** — то, что сказал запустивший программе при посадке. Когда
человек набирает `say hello   world`, ядро кладёт эту строку, как она
набрана, в кабину новой программы до её первой инструкции: не отправлена,
не получена — просто есть, без ограничений, кроме памяти. Слово 0 — имя
самой программы.

`main` в BoxOS вызывается с `argc = 0`, `argv = nullptr`: аргументы берут
отсюда. Чаще всего удобнее объявить Form ([form](../form.md)) — тогда
оболочка сама разложит слова по полям, и программа строку не разбирает;
Luggage нужен, когда программа хочет свою строку целиком.

Слова режутся один раз при первом обращении и принадлежат кабине: соседние
нити видят ту же строку.

## Функции

### `luggage::line`

**Краткое описание:** Возвращает всю строку как она набрана.

**Параметры:** Нет.

**Возвращает:** (`std::string_view`) пусто, если ничего не дали.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include <print>

#include "box/cxx/luggage.h"

void Echo() { std::println("меня запустили так: {}", box::luggage::line()); }
```

### `luggage::size` / `luggage::empty`

**Краткое описание:** Возвращают число слов и признак, что слов нет.

**Параметры:** Нет.

**Возвращает:** (`std::size_t`) / (`bool`). Слова разделяются пробелами, «кавычки» группируют.

**Побочные эффекты:** Первый вызов режет слова.

**Пример:**
```cpp
#include "box/cxx/luggage.h"

bool NoArguments() { return box::luggage::size() <= 1; }
```

### `luggage::word`

**Краткое описание:** Возвращает слово по номеру без кавычек.

**Параметры:** `i` (`std::size_t`): 0 — имя программы.

**Возвращает:** (`std::string_view`) пусто за последним словом.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "box/cxx/luggage.h"

std::string_view First() { return box::luggage::word(1); }
```

### `luggage::tail`

**Краткое описание:** Возвращает строку от слова `from` до конца как она набрана.

**Параметры:** `from` (`std::size_t`).

**Возвращает:** (`std::string_view`).

**Побочные эффекты:** Нет.

**Типичное применение:** Программа вроде `say`, которой нужен весь остаток строки с пробелами.

**Пример:**
```cpp
#include "box/cxx/luggage.h"

std::string_view Message() { return box::luggage::tail(1); }
```

### `luggage::words`

**Краткое описание:** Возвращает все слова по порядку.

**Параметры:** Нет.

**Возвращает:** (`std::vector<std::string_view>`).

**Побочные эффекты:** Выделяет вектор.

**Пример:**
```cpp
#include <print>

#include "box/cxx/luggage.h"

void List()
{
    for (std::string_view Word : box::luggage::words()) std::println("[{}]", Word);
}
```
