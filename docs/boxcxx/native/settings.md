# box::settings

## Назначение

Заголовок: [`box/cxx/settings.h`](../../../src/userspace/boxcxx/include/box/cxx/settings.h).
C-основа: `box/settings.h`, формат — `settings_reader.h`.

Настройки программы: что человек в ней выставил.

**Что можно настроить**, программа объявляет один раз, в своём образе,
макросом `BOX_SETTINGS` — деревом «вещей» и их свойств:

```cpp
#include "box/settings.h"

BOX_SETTINGS("hours one-of 24 12 default 24 \"how the hours are counted\"\n"
             "seconds on-or-off default on \"whether the seconds are shown\"\n"
             "digits \"the digits of the time\"\n"
             "    color color default #E6E6E6 \"their color\"\n");
```

Каждая строка — `ИМЯ ВИД [что виду нужно] default ЗНАЧЕНИЕ [next-start]
"что делает"`, или `ИМЯ "что содержит"` для вещи, которая только держит
строки с отступом под ней. Виды: `on-or-off`, `number from A to B [ЕДИНИЦА]
[or off | or all]`, `word`, `text`, `one-of W1 W2 …`, `color`, `key`.
Инструменты сборки отвергают строку, которую не смогли прочитать.
Объявление — единственный источник правды: по нему утилита `settings` и
`help` показывают настройки, по нему проверяются значения, его значения по
умолчанию действуют, пока человек их не изменит. Заголовок `settings`
макрос добавляет сам.

**Что выбрал человек** — файл `<программа>.settings` на томе, только с тем,
что изменено. Его пишет утилита (`settings clock digits color amber`) или
человек вручную; программа сама его никогда не пишет:

```text
digits
    color  amber
seconds off
[work]
    hours 12
```

Настройка называется путём — именами сверху вниз через пробел:
`"digits color"`. Блок `[ТЕГИ]` действует, пока Use Context ([use](use.md))
содержит все его теги: из нескольких подходящих — блок с большим числом
тегов, при равенстве — записанный последним. Ошибка в строке файла никогда
не останавливает программу: настройка сохраняет значение, а строка
называется среди проблем.

Запрос пути, которого программа не объявила, или запрос не того вида —
ошибка программы: о ней сообщается один раз, а ответ — `false`, 0, `""`,
чёрный или «нет клавиши».

## Чтение

### `settings::on` / `number` / `word` / `text` / `choice` / `color` / `key`

**Краткое описание:** Возвращают значение настройки по пути.

**Параметры:**
- `path` (`const char *`): путь, например `"digits color"`.

**Возвращает:** `on` — (`bool`); `number` — (`std::int64_t`), 0 означает `off` или `all` (как объявлено); `word`, `text`, `choice` — (`std::string`) копия; `color` — (`std::uint32_t`) 0xRRGGBB; `key` — (`KeyChord`) клавиша с Ctrl или Alt (`key_chord.h`), все нули — нет.

**Побочные эффекты:** При первом обращении читают файл настроек (он ищется по имени программы везде на томе).

**Пример:**
```cpp
#include "box/cxx/settings.h"

bool ShowSeconds() { return box::settings::on("seconds"); }
std::uint32_t DigitColor() { return box::settings::color("digits color"); }
```

### `settings::reload`

**Краткое описание:** Перечитывает файл человека и Use Context.

**Параметры:** Нет.

**Возвращает:** (`bool`) изменилось ли какое-нибудь действующее значение.

**Побочные эффекты:** Читает файл; текст, который вернули прежние вызовы C-уровня, больше недействителен (копии `std::string` остаются).

**Пример:**
```cpp
#include "box/cxx/settings.h"

bool Refresh() { return box::settings::reload(); }
```

## Наблюдение

### `settings::watch`

**Краткое описание:** Следит за файлом настроек и Use Context на этой нити.

**Параметры:** Конструктор по умолчанию.

**Возвращает:** Неприменимо: класс; только перемещение. `operator bool` — подписки удались.

**Побочные эффекты:** Заявляет Touch на имени программы (его носит файл настроек) и на слове контекста; снимает при уничтожении.

**Пример:** См. `watch::changed`.

### `watch::changed`

**Краткое описание:** Сообщает, сохранили ли файл или сменился контекст с прошлой проверки так, что действующее значение изменилось.

**Параметры:** Нет.

**Возвращает:** (`bool`); без подписок — всегда `false`.

**Побочные эффекты:** Не ждёт; перечитывает файл, только если он был сохранён целиком.

**Типичное применение:** Программа, рисующая в цикле, спрашивает раз за оборот и перечитывает то, что показывает.

**Пример:**
```cpp
#include "box/cxx/settings.h"

void Loop()
{
    box::settings::watch Watch;
    bool Seconds = box::settings::on("seconds");
    for (int Turn = 0; Turn < 1000; Turn++) {
        if (Watch.changed()) Seconds = box::settings::on("seconds");
        (void)Seconds;   // ... нарисовать кадр
    }
}
```
