# box::executor

## Назначение

Заголовок: [`box/cxx/executor.h`](../../../src/userspace/boxcxx/include/box/cxx/executor.h).

Кооперативная асинхронность для сопрограмм C++ в духе BoxOS. Это не цикл
событий Unix (нет epoll, select, файловых дескрипторов): это цикл одной
нити, который возобновляет сопрограмму, когда её источник событий BoxOS
готов, пользуясь его собственной парой «проверить без ожидания / ждать».

- `box::task<T>` — ленивая сопрограмма, возвращающая `T`;
- `box::executor` — цикл выполнения (один на нить);
- ожидания: `box::touch_event()`, `box::brook_read(b, frame)`, `box::pocket_recv()`, `box::after(d)`, `box::until(tp)`; в других заголовках — `subscription::next()` ([touch](touch.md)), `next_message()`, `call()`, `result_any()` ([message](message.md)), `strand::completion()` ([strand](strand.md)), ожидания [brook](brook.md), [current](current.md), [ferry](ferry.md).

Параллельность настоящая — соседние нити кабины ([strand](strand.md)) и
другие ядра производят события. Когда **все** сопрограммы цикла ждут,
нити нечего делать, и цикл действительно засыпает в ядре, а не крутится:

- ожидания кольца результатов (сообщения, ответы ядра), таймеры и ожидание нити — один настоящий сон до ближайшего срока, его прерывает межпроцессорное прерывание;
- ожидания Touch и Brook (следят за своей кэш-линией через UMWAIT, а производитель может быть соседней нитью на том же ядре) — короткие сны по очереди по 16 мс с проверкой между ними и уступкой процессора; без пустого кручения и без потерянных пробуждений.

## task

### `box::task<T>`

**Краткое описание:** Ленивая сопрограмма с результатом `T` (или `void`).

**Параметры:** Создаётся вызовом функции-сопрограммы с типом возврата `box::task<T>` (`co_return` значения).

**Возвращает:** Неприменимо: класс; только перемещение; владеет кадром сопрограммы.

**Побочные эффекты:** Ничего не выполняет, пока не запущена: `co_await` из другой сопрограммы или `executor::block_on`/`spawn`.

**Как работает:** `co_await` задачи — симметричная передача управления в её кадр; по окончании управление возвращается ожидающему без роста стека. Исключение, вылетевшее из сопрограммы, сохраняется и перебрасывается в ожидающем.

**Пример:**
```cpp
#include "box/cxx/executor.h"

box::task<int> Answer() { co_return 42; }

box::task<int> Twice()
{
    const int A = co_await Answer();
    co_return A * 2;
}
```

### `task::done` / `task::result` / `task::handle` / `task::release`

**Краткое описание:** Сообщают, закончена ли задача, забирают результат, возвращают и отпускают дескриптор сопрограммы.

**Параметры:** Нет.

**Возвращает:** `done` — (`bool`); `result` — (`T`), перебрасывает сохранённое исключение; `handle` — (`std::coroutine_handle<>`); `release` — дескриптор, задача больше им не владеет.

**Побочные эффекты:** `result` на незаконченной задаче без значения — аварийная остановка (`__builtin_trap`).

**Пример:**
```cpp
#include "box/cxx/executor.h"

box::task<int> Answer() { co_return 42; }

int Sync()
{
    box::executor Loop;
    return Loop.block_on(Answer());
}
```

## executor

### `box::executor`

**Краткое описание:** Кооперативный цикл выполнения сопрограмм одной нити.

**Параметры:** Конструктор по умолчанию; копировать нельзя.

**Возвращает:** Неприменимо: класс.

**Побочные эффекты:** Деструктор уничтожает отсоединённые сопрограммы, которые не были доведены.

**Пример:** См. `executor::run`.

### `executor::current`

**Краткое описание:** Возвращает цикл, который сейчас выполняется в этой нити.

**Параметры:** Нет.

**Возвращает:** (`executor *`) или `nullptr` вне `run`.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "box/cxx/executor.h"

bool Inside() { return box::executor::current() != nullptr; }
```

### `executor::spawn`

**Краткое описание:** Забирает задачу и ставит её в очередь «запустил и забыл».

**Параметры:**
- `t` (`task<T>`): задача; результат отбрасывается.

**Возвращает:** `void`.

**Побочные эффекты:** Цикл владеет кадром.

**Пример:** См. `executor::run`.

### `executor::run`

**Краткое описание:** Ведёт цикл, пока есть готовые или ждущие сопрограммы.

**Параметры:** Нет.

**Возвращает:** `void`.

**Побочные эффекты:** Возобновляет сопрограммы, засыпает в ядре, когда все ждут. На любом выходе (и при исключении) восстанавливает `current()` и уничтожает отсоединённые кадры.

**Пример:**
```cpp
#include <chrono>
#include <print>

#include "box/cxx/executor.h"

box::task<void> Tick(int Id)
{
    using namespace std::chrono_literals;
    for (int I = 0; I < 3; I++) {
        co_await box::after(100ms);
        std::println("задача {} шаг {}", Id, I);
    }
}

void Both()
{
    box::executor Loop;
    Loop.spawn(Tick(1));
    Loop.spawn(Tick(2));
    Loop.run();
}
```

### `executor::block_on`

**Краткое описание:** Выполняет одну корневую задачу до конца и возвращает её результат.

**Параметры:**
- `t` (`task<T>`).

**Возвращает:** (`T`); перебрасывает исключение задачи.

**Побочные эффекты:** Как у `run`.

**Пример:** См. `task::result`.

### `executor::schedule` / `executor::wait_on`

**Краткое описание:** Ставят сопрограмму в очередь и регистрируют ожидание источника событий.

**Параметры:**
- `schedule(std::coroutine_handle<>)`.
- `wait_on(h, self, poll, block, domain, deadline_tsc = 0, accept_any = false)`: `poll(self)` — проверить без ожидания (true — можно возобновить), `block(self, ms)` — ждать до `ms` (0 — без предела), `domain` — линия ожидания (`touch`, `result`, `brook`, `timer`, `join`), `deadline_tsc` — абсолютный срок, `accept_any` — ожидание забирает любую запись кольца результатов.

**Возвращает:** `void`.

**Побочные эффекты:** Меняют очереди цикла.

**Примечания:** Нужны авторам собственных объектов ожидания. Правило «защёлки»: если `block` уже забрал событие, следующий `poll` должен сообщить готовность по сохранённому значению, а не читать источник снова — иначе событие потеряется. Метка `result` — обещание, что источник доставляется через кольцо результатов с прерыванием; ошибочная метка повесит одно ядро навсегда.

**Пример:** См. объекты ожидания в [touch](touch.md).

## Ожидания

### `box::after` / `box::until`

**Краткое описание:** Усыпляют сопрограмму на длительность или до момента времени.

**Параметры:**
- `after(std::chrono::duration)`: неположительная — готово сразу; меньше такта часов — округляется вверх.
- `until(std::chrono::time_point)`: точно для `steady_clock`; для других часов остаток пересчитывается на `steady_clock`.

**Возвращает:** Объект ожидания (`timer_await`), дающий `void`.

**Побочные эффекты:** Сопрограмма засыпает; соседние сопрограммы работают.

**Пример:** См. `executor::run`.

### `box::touch_event`

**Краткое описание:** Ждёт следующее событие Touch любого тега, пришедшее в кабину.

**Параметры:** Нет.

**Возвращает:** Объект ожидания, дающий `Touch`.

**Побочные эффекты:** Забирает событие из общего кольца без склада по тегам.

**Примечания:** Не смешивайте с `box::subscription` в одной кабине; для событий одного тега используйте `subscription::next()`.

**Пример:**
```cpp
#include "box/cxx/executor.h"

box::task<void> AnyEvent()
{
    Touch Event = co_await box::touch_event();
    (void)Event;
}
```

### `box::brook_read`

**Краткое описание:** Ждёт следующий кадр потока Brook.

**Параметры:**
- `b` — поток (`Brook *` boxlib), `frame` — буфер размером `brook_frame_size(b)` байт, принадлежит вызывающему.

**Возвращает:** Объект ожидания, дающий `int`: `OK` или `-ERR_STREAM_CLOSED`, когда писатель ушёл и кольцо опустело (это окончание без гонок, а не EOF Unix), или другая отрицательная ошибка.

**Побочные эффекты:** Забирает кадр.

**Примечания:** Типизированная обёртка — [brook](brook.md).

**Пример:** См. [brook](brook.md).

### `box::pocket_recv`

**Краткое описание:** Ждёт следующий ответ Pocket/IPC.

**Параметры:** Нет.

**Возвращает:** Объект ожидания, дающий `Result`.

**Побочные эффекты:** Забирает запись кольца результатов.

**Примечания:** Для сообщений удобнее `box::next_message()` ([message](message.md)).

**Пример:**
```cpp
#include "box/cxx/executor.h"

box::task<void> Reply()
{
    Result Got = co_await box::pocket_recv();
    (void)Got;
}
```
