# box::strand

## Назначение

Заголовок: [`box/cxx/strand.h`](../../../src/userspace/boxcxx/include/box/cxx/strand.h).
C-основа: `box/strand.h`, `box/sync.h`, `box/core/strand_self.h`.

**Нить** (strand) — дополнительный контекст выполнения внутри кабины
вызывающего: общее адресное пространство, куча, код и кольца IPC, но свой
стек и состояние планировщика. `std::thread` в BoxOS — это уже нить; этот
заголовок называет основу прямо и добавляет то, чего не выразить в `std`:

- `box::strand` — как `std::thread`, но деструктор **ждёт** нить (join), а не вызывает `std::terminate`;
- `box::spawn_detached` и `box::this_strand::exit` — нить без ожидающего;
- `box::park` / `box::wake` — примитив ядра «уснуть на слове памяти» (аналог futex);
- `box::this_strand` — id, уступить процессор, главная ли это нить;
- `box::strand_watch` — наблюдение за жизненным циклом всех нитей системы.

Планирование: отдельных приоритетов у нити нет — в BoxOS это свойство
кабины, им управляют теги процесса ([process](process.md)). Единственный
рычаг на уровне нити — добровольное `this_strand::yield()`.

## park и wake

### `box::park_status`

**Краткое описание:** Называет, почему вернулся `box::park`.

**Параметры:**
- `woke` — соседняя нить разбудила это слово (проверьте условие ещё раз: пробуждение может быть «пустым»).
- `timeout` — время вышло.
- `value_mismatch` — слово уже отличалось от ожидаемого в момент вызова; сна не было — то, чего вы ждали, уже произошло.
- `error` — ошибка ядра (например, плохой адрес).

**Возвращает:** Неприменимо: перечисление.

**Побочные эффекты:** Нет.

**Пример:** См. `box::park`.

### `box::park`

**Краткое описание:** Усыпляет нить на 8-байтовом слове, пока соседняя нить его не изменит и не разбудит.

**Параметры:**
- `a` (`const std::atomic<T> &`): слово; `T` — 8 байт, тривиально копируемый, без байтов-заполнителей (`uint64_t`, `int64_t`, указатель). Проверяется на этапе компиляции.
- `expected` (`T`): значение, которое слово должно иметь, чтобы нить уснула.
- `timeout_ms` (`std::uint32_t`): предел, 0 — без предела.
- Низкоуровневая перегрузка: `park(const volatile void *addr, std::uint64_t expected, std::uint32_t timeout_ms = 0)` — любое выровненное 8-байтовое слово.

**Возвращает:** (`park_status`).

**Побочные эффекты:** Блокирует нить.

**Как работает:** Ядро сравнивает слово с `expected` в момент засыпания, поэтому пробуждение не теряется. Ядро переводит виртуальный адрес в физическую страницу и спит на ней: две кабины, спящие на одной общей странице, встречаются правильно, а слово на частном стеке уникально для своей нити. Слово должно оставаться отображённым на всё время сна.

**Примечания:** Для слов уже 8 байт используйте `std::atomic<T>::wait`/`notify`.

**Пример:**
```cpp
#include <atomic>

#include "box/cxx/strand.h"

std::atomic<std::uint64_t> Ready{0};

void Waiter()
{
    while (Ready.load() == 0) (void)box::park(Ready, std::uint64_t{0});
}

void Signaller()
{
    Ready.store(1);
    (void)box::wake_all(Ready);
}
```

### `box::park_for`

**Краткое описание:** Усыпляет нить на слове не дольше заданной длительности `std::chrono`.

**Параметры:**
- `a` (`const std::atomic<std::uint64_t> &`), `expected` (`std::uint64_t`).
- `d` (`std::chrono::duration`): округляется вверх до миллисекунд, меньше миллисекунды — до одной, ограничивается `UINT32_MAX`.

**Возвращает:** (`park_status`); неположительная длительность — сразу `timeout` без проверки слова.

**Побочные эффекты:** Блокирует нить.

**Пример:**
```cpp
#include <chrono>

#include "box/cxx/strand.h"

bool WaitASecond(const std::atomic<std::uint64_t> &Flag)
{
    using namespace std::chrono_literals;
    return box::park_for(Flag, 0, 1s) != box::park_status::timeout;
}
```

### `box::wake` / `wake_one` / `wake_all`

**Краткое описание:** Будят нити, спящие на слове.

**Параметры:**
- `a` (`const std::atomic<T> &`) или `addr` (`const volatile void *`).
- `count` (`std::uint32_t`): сколько разбудить, 0 — всех; `wake_one` — одну, `wake_all` — всех.

**Возвращает:** (`bool`) ядро приняло пробуждение.

**Побочные эффекты:** Пробуждает нити.

**Пример:** См. `box::park`.

## strand

### `box::strand`

**Краткое описание:** Нить с семантикой `std::thread`, которую деструктор дожидается, а не убивает программу.

**Параметры:**
- `strand()` — пустая.
- `strand(F &&f, Args &&...args)` (`explicit`): запускает `f(args...)` в новой нити; аргументы копируются (decay-copy) как у `std::thread`.

**Возвращает:** Неприменимо: класс; только перемещение. Перемещающее присваивание сначала дожидается прежней нити.

**Побочные эффекты:** Создаёт нить; бросает `std::system_error`, если у ядра нет места для нити.

**Как работает:** Класс содержит `std::thread`: запуск, деструкторы `thread_local` и безопасное ожидание взяты оттуда без изменений; отличается только политика времени жизни.

**Примечания:** Ловушка «ожидание в деструкторе»: если объект уничтожается, пока нить ждёт того, кто его уничтожает, программа повиснет — ровно как при явном `join()`. Сначала дайте нити закончиться (сигнал, флаг).

**Пример:**
```cpp
#include <atomic>
#include <print>

#include "box/cxx/strand.h"

int SumInParallel()
{
    std::atomic<int> Total{0};
    {
        box::strand Left([&] { for (int I = 0; I < 500; I++) Total += I; });
        box::strand Right([&] { for (int I = 500; I < 1000; I++) Total += I; });
    }   // обе нити дождались здесь
    return Total.load();
}
```

### `joinable` / `join` / `detach` / `get_id` / `native_handle` / `swap`

**Краткое описание:** Как у `std::thread`.

**Параметры:** Нет (`swap` — другая нить).

**Возвращает:** `joinable` — (`bool`); `get_id` — (`strand::id`); `native_handle` — pid нити; остальные — `void`.

**Побочные эффекты:** `join` блокирует и бросает `std::system_error`, если ждать нечего; `detach` отпускает нить без надзора.

**Пример:**
```cpp
#include "box/cxx/strand.h"

void Background(box::strand &Worker) { if (Worker.joinable()) Worker.detach(); }
```

### `strand::completion`

**Краткое описание:** Возвращает объект ожидания для `co_await`: сопрограмма засыпает, пока нить не завершится.

**Параметры:** Нет.

**Возвращает:** (`completion_await`).

**Побочные эффекты:** Ничего не «забирает»: нить остаётся joinable, ожидание делает деструктор или `join`.

**Примечания:** `co_await` на нити, которую ждать нечего, бросает `std::system_error(invalid_argument)`. Объект нити должен пережить ожидание и не перемещаться и не уничтожаться из другой нити, пока сопрограмма ждёт. Работает внутри [executor](executor.md).

**Пример:**
```cpp
#include "box/cxx/executor.h"
#include "box/cxx/strand.h"

box::task<void> AfterWork(box::strand &Worker)
{
    co_await Worker.completion();
}
```

### `strand::hardware_concurrency` / `strand::make_id`

**Краткое описание:** Возвращают число ядер приложений и превращают pid в `strand::id`.

**Параметры:** `make_id(std::uint32_t pid)`.

**Возвращает:** (`unsigned`) ядра, способные идти параллельно (0 — неизвестно); (`strand::id`).

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "box/cxx/strand.h"

unsigned Workers() { return box::strand::hardware_concurrency(); }
```

### `strand::id`

**Краткое описание:** Идентичность нити — её pid ядра.

**Параметры:** `id()` — «не нить» (pid 0).

**Возвращает:** Неприменимо: класс; `==`, `<=>`, `native()` — pid, явное преобразование в `std::thread::id`; есть `std::hash` и `std::formatter` (десятичный pid).

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include <format>

#include "box/cxx/strand.h"

std::string Name() { return std::format("нить {}", box::this_strand::id()); }
```

## Нити без ожидающего

### `box::spawn_detached`

**Краткое описание:** Запускает нить без дескриптора ожидания.

**Параметры:**
- `f`, `args`: как у `strand`.

**Возвращает:** (`strand::id`) — дескриптор наблюдения (для сравнения с событиями `strand_watch`), действителен до `strand:exited`; управлять нитью через него нельзя.

**Побочные эффекты:** Создаёт нить; бросает `std::system_error`, если места нет. Ядро освобождает pid, когда нить кончится.

**Пример:**
```cpp
#include "box/cxx/strand.h"

void Heartbeat() { (void)box::spawn_detached([] { /* фоновая работа */ }); }
```

### `this_strand::exit`

**Краткое описание:** Завершает текущую нить сразу, выполнив её деструкторы `thread_local`.

**Параметры:** Нет.

**Возвращает:** Не возвращает (`[[noreturn]]`).

**Побочные эффекты:** Завершает нить; стек **не раскручивается** — автоматические объекты и захваченные аргументы не уничтожаются.

**Примечания:** Допустимо только в нити из `spawn_detached`. В главной нити — `std::terminate` (главная нить завершается возвратом из `main`, чтобы прошли статические деструкторы). В нити `box::strand`/`std::thread` — неопределённое поведение: ожидающий уснёт навсегда.

**Пример:**
```cpp
#include "box/cxx/strand.h"

void Worker(bool Done) { if (Done) box::this_strand::exit(); }
```

## this_strand

### `this_strand::id` / `yield` / `is_main` / `info`

**Краткое описание:** Возвращают id текущей нити, уступают процессор, сообщают, главная ли нить, и возвращают её сведения.

**Параметры:** Нет.

**Возвращает:** `id` — (`strand::id`), у главной нити — pid кабины; `yield` — `void`; `is_main` — (`bool`); `info` — (`strand_info{id, is_main}`), никогда не неудача.

**Побочные эффекты:** `yield` отдаёт процессор.

**Пример:**
```cpp
#include "box/cxx/strand.h"

bool OnMain() { return box::this_strand::is_main(); }
```

## Наблюдение за нитями

### `strand_spawned` / `strand_exited` / `strand_parked` / `strand_woken`

**Краткое описание:** Раскладывают полезную нагрузку системных Touch-событий жизненного цикла нитей байт в байт.

**Параметры:**
- `strand_spawned`, `strand_exited` (8 байт): `pid` — нить; `cabin_pid` — **запускатель** кабины, а не её собственный pid.
- `strand_parked` (12 байт, упаковано): `phys` — физическая страница, `pid`.
- `strand_woken` (16 байт): `phys`, `pid`, `waker_pid` — кто разбудил.

**Возвращает:** Неприменимо: структуры.

**Побочные эффекты:** Нет.

**Пример:** См. `strand_watch`.

### `strand_touch` / `strand_touch_kind`

**Краткое описание:** Одно разобранное событие с видом и данными.

**Параметры:**
- `kind` (`strand_touch_kind`: `spawned`, `exited`, `parked`, `woken`), `source` (pid отправителя — ядро), объединение с данными; `strand_pid()` — pid нити при любом виде.

**Возвращает:** Неприменимо: структура.

**Побочные эффекты:** Нет.

**Пример:** См. `strand_watch`.

### `box::strand_watch`

**Краткое описание:** Наблюдает за жизненным циклом нитей всей системы через четыре тега `strand:*`.

**Параметры:** Конструктор по умолчанию подписывается на `strand:spawned`, `strand:exited`, `strand:parked`, `strand:woken`.

**Возвращает:** Неприменимо: класс; только перемещение; `operator bool` — все четыре подписки удались.

**Побочные эффекты:** Держит четыре подписки ([touch](touch.md)).

**Примечания:** События системные: видны нити всех кабин. Подписка доставляет события только той нити, которая подписалась; у каждой нити — свой `strand_watch`.

**Пример:**
```cpp
#include <print>

#include "box/cxx/strand.h"

void Spy()
{
    box::strand_watch Watch;
    if (!Watch) return;
    for (int Seen = 0; Seen < 10;)
        if (auto Event = Watch.wait(1000)) {
            std::println("нить {} — событие {}", Event->strand_pid(), static_cast<int>(Event->kind));
            Seen++;
        }
}
```

### `set_filter_cabin` / `poll` / `wait` / `next`

**Краткое описание:** Фильтруют события по кабине, забирают событие без ожидания, ждут его и ждут в сопрограмме.

**Параметры:**
- `spawner_pid` (`std::uint32_t`): оставить только `spawned`/`exited` кабин этого запускателя; 0 — без фильтра (`parked`/`woken` не фильтруются).
- `ms` (`std::uint32_t`): для `wait`, 0 — без предела.

**Возвращает:** `poll`, `wait` — (`std::optional<strand_touch>`); `next` — объект ожидания для `co_await`, дающий `std::optional<strand_touch>`.

**Побочные эффекты:** Забирают события из подписок; `wait` блокирует.

**Как работает:** `poll` проверяет теги в постоянном порядке: spawned, exited, parked, woken. `wait` по очереди ждёт каждый тег короткими отрезками по 16 мс (у ядра пока нет ожидания «любого из N тегов»), поэтому может вернуться чуть позже срока.

**Примечания:** Одновременно не больше одного `co_await next()` на объект; объект должен пережить ожидание.

**Пример:** См. `strand_watch`.
