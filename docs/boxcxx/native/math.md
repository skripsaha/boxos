# box::math

## Назначение

Заголовок: [`box/cxx/math.h`](../../../src/userspace/boxcxx/include/box/cxx/math.h).

Удобный слой над `<cmath>`: логарифм по любому основанию, корень любой
степени, округление до знаков после запятой и тригонометрия в градусах и
оборотах — точная на «круглых» углах.

Здесь используются константы `std::kPi`, `std::kInf`, `std::kQNaN` —
расширение `<cmath>` boxcxx.

## Углы

### `box::angle` / `rad` / `deg` / `turn`

**Краткое описание:** Называют единицу угла.

**Параметры:** `angle::rad` (радианы), `angle::deg` (градусы), `angle::turn` (обороты); короткие `box::rad`, `box::deg`, `box::turn`.

**Возвращает:** Неприменимо: перечисление.

**Побочные эффекты:** Нет.

**Пример:** См. `box::sin`.

### `to_radians` / `from_radians`

**Краткое описание:** Переводят угол в радианы и обратно.

**Параметры:** `x` (`double`), `u` (`angle`).

**Возвращает:** (`double`).

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "box/cxx/math.h"

double Half() { return box::to_radians(0.5, box::turn); }   // π
```

### `box::sin` / `cos` / `tan`

**Краткое описание:** Тригонометрические функции с единицей угла.

**Параметры:** `x` (`double`), `u` (`angle`, по умолчанию радианы).

**Возвращает:** (`double`); не конечный аргумент в градусах/оборотах — NaN.

**Побочные эффекты:** Нет.

**Как работает:** Градусы и обороты сначала приводятся к четверти круга (`fmod` точен), а уже потом переводятся в радианы. Поэтому стороны света точны (`sin(180, deg)` — ровно 0, а не 1.2e-16), `tan` точен на каждом кратном 45°, и погрешность не растёт с величиной угла.

**Пример:**
```cpp
#include "box/cxx/math.h"

double Height(double Length, double Degrees) { return Length * box::sin(Degrees, box::deg); }
```

### `box::asin` / `acos` / `atan` / `atan2`

**Краткое описание:** Обратные тригонометрические функции с результатом в выбранной единице.

**Параметры:** `x` (`double`) или `y`, `x`; `u` (`angle`).

**Возвращает:** (`double`).

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "box/cxx/math.h"

double Heading(double Dx, double Dy) { return box::atan2(Dy, Dx, box::deg); }
```

## Логарифм, корень, округление

### `box::log`

**Краткое описание:** Возвращает натуральный логарифм или логарифм по основанию.

**Параметры:** `x` (`double`); `base` (`double`) — во второй перегрузке.

**Возвращает:** (`double`).

**Побочные эффекты:** Нет.

**Как работает:** Основания 2 и 10 идут через `std::log2`/`std::log10`, а не через отношение логарифмов: точные целые результаты для степеней двойки и десяти сохраняются.

**Пример:**
```cpp
#include "box/cxx/math.h"

double Bits(double Values) { return box::log(Values, 2); }
```

### `box::root`

**Краткое описание:** Возвращает корень степени `n`.

**Параметры:** `x`, `n` (`double`).

**Возвращает:** (`double`): `n == 2` — `sqrt`, `n == 3` — `cbrt`; `x == 0` — 0 (при `n > 0`) или бесконечность; отрицательный `x` — вещественный корень только для нечётного целого `n`, иначе NaN.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "box/cxx/math.h"

double Side(double Volume) { return box::root(Volume, 3); }
```

### `box::round`

**Краткое описание:** Округляет до заданного числа знаков после запятой.

**Параметры:** `x` (`double`); `digits` (`int`, по умолчанию 0): отрицательное — до кратного `10^-digits`.

**Возвращает:** (`double`); не конечное — без изменений.

**Побочные эффекты:** Нет.

**Как работает:** Округляется значение, которое double **действительно** хранит, — через точное десятичное преобразование, а не умножение на степень десяти (которое давало `round(2.675, 2) = 2.68`, но `round(1.005, 2) = 1.00` и переполнялось на краях диапазона). Точная середина округляется от нуля, как у `std::round`.

**Пример:**
```cpp
#include "box/cxx/math.h"

double Money(double Value) { return box::round(Value, 2); }
```
