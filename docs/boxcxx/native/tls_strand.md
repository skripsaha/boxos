# tls_strand

## Назначение

Заголовок: [`box/cxx/tls_strand.h`](../../../src/userspace/boxcxx/include/box/cxx/tls_strand.h).

Деструкторы `thread_local` нити. Ядро создаёт локальное хранилище нити
(TLS) из шаблона программы ещё до первой инструкции нити — у главной и у
каждой порождённой, — поэтому `thread_local` читает начальное значение без
предварительного кода. На долю нити остаётся конец времени жизни: точка
входа нити вызывает `__boxcxx_thread_storage_enter()` до работы и
`__boxcxx_thread_storage_exit()` перед `strand_exit()`, чтобы выполнились
деструкторы её `thread_local`.

Это контракт, который оборачивают `std::thread`, `box::strand` и
`box::spawn_detached` ([strand](strand.md)). Вызывать функции вручную нужно
только в «сырой» нити, запущенной `strand_spawn` из boxlib.

## Функции

### `__boxcxx_thread_storage_enter`

**Краткое описание:** Взводит реестр деструкторов `thread_local` текущей нити.

**Параметры:** Нет.

**Возвращает:** `void`.

**Побочные эффекты:** Сейчас ничего (голова реестра лежит в обнулённом TLS нити); оставлено для симметрии и будущей подготовки нити.

**Пример:** См. `__boxcxx_thread_storage_exit`.

### `__boxcxx_thread_storage_exit`

**Краткое описание:** Выполняет и освобождает все деструкторы `thread_local` текущей нити в обратном порядке.

**Параметры:** Нет.

**Возвращает:** `void`.

**Побочные эффекты:** Уничтожает объекты `thread_local` нити.

**Примечания:** Вызывать ровно один раз — непосредственно перед завершением нити (для главной — перед статическими деструкторами при выходе процесса, это делает рантайм).

**Пример:**
```cpp
#include "box/cxx/tls_strand.h"
#include "box/strand.h"

void RawWorker(void *)
{
    __boxcxx_thread_storage_enter();
    // ... работа нити, может использовать thread_local
    __boxcxx_thread_storage_exit();
    strand_exit();
}
```
