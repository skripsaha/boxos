# box::ferry

## Назначение

Заголовок: [`box/cxx/ferry.h`](../../../src/userspace/boxcxx/include/box/cxx/ferry.h).

Асинхронный файловый ввод-вывод для сопрограмм. `box::tagfs::file::read_async`
и `write_async` ([tagfs](tagfs.md)) ставят операцию хранилища в очередь,
**не блокируя**, и возвращают `box::ferry` — дескриптор, который ждут через
`co_await` в [executor](executor.md) и получают число байтов или причину
ошибки, когда диск закончит. Одновременно в полёте могут быть несколько
паромов; каждый `co_await` возобновляет свою сопрограмму, когда приходит
завершение **именно его** операции, в каком бы порядке диск их ни отдавал.

Как это устроено:

- **путевой лист**: каждой операции нить выдаёт монотонный, никогда не повторяющийся номер, и ядро возвращает его в завершении. Завершения хранилища помечены флагом `KCTX_STORAGE` и никогда не путаются с сообщениями или обычными ответами ядра;
- **паромная станция** (своя у каждой нити) хранит открытые операции и раздаёт каждому парому только его груз. Завершения хранилища полностью изолированы: все остальные потребители кольца результатов (синхронный `fread`, `box::result_any`, приём IPC) откладывают их для станции;
- станция **владеет блоком отправки** (манифест и дескрипторы), пока не придёт завершение, потому что ядро читает их асинхронно. Поэтому уничтожить паром можно в любой момент: это неблокирующее отсоединение без обращения к освобождённой памяти.

Буфер данных — ваш, и ядро пишет в него по DMA всё время операции: он
должен пережить `co_await`.

Ограничения: станция локальна для нити — `co_await` парома только в той
нити, которая его создала. Не вызывайте `box::result_any()` в нити, где
летят паромы.

## Класс ferry

### `box::ferry`

**Краткое описание:** Дескриптор асинхронной файловой операции для `co_await`.

**Параметры:** Создаётся `read_async` / `write_async`; `ferry()` — пустой.

**Возвращает:** Неприменимо: класс; только перемещение.

**Побочные эффекты:** Деструктор отсоединяет операцию (она доработает, станция освободит её блок).

**Пример:**
```cpp
#include <array>
#include <cstddef>

#include "box/cxx/executor.h"
#include "box/cxx/ferry.h"
#include "box/cxx/tagfs.h"

box::task<std::size_t> TwoBlocks(box::tagfs::file Log)
{
    std::array<std::byte, 512> A{}, B{};
    box::ferry First  = Log.read_async(0, A);     // обе операции уже в полёте
    box::ferry Second = Log.read_async(512, B);
    box::result<std::size_t> N1 = co_await First;
    box::result<std::size_t> N2 = co_await Second;
    co_return N1.value_or(0) + N2.value_or(0);
}
```

### `co_await` (`await_ready` / `await_suspend` / `await_resume`)

**Краткое описание:** Ждёт завершения операции.

**Параметры:** Нет.

**Возвращает:** (`box::result<std::size_t>`) число перенесённых байтов или причина: `invalid_argument` для пустого дескриптора файла (готово сразу), ошибка отправки или код из завершения.

**Побочные эффекты:** Засыпает на executor; станция забирает завершение.

**Пример:** См. `box::ferry`.

### `file::read_async` / `file::write_async`

**Краткое описание:** Ставят чтение или запись файла в очередь и возвращают паром.

**Параметры:**
- `offset` (`std::uint64_t`).
- `p`, `n` или `buf` (`std::span<std::byte>` / `std::span<const std::byte>`).

**Возвращает:** (`box::ferry`).

**Побочные эффекты:** Отправляют манифест хранилища без ожидания.

**Пример:**
```cpp
#include <span>

#include "box/cxx/executor.h"
#include "box/cxx/ferry.h"
#include "box/cxx/tagfs.h"

box::task<bool> Save(box::tagfs::file Out, std::span<const std::byte> Data)
{
    auto Written = co_await Out.write_async(0, Data);
    co_return Written && *Written == Data.size();
}
```
