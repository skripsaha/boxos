# box::message

## Назначение

Заголовок: [`box/cxx/message.h`](../../../src/userspace/boxcxx/include/box/cxx/message.h).
C-основа: `box/ipc.h`.

Сообщения между процессами. Процесс отправляет байты другому процессу по
pid (`send`) или всем процессам, которые носят тег (`broadcast`). Ядро
копирует нагрузку в кучу получателя и кладёт запись в его кольцо
результатов (ResultRing); получатель её забирает.

Это не Touch (события по тегам, [touch](touch.md)) и не Brook (поток
между двумя сторонами, [brook](brook.md)) — у каждого свой слой.

Байты сообщения **одолжены** программе: `box::message` держит их и
возвращает ядру (`give_back`), когда уничтожается. Поэтому сообщение
перемещается и не копируется. Чтение безопасно: пустая запись или запись
ядра никогда не разыменовываются.

## Сообщение

### `box::message`

**Краткое описание:** Хранит полученное сообщение и его одолженные байты.

**Параметры:** `message()` — пустое; `message(const Result &)` (`explicit`).

**Возвращает:** Неприменимо: класс; только перемещение.

**Побочные эффекты:** Деструктор возвращает байты ядру.

**Пример:** См. `box::receive_for`.

### `valid` / `from` / `size` / `raw`

**Краткое описание:** Сообщают, настоящее ли это сообщение, и возвращают отправителя, размер и сырую запись.

**Параметры:** Нет.

**Возвращает:** `valid` / `operator bool` — (`bool`) pid отправителя не 0; `from` — (`std::uint32_t`) pid; `size` — (`std::uint32_t`) байты; `raw` — (`const Result &`).

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "box/cxx/message.h"

bool FromParent(const box::message &M, std::uint32_t Parent) { return M && M.from() == Parent; }
```

### `bytes` / `text` / `payload_as`

**Краткое описание:** Возвращают нагрузку как байты, как текст или как значение типа `T`.

**Параметры:** `T` — тривиально копируемый.

**Возвращает:** `bytes` — (`std::span<const std::byte>`), пусто для пустой записи; `text` — (`std::string_view`); `payload_as` — (`std::optional<T>`), пусто, если байтов меньше `sizeof(T)`.

**Побочные эффекты:** Нет.

**Примечания:** Вид действителен, пока жив объект сообщения.

**Пример:**
```cpp
#include "box/cxx/message.h"

struct Ping {
    std::uint32_t Seq;
};

std::uint32_t Seq(const box::message &M) { return M.payload_as<Ping>().value_or(Ping{0}).Seq; }
```

### `reply`

**Краткое описание:** Отправляет ответ отправителю.

**Параметры:**
- `data` (`const void *`), `n` (`std::uint16_t`); или `v` (`const T &`) — тривиально копируемый, не больше 65535 байт.

**Возвращает:** (`box::status`); ошибка — `process_not_found`, если это не настоящее сообщение, или причина ядра (`process_terminated`, кольцо получателя полно…).

**Побочные эффекты:** Отправляет сообщение.

**Пример:** См. `box::receive_for`.

## Отправка

### `box::send` / `box::broadcast`

**Краткое описание:** Отправляют байты процессу по pid или всем процессам с тегом.

**Параметры:**
- `pid` (`std::uint32_t`) или `tag` (`const char *`).
- `data` (`const void *`), `n` (`std::uint16_t`); или `v` (`const T &`) — тривиально копируемый, не больше 65535 байт.

**Возвращает:** (`box::status`); ошибка — настоящая причина: `invalid_argument` (плохой pid), `process_terminated` / `process_not_found`, кольцо полно, нет подписчиков рассылки.

**Побочные эффекты:** Копируют нагрузку получателю.

**Пример:**
```cpp
#include "box/cxx/message.h"

struct Ping {
    std::uint32_t Seq;
};

box::status Knock(std::uint32_t Pid) { return box::send(Pid, Ping{1}); }
```

## Получение

### `box::receive` / `box::receive_for`

**Краткое описание:** Забирают следующее сообщение без ожидания или ждут его.

**Параметры:**
- `timeout_ms` (`std::uint32_t`): для `receive_for`, 0 — без предела.

**Возвращает:** (`std::optional<message>`) пусто — сообщений нет или время вышло.

**Побочные эффекты:** `receive_for` блокирует.

**Примечания:** Регистрироваться не нужно: процесс читает своё кольцо результатов. Входящие общие для нити — один потребитель на нить.

**Пример:**
```cpp
#include "box/cxx/message.h"

struct Ping {
    std::uint32_t Seq;
};

void EchoServer()
{
    while (auto M = box::receive_for(0)) {
        if (auto Got = M->payload_as<Ping>()) (void)M->reply(Ping{Got->Seq + 1});
    }
}
```

### `box::next_message`

**Краткое описание:** Возвращает объект ожидания для `co_await` следующего сообщения.

**Параметры:** Нет.

**Возвращает:** Объект ожидания, дающий `box::message` (недействительное при ложном пробуждении).

**Побочные эффекты:** Сопрограмма засыпает на текущем [executor](executor.md).

**Пример:**
```cpp
#include "box/cxx/message.h"

box::task<void> Inbox()
{
    for (;;) {
        box::message M = co_await box::next_message();
        if (M) (void)M.reply("ok", 2);
    }
}
```

### `box::call`

**Краткое описание:** Отправляет запрос и ждёт ровно один ответ — сопрограмма запроса-ответа.

**Параметры:**
- `pid` (`std::uint32_t`).
- `data` (`const void *`), `n` (`std::uint16_t`); или `req` (`Req`, по значению — копируется в кадр сопрограммы; указатели запрещены).
- `timeout_ms` (`std::uint32_t`): 0 — без предела.

**Возвращает:** (`box::task<box::result<message>>`); ошибка — причина отправки, `timeout`, `route_self` (вызов самого себя).

**Побочные эффекты:** Отправляет сообщение и забирает **следующую** запись входящих.

**Как работает:** Сопоставление — по порядку прихода, а не по номеру запроса: `call` забирает ровно одну следующую запись, не очищая входящие и не фильтруя их.

**Примечания:** Держите не больше одного `call` в полёте на нить, не принимайте другие сообщения на время вызова и проверяйте `from()` ответа. Указатель `data` должен жить до первого запуска сопрограммы.

**Пример:**
```cpp
#include "box/cxx/message.h"

struct Ping {
    std::uint32_t Seq;
};

box::task<bool> Alive(std::uint32_t Server)
{
    auto Answer = co_await box::call(Server, Ping{7}, 500);
    co_return Answer && Answer->from() == Server;
}
```

### `box::result_any` / `box::any_result`

**Краткое описание:** Ждут любую запись кольца результатов: сообщение или ответ ядра.

**Параметры:** Нет.

**Возвращает:** `result_any()` — объект ожидания, дающий `any_result`: `valid` / `operator bool`, `is_ipc`, `is_kernel`, `context` (`KCTX_*`), `error_code`, `as_message()` (забирает запись, у ядра — пустое сообщение), `raw`.

**Побочные эффекты:** Забирает запись (кроме ответов [ferry](ferry.md) — те остаются ему).

**Типичное применение:** Сервер IPC или дисплей, которым нужно ждать и сообщения, и ответы ядра одним ожиданием.

**Пример:**
```cpp
#include "box/cxx/message.h"

box::task<void> Pump()
{
    for (;;) {
        box::any_result Record = co_await box::result_any();
        if (Record.is_ipc()) box::message M = Record.as_message();
    }
}
```
