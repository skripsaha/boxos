# box:: — собственный интерфейс BoxOS для C++

## Назначение

Заголовки: [`src/userspace/boxcxx/include/box/cxx`](../../../src/userspace/boxcxx/include/box/cxx).

Пространство имён `box::` — C++-лицо BoxOS: то, чего нет в стандарте,
потому что это понятия самой системы. Каждый заголовок — тонкий
идиоматичный слой над C-интерфейсом boxlib (`box/*.h`): RAII вместо ручного
освобождения, `box::result` с настоящей причиной из ядра вместо `-1`,
типизированные нагрузки вместо `void *`, ожидания для сопрограмм.

BoxOS — не Unix, и словарь здесь свой: кабины вместо процессов-клонов,
нити вместо pthread, теги вместо путей, Touch вместо сигналов, Current
вместо файловых дескрипторов.
