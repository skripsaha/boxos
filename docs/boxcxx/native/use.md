# box::use

## Назначение

Заголовок: [`box/cxx/use.h`](../../../src/userspace/boxcxx/include/box/cxx/use.h).
C-основа: `box/use.h`.

**Use Context** — чем сейчас занят человек за этой машиной. Он один на
машину, его хранит ядро, а задаёт оболочка (`use code cpp`) или программа
с системными полномочиями. Его читают все части системы:

- планировщик даёт программе тем большую долю ядра, чем больше тегов контекста она носит (теги процесса, [process](process.md));
- TagFS сужает запросы контекстом и ставит его теги созданным файлам ([tagfs](tagfs.md));
- настройки программ берут блок `[теги]`, подходящий контексту ([settings](settings.md)).

Том помнит контекст: `set`, `change` и `clear` записывают его на
смонтированный том, и машина, загрузившаяся с этим томом, берёт его
снова. Контекст задаётся в любом случае; значение результата говорит
лишь, запомнил ли его том.

Контекст принадлежит человеку: программа без системных полномочий
получает `access_denied` от `set`, `change`, `clear`. Читать его может
любая программа.

## Функции

### `use::set`

**Краткое описание:** Заменяет контекст списком тегов.

**Параметры:**
- `list` (`std::string_view`): теги через запятую; пусто — очистить.
- или `tags` (`std::initializer_list<std::string_view>`): теги списком (пустые пропускаются).

**Возвращает:** (`box::result<bool>`) запомнил ли том; ошибка — `access_denied` или другая причина.

**Побочные эффекты:** Меняет контекст всей машины и запись на томе.

**Пример:**
```cpp
#include "box/cxx/use.h"

bool StartCoding() { return box::use::set({"code", "cpp"}).has_value(); }
```

### `use::change`

**Краткое описание:** Добавляет и убирает теги одним действием.

**Параметры:**
- `add` (`std::string_view`): добавить после уже имеющихся (через запятую).
- `drop` (`std::string_view`): убрать; тег, названный в обоих, убирается; если ничего не осталось — контекст очищается.

**Возвращает:** (`box::result<bool>`) как у `set`.

**Побочные эффекты:** Как у `set`.

**Пример:**
```cpp
#include "box/cxx/use.h"

void Draft() { (void)box::use::change("draft", "release"); }
```

### `use::clear`

**Краткое описание:** Очищает контекст: человек ничем особым не занят.

**Параметры:** Нет.

**Возвращает:** (`box::result<bool>`).

**Побочные эффекты:** Как у `set`.

**Пример:**
```cpp
#include "box/cxx/use.h"

void Rest() { (void)box::use::clear(); }
```

### `use::current` / `use::active`

**Краткое описание:** Возвращают теги контекста и признак, что контекст задан.

**Параметры:** Нет.

**Возвращает:** `current` — (`std::vector<std::string>`) теги в порядке ядра; пусто, если контекста нет или ядро не ответило; `active` — (`bool`).

**Побочные эффекты:** Запрос к ядру; `current` выделяет память.

**Типичное применение:** Программа, которая подстраивается под занятие человека.

**Пример:**
```cpp
#include <algorithm>

#include "box/cxx/use.h"

bool AtWork()
{
    const auto Tags = box::use::current();
    return std::ranges::find(Tags, "work") != Tags.end();
}
```
