# box::line

## Назначение

Заголовок: [`box/cxx/line.h`](../../../src/userspace/boxcxx/include/box/cxx/line.h).

Типизированная «линия» сообщений между процессами. `box::message` и
`box::send`/`broadcast` ([message](message.md)) — сырые записи и
нетипизированные действия; `box::line<T>` — привязка, которая называет
одну беседу и кадрирует каждую нагрузку как тривиально копируемый `T`.
Сосед [brook](brook.md) и [current](current.md) для слоя IPC.

Линия — не буфер, не сокет и не дескриптор: она ничего не хранит. Очередь
— кольцо результатов нити; линия — невладеющее **значение** (копируется,
как `std::span`), которое помнит, **с кем** и **каким типом** говорит.

Два вида:

- `line<T>::to(pid)` — собеседник: `send()` идёт одной нити по pid;
- `line<T>::on("группа")` — группа: `send()` идёт каждой программе, которая носит тег (один раз, в кольцо её главной нити). Отправитель сам себе не приходит, а получатель должен **носить** тег (`box::tag_scope`, `this_process::add_tag` — [process](process.md)).

**Правило входящих:** кольцо результатов нити общее для всех потребителей
IPC в ней (линии, `box::call`, `next_message`, `result_any`). Приём **не
фильтрует** по собеседнику: фильтр украл бы запись, которая положена
другому потребителю. Поэтому в одной нити — одна беседа одновременно, а
когда важна личность, проверяйте `from()` через `box::message`.

Отправка может не удаться по настоящей причине (`box::status`), а приём —
это событие: доставка есть или нет (`std::optional<T>`, без ошибки).

## Класс line

### `box::line<T>`

**Краткое описание:** Типизированная привязка к собеседнику или группе.

**Параметры:** `line()` — не привязана; `T` — тривиально копируемый, с конструктором по умолчанию, 1–65535 байт.

**Возвращает:** Неприменимо: класс-значение. `operator bool` — привязана; `peer()` (0 у группы); `group()` (`nullptr` у собеседника).

**Побочные эффекты:** Нет.

**Пример:** См. `line::to`.

### `line::to` / `line::on`

**Краткое описание:** Создают линию к собеседнику или к группе.

**Параметры:** `peer_pid` (`std::uint32_t`); `group_tag` (`const char *`) — строка должна жить, пока жива линия.

**Возвращает:** (`line`); нулевой pid — непривязанная линия.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "box/cxx/line.h"

struct Tick {
    std::uint64_t Count;
};

void Talk(std::uint32_t Peer)
{
    auto Line = box::line<Tick>::to(Peer);
    (void)Line.send(Tick{1});
    if (auto Answer = Line.recv_for(100)) { /* Answer->Count */ }
}
```

### `line::send`

**Краткое описание:** Отправляет один `T`.

**Параметры:** `v` (`const T &`).

**Возвращает:** (`box::status`); ошибка — `invalid_argument` (не привязана или плохой pid), `process_not_found` / `process_terminated` (собеседника нет), его кольцо полно, `route_no_subscribers` (в группе нет никого с тегом).

**Побочные эффекты:** Отправка сообщения.

**Пример:**
```cpp
#include "box/cxx/line.h"

struct Alert {
    std::uint32_t Level;
};

bool Shout() { return box::line<Alert>::on("alerts").send(Alert{3}).has_value(); }
```

### `line::try_recv` / `line::recv_for`

**Краткое описание:** Забирают следующую доставку как `T` без ожидания или с ожиданием.

**Параметры:** `ms` (`std::uint32_t`) для `recv_for`, 0 — без предела.

**Возвращает:** (`std::optional<T>`): пусто — нет доставок, время вышло, или запись слишком коротка / недоступна.

**Побочные эффекты:** Запись забирается в любом случае: неразбираемая доставка выбрасывается и неотличима от пустых входящих. Чтобы посмотреть сырую запись, используйте `box::receive` / `box::next_message`.

**Пример:** См. `line::to`.

### `line::recv`

**Краткое описание:** Возвращает объект ожидания для `co_await` следующей доставки.

**Параметры:** Нет.

**Возвращает:** Объект ожидания, дающий `std::optional<T>`.

**Побочные эффекты:** Сопрограмма засыпает на [executor](executor.md).

**Пример:**
```cpp
#include "box/cxx/line.h"

struct Tick {
    std::uint64_t Count;
};

box::task<std::uint64_t> Sum(box::line<Tick> In, int Count)
{
    std::uint64_t Total = 0;
    for (int I = 0; I < Count; I++)
        if (auto Got = co_await In.recv()) Total += Got->Count;
    co_return Total;
}
```
