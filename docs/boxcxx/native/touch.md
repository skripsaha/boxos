# box::touch

## Назначение

Заголовок: [`box/cxx/touch.h`](../../../src/userspace/boxcxx/include/box/cxx/touch.h).
C-основа: `box/touch.h`.

**Touch** — рассылка событий BoxOS по тегам: отправитель шлёт полезную
нагрузку (до 96 байт) на тег, и каждая кабина, которая **заявила** этот
тег, получает копию в своё кольцо TouchRing. Так приходят клавиши, смерть
процессов, выключение системы, подключение USB, события нитей, а программы
сообщают друг другу о своём.

Здесь:

- `box::tag` — интернированный тег (`"system:reboot"_tag`);
- `box::tags` — каталог стандартных тегов ядра;
- `box::subscription` — заявка на тег (сторона получателя): `poll`, `wait`, `co_await next()`, обход как диапазона;
- `box::touch` — полученное событие с типизированным доступом к нагрузке;
- `box::publish`, `box::register_tag` — сторона отправителя и политики.

Доставка с фильтром по тегу опирается на «отложенный склад» boxlib
(`touch_try_pop_tag` / `touch_wait_tag`): кольцо кабины общее, поэтому
чужие события откладываются и потом отдаются подписке своего тега —
несколько подписок в одной кабине независимы.

Не смешивайте `box::subscription` с `box::touch_event()` (чтение всего
кольца без склада) в одной кабине: одно может проглотить событие,
которого ждёт другое.

## Теги

### `box::tag`

**Краткое описание:** Хранит интернированный тег Touch.

**Параметры:**
- `tag()` — недействительный.
- `tag(const char *name)` (`explicit`): интернирует строку (один системный вызов).
- `tag(TouchTagPair p)` (`explicit`).

**Возвращает:** Неприменимо: класс. `valid()` / `operator bool`; `id()` — конкретный id для заявки и получения; `pair()` — пара (`ключ:значение`, `ключ`), публикация попадает в обе корзины.

**Побочные эффекты:** Конструктор из строки — системный вызов. Храните тег в переменной, а не интернируйте в горячем цикле.

**Пример:**
```cpp
#include "box/cxx/touch.h"

using namespace box::literals;
const box::tag Tick = "metric:tick"_tag;
```

### `operator""_tag`

**Краткое описание:** Интернирует тег из строкового литерала.

**Параметры:** Литерал.

**Возвращает:** (`box::tag`).

**Побочные эффекты:** Системный вызов при каждом выполнении.

**Пример:** См. `box::tag`.

### `box::tags`

**Краткое описание:** Даёт стандартные теги ядра, интернированные один раз.

**Параметры:** `keyboard()`, `process_died()`, `process_spawned()`, `system_shutdown()`, `system_reboot()`, `usb_connect()`, `usb_disconnect()`.

**Возвращает:** (`const tag &`) кэшированный на всё время процесса.

**Побочные эффекты:** Первый вызов интернирует тег.

**Примечания:** Получать события всё равно нужно через подписку — каждой нитью свою.

**Пример:**
```cpp
#include "box/cxx/touch.h"

box::subscription Deaths() { return box::subscription(box::tags::process_died()); }
```

## Событие

### `box::touch`

**Краткое описание:** Хранит полученное событие.

**Параметры:** `touch()`, `touch(const Touch &)` (`explicit`).

**Возвращает:** Неприменимо: класс.

**Побочные эффекты:** Нет.

**Пример:** См. `payload_as`.

### `tag_id` / `source` / `timestamp` / `raw` / `flags`

**Краткое описание:** Возвращают тег, pid отправителя, отметку времени (TSC), сырое событие и флаги.

**Параметры:** Нет.

**Возвращает:** `TouchTag`, `std::uint32_t`, `std::uint64_t`, `const Touch &`, `std::uint16_t`.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "box/cxx/touch.h"

std::uint32_t Who(const box::touch &Event) { return Event.source(); }
```

### `provenance` / `from_kernel` / `from_user` / `from_tagfs`

**Краткое описание:** Сообщают, какой слой отправил событие.

**Параметры:** Нет.

**Возвращает:** `provenance` — (`box::provenance`: `none`, `kernel`, `user`, `tagfs`); остальные — (`bool`).

**Побочные эффекты:** Нет.

**Как работает:** `box::publish` из программы ставит отметку `user`, публикации ядра — `kernel`, события TagFS — `tagfs`. Подделать отметку ядра программа не может.

**Пример:**
```cpp
#include "box/cxx/touch.h"

bool Trusted(const box::touch &Event) { return Event.from_kernel(); }
```

### `payload` / `payload_as`

**Краткое описание:** Возвращают нагрузку как байты или как значение типа `T`.

**Параметры:** `T` — тривиально копируемый, не больше 96 байт (проверяется при компиляции).

**Возвращает:** `payload` — (`std::span<const std::byte>`); `payload_as` — (`std::optional<T>`), пусто, если нагрузка короче `T`.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "box/cxx/touch.h"

struct Tick {
    std::uint64_t Count;
};

std::uint64_t Count(const box::touch &Event) { return Event.payload_as<Tick>().value_or(Tick{0}).Count; }
```

## Отправитель

### `box::publish`

**Краткое описание:** Отправляет событие на тег.

**Параметры:**
- `tg` (`const tag &`).
- Сырая форма: `payload` (`const void *`), `plen` (`std::uint32_t`).
- Типизированная форма: `v` (`const T &`) — тривиально копируемое значение не больше 96 байт; **указатели запрещены** (указатель бессмыслен в чужом адресном пространстве, и такой вызов раньше тихо отправлял 8 байт адреса).
- `after_ms` (`std::uint32_t`): отложить доставку, по умолчанию 0.

**Возвращает:** (`bool`) ядро приняло событие.

**Побочные эффекты:** Доставляет копию всем кабинам, заявившим тег.

**Пример:**
```cpp
#include "box/cxx/touch.h"

struct Tick {
    std::uint64_t Count;
};

bool Beat(std::uint64_t N)
{
    using namespace box::literals;
    static const box::tag Metric = "metric:tick"_tag;
    return box::publish(Metric, Tick{N});
}
```

### `box::register_tag`

**Краткое описание:** Регистрирует политику доставки и права тега.

**Параметры:**
- `tg` (`const tag &`).
- `pol` (`touch_policy`): `edge` (каждое событие), `level` (уровень, нужно подтверждение `ack`), `latched` (последнее значение хранится).
- `cap` (`touch_capability`): `open` (публикует кто угодно), `owners`, `kernel_only`.

**Возвращает:** (`bool`) удалось.

**Побочные эффекты:** Меняет реестр тегов.

**Пример:**
```cpp
#include "box/cxx/touch.h"

bool Own(const box::tag &Mine) { return box::register_tag(Mine, box::touch_policy::latched, box::touch_capability::owners); }
```

### `box::touch_irq_return`

**Краткое описание:** Сообщает ядру, что ручной обработчик режима INTERRUPT закончил работу.

**Параметры:** Нет.

**Возвращает:** (`bool`).

**Побочные эффекты:** Разрешает доставку отложенных событий.

**Примечания:** Почти никогда не нужен: используйте подписку (режим REST). Режим INTERRUPT — это модель асинхронных сигналов Unix, которую этот слой заменяет.

**Пример:** Не приводится.

## Подписка

### `box::subscription`

**Краткое описание:** Заявка на тег на время жизни объекта — модель «забираю сам» (REST).

**Параметры:**
- `subscription()` — пустая.
- `subscription(const tag &tg)` (`explicit`): заявляет тег; при неудаче объект пустой.

**Возвращает:** Неприменимо: класс; только перемещение. `operator bool` — заявка действует; `id()`.

**Побочные эффекты:** Конструктор заявляет тег, деструктор снимает.

**Примечания:** Заявка доставляет события только той нити, которая её сделала. Режим «запускать манифест на каждое событие» (`TOUCH_REACT`) и режим INTERRUPT этим типом не предлагаются.

**Пример:**
```cpp
#include <print>

#include "box/cxx/touch.h"

void WatchDeaths()
{
    box::subscription Deaths(box::tags::process_died());
    while (auto Event = Deaths.wait()) std::println("умер процесс, событие от {}", Event->source());
}
```

### `poll` / `wait` / `ack`

**Краткое описание:** Забирают следующее событие тега без ожидания или с ожиданием и подтверждают событие уровня.

**Параметры:**
- `timeout_ms` (`std::uint32_t`): для `wait`, 0 — без предела.

**Возвращает:** `poll`, `wait` — (`std::optional<touch>`), пусто — нет событий или время вышло; `ack` — (`bool`).

**Побочные эффекты:** `wait` блокирует; `ack` разрешает следующее событие для политик `latched`/`level`.

**Пример:** См. `box::subscription`.

### `next`

**Краткое описание:** Возвращает объект ожидания для `co_await` следующего события тега.

**Параметры:** Нет.

**Возвращает:** Объект ожидания, дающий `std::optional<touch>`.

**Побочные эффекты:** Сопрограмма засыпает на текущем [executor](executor.md).

**Пример:**
```cpp
#include "box/cxx/executor.h"
#include "box/cxx/touch.h"

box::task<void> Keys(box::subscription &Keyboard)
{
    for (;;)
        if (auto Event = co_await Keyboard.next()) { /* обработать клавишу */ }
}
```

### Обход: `begin` / `end` / `set_drain_timeout` / `drain_timeout`

**Краткое описание:** Делают подписку входным диапазоном событий.

**Параметры:**
- `ms` (`std::uint32_t`): сколько ждать каждое следующее событие; 0 (по умолчанию) — бесконечный цикл, из которого выходят сами.

**Возвращает:** `begin` — итератор (у пустой подписки — сразу конец); `end` — `std::default_sentinel_t`.

**Побочные эффекты:** Каждый шаг ждёт событие; диапазон кончается, когда ожидание ничего не дало.

**Типичное применение:** Забрать накопившуюся пачку событий: задать конечный таймаут и пройти циклом.

**Пример:**
```cpp
#include "box/cxx/touch.h"

int Drain(box::subscription &Sub)
{
    Sub.set_drain_timeout(10);
    int Count = 0;
    for (const box::touch &Event : Sub) Count += Event.payload().size() > 0;
    return Count;
}
```
