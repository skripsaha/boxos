# box::child

## Назначение

Заголовок: [`box/cxx/child.h`](../../../src/userspace/boxcxx/include/box/cxx/child.h).

Надзор за запущенным дочерним процессом. `box::process::spawn`
([process](process.md)) возвращает голый pid; `box::child` — **владеющий**
(только перемещение) надзиратель: ждёт окончания ребёнка, узнаёт, **как** он
закончился (чисто, убит, упал), убивает его и проверяет, жив ли. Всё на
событиях Touch `process:died`, без опроса и без `waitpid`/`SIGCHLD` Unix.

Итог — в модели ошибок BoxOS, а не волшебное число: чистый выход — значение
результата (код ≥ 0); убит — ошибка `process_killed`; упал —
`process_crashed`; истёк предел ожидания при живом ребёнке — `timeout`.

Деструктор **отсоединяет**: не убивает и не ждёт; брошенный ребёнок
продолжает работать сам.

Как устроено: `process:died` — общая рассылка; один экземпляр смерти
звонит всей нити, а кто умер — в нагрузке. Поэтому одна **станция**
(своя у каждой нити) держит единственную подписку и раздаёт смерти по
точной идентичности ребёнка — паре (pid, поколение). Ядро перевыдаёт pid
сразу после уборки процесса, но у переиспользованного pid новое
поколение, поэтому чужая старая смерть с тем же pid не достанется новому
ребёнку.

Ограничения: `wait`, `exited`, `kill` — в той же нити, которая запустила
ребёнка. Не запускайте `box::system_watch` в нити, которая надзирает за
детьми: они будут бороться за подписку `process:died`.

## Класс child

### `child::spawn`

**Краткое описание:** Запускает программу и берёт её под надзор.

**Параметры:**
- `name` (`const char *`): командная строка, как у `process::spawn` (первое слово — программа, вся строка — Luggage).

**Возвращает:** (`box::result<child>`); ошибка — причина `process::spawn`, `process_blocked` (нить не смогла заявить `process:died` или ядро не сообщило поколение — тогда ребёнок убивается: следить за ним вслепую нельзя), `no_memory` (ребёнок убивается).

**Побочные эффекты:** При первом вызове в нити заявляет `process:died` (до запуска, чтобы не пропустить смерть); создаёт процесс.

**Пример:**
```cpp
#include <print>

#include "box/cxx/child.h"

int RunWorker()
{
    auto Worker = box::child::spawn("worker --fast");
    if (!Worker) {
        std::println("не запустился: {}", Worker.error());
        return -1;
    }
    box::result<int> Code = Worker->wait();
    if (Code) return *Code;                                                  // чистый выход
    if (Code.error().code() == box::errc::process_killed) std::println("убит");
    if (Code.error().code() == box::errc::process_crashed) std::println("упал");
    return -1;
}
```

### `child()` / перемещение / `~child`

**Краткое описание:** Создают пустой надзиратель, передают надзор и отсоединяют ребёнка.

**Параметры:** Нет / другой `child`.

**Возвращает:** Неприменимо. `operator bool` — надзирает; `pid()` — pid ребёнка.

**Побочные эффекты:** Деструктор и перемещающее присваивание забывают ещё живого ребёнка на станции (его смерть потом ничья); не убивают и не ждут.

**Пример:**
```cpp
#include "box/cxx/child.h"

void LetGo() { (void)box::child::spawn("clock"); }   // работает дальше сам
```

### `child::alive`

**Краткое описание:** Сообщает, жив ли ребёнок, по уже пришедшим событиям.

**Параметры:** Нет.

**Возвращает:** (`bool`) `false` для пустого, уже собранного или умершего.

**Побочные эффекты:** Забирает ждущие события смерти без блокировки.

**Примечания:** Не спрашивает ядро; взгляд ядра — `box::process(pid).alive()`.

**Пример:**
```cpp
#include "box/cxx/child.h"

bool Busy(box::child &Worker) { return Worker.alive(); }
```

### `child::kill`

**Краткое описание:** Завершает ребёнка.

**Параметры:** Нет.

**Возвращает:** (`box::status`); пустой надзиратель, уже собранный ребёнок или уже умерший (ядро ответило `process_not_found` / `process_terminated`) — успех. Иначе причина ядра.

**Побочные эффекты:** Сначала проверяет, не пришла ли уже смерть, чтобы не убить чужой процесс с переиспользованным pid; затем `proc_kill`.

**Пример:**
```cpp
#include "box/cxx/child.h"

bool Stop(box::child &Worker) { return Worker.kill().has_value() && Worker.wait(1000).has_value(); }
```

### `child::wait`

**Краткое описание:** Ждёт окончания ребёнка.

**Параметры:**
- `timeout_ms` (`std::uint32_t`): предел, 0 — без предела.

**Возвращает:** (`box::result<int>`): код чистого выхода; ошибка — `invalid_argument` (пустой надзиратель), `timeout`, `process_killed`, `process_crashed`. Повторное ожидание собранного ребёнка возвращает сохранённый итог без блокировки.

**Побочные эффекты:** Блокирует; смерти других детей нити, пришедшие во время ожидания, откладываются для их надзирателей.

**Пример:** См. `child::spawn`.

### `child::exited`

**Краткое описание:** Возвращает объект ожидания для `co_await` окончания ребёнка.

**Параметры:** Нет.

**Возвращает:** Объект ожидания, дающий `box::result<int>` — как `wait()` без предела.

**Побочные эффекты:** Сопрограмма засыпает на [executor](executor.md); для ожидания с пределом используйте `wait(ms)`.

**Пример:**
```cpp
#include "box/cxx/child.h"

box::task<int> Supervise()
{
    auto Worker = box::child::spawn("worker");
    if (!Worker) co_return -1;
    auto Code = co_await Worker->exited();
    co_return Code.value_or(-1);
}
```
