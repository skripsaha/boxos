# box::clock

## Назначение

Заголовок: [`box/cxx/clock.h`](../../../src/userspace/boxcxx/include/box/cxx/clock.h).

Часовой пояс машины. Читать время и пояс умеет стандарт:
`std::chrono::current_zone()` отвечает, в каком поясе машина, а
`std::chrono::system_clock` — который сейчас момент (см.
[стандартная библиотека: время](../std/time.md)). Стандарта для **установки**
пояса нет — это вопрос о машине, а не о времени, поэтому установка живёт
здесь.

Пояс хранится в файле `zone` с тегом `clock:zone`; при записи публикуется
Touch на `clock:zone` с новым именем, чтобы часы на экране перерисовались
без опроса. Программа, которая каждый раз вызывает `current_zone()`,
событие не нуждается: этот вызов смотрит каждый раз.

## Константы

### `clock::zone_tag` / `clock::zone_file` / `clock::zone_name_max`

**Краткое описание:** Называют тег и файл настройки пояса и наибольшую длину имени.

**Параметры:** `zone_tag = "clock:zone"`, `zone_file = "zone"`, `zone_name_max = 63`.

**Возвращает:** Неприменимо: константы.

**Побочные эффекты:** Нет.

**Пример:** См. `clock::set_zone`.

## Функции

### `clock::set_zone`

**Краткое описание:** Устанавливает часовой пояс машины.

**Параметры:**
- `name` (`std::string_view`): имя IANA, например `"Europe/Moscow"`.

**Возвращает:** (`box::status`); `invalid_argument`, если такого пояса нет в базе (тогда ничего не записано), иначе причина TagFS или `write_failed`.

**Побочные эффекты:** Пишет файл пояса (создаёт его при необходимости); публикует Touch на `clock:zone`.

**Как работает:** Имя сначала проверяется по базе поясов, и записывается **каноническое** написание из базы (ссылка `US/Eastern` записывается как пояс, на который она указывает). Перед записью файл обрезается до нуля, чтобы короткое имя не оставило хвост длинного. Публикация — по возможности: настройка сохранена и правильна, слушал кто-нибудь или нет.

**Пример:**
```cpp
#include <print>

#include "box/cxx/clock.h"

void Move(std::string_view Zone)
{
    if (auto Done = box::clock::set_zone(Zone); !Done) std::println("пояс не установлен: {}", Done.error());
}
```

### `clock::zone_setting`

**Краткое описание:** Возвращает сохранённое имя пояса.

**Параметры:** Нет.

**Возвращает:** (`std::string`) как записано, пусто, если ничего не задано.

**Побочные эффекты:** Запрос к TagFS и чтение файла.

**Примечания:** Это сохранённое значение, а не обязательно действующее: имя, которого база не знает, здесь читается как есть, а `current_zone()` вернёт `Etc/UTC`. Различие позволяет команде честно сказать об этом.

**Пример:**
```cpp
#include <chrono>
#include <print>

#include "box/cxx/clock.h"

void Explain()
{
    const std::string Said = box::clock::zone_setting();
    const std::string_view Used = std::chrono::current_zone()->name();
    if (!Said.empty() && Said != Used) std::println("в настройке {}, но действует {}", Said, Used);
}
```
