# Числа

## Назначение

`<random>`, `<cmath>`, `<stdfloat>`, `<charconv>` и соседи в BoxOS.
Удобные расширения — логарифм по основанию, корень степени, округление до
знаков, тригонометрия в градусах — в [math](../native/math.md); аппаратная
энтропия — `box::hardware_entropy` ([cpu](../native/cpu.md)).

## Случайные числа

### `std::random_device`

**Краткое описание:** Источник случайных чисел из процессора.

**Параметры:** Как в стандарте.

**Возвращает:** 32-битные значения.

**Побочные эффекты:** Инструкция RDRAND.

**Как работает:** Основа — RDRAND; `entropy()` = 32.0. Без RDRAND — смесь TSC (splitmix), `entropy()` = 0.0: такой `random_device` **не криптостойкий** и честно об этом сообщает.

**Примечания:** Для 64-битных значений и RDSEED — `box::hardware_entropy`.

**Пример:**
```cpp
#include <random>

int Roll()
{
    std::random_device Seed;
    std::mt19937 Engine(Seed());
    return std::uniform_int_distribution<int>(1, 6)(Engine);
}
```

### Движки и распределения

**Краткое описание:** Все стандартные движки и распределения, включая `philox_engine` (C++26).

**Параметры:** Как в стандарте.

**Возвращает:** Как в стандарте.

**Побочные эффекты:** Нет.

**Как работает:** Движки побитово совпадают с другими реализациями (`philox` сверен с libstdc++). Распределения используют собственные алгоритмы (Марсалья, Марсалья–Цанг, PTRS Хёрмана, BINV): совпадают с другими реализациями по распределению, но не по последовательности.

**Примечания:** Нет `operator<<`/`operator>>` для движков и распределений (никто не написал; препятствий нет). Конструкторы и `seed` с последовательностью принимают конкретный `std::seed_seq &`, а не любой тип последовательности: собственный тип последовательности не подойдёт.

**Пример:**
```cpp
#include <random>

double Noise(std::uint64_t Seed)
{
    std::philox4x64 Engine(Seed);
    return std::normal_distribution<double>(0.0, 1.0)(Engine);
}
```

## Математика

### `<cmath>`

**Краткое описание:** Математические функции с правильным округлением ключевых операций.

**Параметры:** Как в стандарте.

**Возвращает:** Как в стандарте.

**Побочные эффекты:** Нет.

**Как работает:** Полный набор функций, включая специальные математические функции и `long double`. Расширение boxcxx: константы `std::kPi`, `std::kInf`, `std::kQNaN` (ими пользуется [math](../native/math.md)); для стандартного кода предпочтительны `std::numbers::pi` и `std::numeric_limits`.

**Пример:**
```cpp
#include <cmath>
#include <numbers>

double Area(double Radius) { return std::numbers::pi * std::pow(Radius, 2); }
```

### `<stdfloat>` / `<cfenv>`

**Краткое описание:** Расширенные типы с плавающей точкой и среда плавающей точки.

**Параметры:** Как в стандарте.

**Возвращает:** Как в стандарте.

**Побочные эффекты:** `<cfenv>` меняет режим округления и флаги исключений текущей нити.

**Как работает:** `std::float16_t`, `float32_t`, `float64_t`, `float128_t`, `bfloat16_t` — встроенные типы компилятора; библиотека форматирует, разбирает и считает их.

**Пример:**
```cpp
#include <stdfloat>

std::float16_t Half(std::float16_t X) { return X / std::float16_t(2); }
```

### `<charconv>` / `<format>` для чисел

**Краткое описание:** Перевод чисел в текст и обратно.

**Параметры:** Как в стандарте.

**Возвращает:** Как в стандарте.

**Побочные эффекты:** Нет.

**Как работает:** `to_chars` и `from_chars` для плавающей точки правильно округлены (сверено с MPFR) во всех формах — фиксированной, научной, общей, шестнадцатеричной. На них же построены `printf`/`scanf`, `std::format` и потоки — один движок для всех.

**Пример:**
```cpp
#include <charconv>
#include <string_view>

double Parse(std::string_view Text)
{
    double Value = 0;
    std::from_chars(Text.data(), Text.data() + Text.size(), Value);
    return Value;
}
```

### `<valarray>`

**Краткое описание:** Массивы для покомпонентных вычислений.

**Параметры:** Как в стандарте.

**Возвращает:** Как в стандарте.

**Побочные эффекты:** Большие операции могут выполняться бригадой нитей.

**Пример:**
```cpp
#include <valarray>

double Dot(const std::valarray<double> &A, const std::valarray<double> &B) { return (A * B).sum(); }
```
