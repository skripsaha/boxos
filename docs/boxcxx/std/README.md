# Стандартная библиотека C++ в BoxOS

## Назначение

Заголовки: [`src/userspace/boxcxx/include/std`](../../../src/userspace/boxcxx/include/std).
Полная опись соответствия стандарту: [`CONFORMANCE.md`](../../../src/userspace/boxcxx/CONFORMANCE.md).

boxcxx — собственная стандартная библиотека BoxOS: каждый заголовок написан
для этой системы, а не перенесён из libstdc++ или libc++. Базовый стандарт
— C++23 (N4950), сборка в режиме `-std=gnu++23`; часть возможностей C++26
реализована, и их макросы `__cpp_lib_*` объявлены без проверки
`__cplusplus`.

Эти страницы описывают, **как стандартная библиотека ведёт себя в BoxOS**:
куда пишет `std::print`, чем является `std::thread`, какие часы у
`<chrono>`, где лежат файлы `std::ofstream`, что сознательно сделано иначе.
Поведение каждой функции определено стандартом и здесь не пересказывается.

## Что есть

**109 заголовков**: 104 из 105 заголовков C++23, `<stdatomic.h>` и четыре
заголовка C++26 — `<inplace_vector>`, `<debugging>`, `<stdbit.h>`,
`<stdckdint.h>`. Все 21 обёртка библиотеки C (`<cstdio>`, `<cstdlib>`,
`<cstring>`, `<ctime>`, `<cwchar>`…) на месте. Есть `<format>`, `<print>`,
`<ranges>`, `<expected>`, `<flat_map>`, `<mdspan>`, `<generator>`,
`<stacktrace>`, `<regex>`, `<execution>` с настоящими параллельными
алгоритмами, `<chrono>` с базой часовых поясов IANA, потоки `<iostream>` и
`<fstream>`, широкие символы и локальные фасеты.

**Нет:**
- `<filesystem>` — сознательно: TagFS адресует файлы тегами, иерархии путей для моделирования нет (отсюда и нет перегрузок `filesystem::path` у `fstream`);
- устаревший `<codecvt>`;
- форм `<name.h>` (`<string.h>`, `<stdlib.h>`): только `<cX>`; имена всё равно видны и без `std::`, так что перенесённый код с `isdigit(c)` компилируется, а с `#include <ctype.h>` — нет;
- второй локали: есть только `"C"` (UTF-8), `std::locale("de_DE")` бросает исключение;
- errno как механизма: `<cerrno>` есть, но ни boxlib, ни `box::` его не устанавливают.

## Если что-то удивило

- `while (std::getline(std::cin, s))` никогда не кончается: клавиатура — живая консоль без конца, Ctrl-D нет. Читайте известное число строк или из файла.
- `std::cerr` пишет на **экран**, как `cout`; отдельный канал диагностики BoxOS — последовательный журнал `box::log()` ([current](../native/current.md)).
- `std::ofstream f("a/b.txt")` открывает файл с **именем** `a/b.txt`: TagFS не знает путей.
- `#include <filesystem>` — такого заголовка нет.
- `os << u8"текст"` и `os << L"текст"` в узкий поток не компилируются (как требует стандарт).
- `for (auto &[k, v] : m)` над `flat_map` или `box::flat_hash_map` не компилируется: итератор отдаёт прокси, пишите `auto` или `auto &&`.
- `constexpr std::string s = "длинная строка…";` — не константа: строка длиннее 15 символов владеет выделением памяти.
- `std::getenv` всегда возвращает `nullptr`, `std::system(cmd)` — −1: у процесса BoxOS теги, а не переменные окружения, и командного процессора для строк нет (запуск — `box::process::spawn`, [process](../native/process.md)).

## Проверка

Соответствие держит набор `src/userspace/apps/cxxtest.cpp`: более 250 фаз,
около 6 700 проверок времени выполнения и 2 000 `static_assert`, на BIOS и
UEFI, на 1 и 16 ядрах. Каждое отклонение от стандарта записано в
`CONFORMANCE.md` с меткой: `!` — тихо неверно, `+` — строже стандарта, `~` —
отклонение по решению, `–` — отсутствует, `?` — выбор там, где стандарт
оставляет свободу, `✓` — закрыто.
