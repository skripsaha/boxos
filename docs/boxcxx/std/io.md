# Ввод и вывод

## Назначение

Как стандартный ввод-вывод C++ и C устроен в BoxOS. В BoxOS нет модели
stdin/stdout/stderr Unix и нет файловых дескрипторов: есть **Current** —
именованные каналы ([current](../native/current.md)). Стандартные потоки —
это стандартные имена для каналов Current:

- `std::cout`, `std::cerr`, `std::clog`, `stdout`, `stderr`, `std::print` — канал `"screen"`;
- `std::cin`, `stdin` — канал `"keyboard"`;
- `std::filebuf`, `std::fstream`, `fopen` — канал `"file:имя"`.

Все пишущие на экран идут через **один** дескриптор: `std::cout << a;
std::print("{}", b);` выводит `a`, затем `b` — один канал, один порядок.

## Консоль

### `std::print` / `std::println`

**Краткое описание:** Форматируют и выводят текст на экран.

**Параметры:** Как в стандарте (`<print>`); есть формы с `std::ostream &`.

**Возвращает:** `void`.

**Побочные эффекты:** Запись в канал `"screen"`.

**Примечания:** `println()` без аргументов есть (это C++26, взято раньше). Перегрузок с `FILE *` нет. `vprint_unicode` совпадает с `vprint_nonunicode`: перекодирования нет, вывод UTF-8 как есть. Цвет вывода — `box::styled` ([console](../native/console.md)).

**Пример:**
```cpp
#include <print>

int main()
{
    std::println("{:>8} | {:<8}", "имя", "размер");
    std::println("{:>8} | {:<8}", "notes", 1024);
    return 0;
}
```

### `std::cout` / `std::cerr` / `std::clog` / `std::cin`

**Краткое описание:** Стандартные потоки, привязанные к экрану и клавиатуре.

**Параметры:** Нет.

**Возвращает:** Неприменимо: объекты.

**Побочные эффекты:** Ввод-вывод через Current.

**Как работает:** Связи и буферизация — по стандарту: `cin.tie() == &cout`, `cerr.tie() == &cout`, `cerr` без буфера. Клавиатура отдаёт одну отредактированную строку без перевода строки, буфер потока возвращает `\n` на место, чтобы `getline` работал. Объекты создаются раньше глобальных конструкторов программы; последний `ios_base::Init` сбрасывает их при выходе.

**Примечания:**
- `std::cin` никогда не достигает конца файла: консоль бесконечна, Ctrl-D нет.
- `cerr` и `clog` пишут на экран (`cout.rdbuf() == cerr.rdbuf()`): диагностика, видимая только по кабелю последовательного порта, на реальной машине потерялась бы. Для журнала — `box::log()`.
- `wcin`/`wcout` можно смешивать с узкими потоками: кодировка UTF-8, состояния у неё нет, порядок вывода сохраняется.
- `sync_with_stdio` ничего не делает.

**Пример:**
```cpp
#include <iostream>
#include <string>

int main()
{
    std::string Name;
    std::cout << "Как вас зовут? " << std::flush;
    std::getline(std::cin, Name);   // одна строка: конца у клавиатуры нет
    std::cout << "Привет, " << Name << "!\n";
    return 0;
}
```

## Файлы

### `std::ifstream` / `std::ofstream` / `std::fstream` / `std::filebuf`

**Краткое описание:** Файловые потоки над файлами TagFS.

**Параметры:** Имя файла (`const char *` или `const std::string &`) и режим.

**Возвращает:** Неприменимо: классы.

**Побочные эффекты:** Открывают канал `"file:имя"`.

**Как работает:**
- Аргумент — **имя** файла TagFS, а не путь: каталогов нет, разделитель не разбирается.
- Все строки таблицы режимов [filebuf.members] реализованы, включая `noreplace`; `ios::out` без `app` обрезает файл (TagFS умеет укорачивать файлы).
- `binary` принимается и ничего не меняет: преобразований текста нет.
- Запись за концом сначала удлиняет файл до позиции; промежуток читается нулями.
- `std::wofstream` пишет UTF-8. Относительный `seekg`/`seekp` по широкому файлу — ошибка (символы разной длины); `tellg`/`seekg` с сохранённой позицией работает.
- `native_handle()` — `Current *`.

**Примечания:** Перегрузок с `std::filesystem::path` нет. Имя ищется так же, как в `box::tagfs::find` (берётся первый файл с этим именем), а новый файл создаётся как `box::tagfs::create` — с тегами Use Context ([use](../native/use.md)). Имена в TagFS не уникальны; для точной работы с файлом по id — `box::tagfs` ([tagfs](../native/tagfs.md)).

**Пример:**
```cpp
#include <fstream>
#include <string>

int Lines()
{
    {
        std::ofstream Out("notes.txt");
        Out << "первая\nвторая\n";
    }
    std::ifstream In("notes.txt");
    int Count = 0;
    for (std::string Line; std::getline(In, Line);) Count++;   // у файла конец есть
    return Count;
}
```

## Библиотека C

### `printf` / `fopen` / `FILE` (`<cstdio>`)

**Краткое описание:** Ввод-вывод C через Current.

**Параметры:** Как в стандарте C.

**Возвращает:** Как в стандарте C.

**Побочные эффекты:** Ввод-вывод.

**Как работает:**
- `FILE` — буфер, позиция и режим вокруг Current: `stdout`/`stderr` — `"screen"`, `stdin` — `"keyboard"`, `fopen("report", "r")` — `"file:report"`.
- `printf` и `getchar` — одна функция с boxlib: у boxlib они слабые, boxcxx определяет сильные, поэтому программа на C++ получает полный набор преобразований (`%#x`, `%f`…), а программа на C — меньший набор boxlib.
- `fread`/`fwrite` — только в `std::`: в глобальном пространстве имён живут другие `fread`/`fwrite` boxlib (по id файла и смещению).
- `stderr` — на экран, без буфера.
- Плавающая точка печатается и читается через `<charconv>` (правильное округление).
- Ориентация потока по C: после `printf` вызов `fwprintf(stdout, …)` отвергается.
- `FOPEN_MAX` = 16 (гарантия, не предел), `FILENAME_MAX` = 32 (длина имени файла TagFS).

**Примечания:** `feof` у клавиатуры не наступает никогда.

**Пример:**
```cpp
#include <cstdio>

int Report()
{
    std::FILE *Out = std::fopen("report", "w");
    if (!Out) return 1;
    std::fprintf(Out, "%-10s %8.2f\n", "итого", 12.5);
    std::fclose(Out);
    return 0;
}
```

## Потоки в памяти

### `<sstream>` / `<spanstream>` / `<syncstream>`

**Краткое описание:** Строковые потоки, потоки над `std::span` и синхронизированный вывод.

**Параметры:** Как в стандарте.

**Возвращает:** Неприменимо.

**Побочные эффекты:** Нет (кроме `osyncstream`, который пишет при уничтожении или `emit`).

**Как работает:** Все три по стандарту, узкие и широкие. `std::osyncstream` собирает вывод одной нити и выдаёт его целиком — строки нескольких нитей на экране не перемешиваются.

**Пример:**
```cpp
#include <iostream>
#include <syncstream>
#include <thread>

int main()
{
    std::thread A([] { std::osyncstream(std::cout) << "нить A: " << 1 << '\n'; });
    std::thread B([] { std::osyncstream(std::cout) << "нить B: " << 2 << '\n'; });
    A.join();
    B.join();
    return 0;
}
```
