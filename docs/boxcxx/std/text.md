# Текст

## Назначение

Строки, кодировки, локали и регулярные выражения в BoxOS. Кодировка всей
системы — **UTF-8**: файлы, консоль, сообщения, теги. Для текста в ячейках
экрана — [painter::tui text](../painter/tui/text.md); для набора текста
шрифтами — [Typecase](../typecase/README.md).

## Строки

### `std::string` / `std::string_view` / `std::format`

**Краткое описание:** Строки и форматирование по стандарту.

**Параметры:** Как в стандарте.

**Возвращает:** Как в стандарте.

**Побочные эффекты:** Выделение памяти для длинных строк.

**Как работает:** Короткие строки до 15 символов хранятся внутри объекта (такая строка может быть `constexpr`); длиннее — в куче. `std::format` полный, включая форматирование диапазонов, кортежей, времени, `std::thread::id`, широкие формы и спецификатор `L` (числа по фасету `numpunct` локали контекста). Собственные типы BoxOS умеют форматироваться: `box::error`, `box::color`, `box::strand::id`, `box::heap::stats` и другие.

**Пример:**
```cpp
#include <format>
#include <vector>

std::string Row(const std::vector<int> &Values) { return std::format("{}", Values); }   // "[1, 2, 3]"
```

## Локали

### `std::locale`

**Краткое описание:** Одна локаль `"C"` (UTF-8) и возможность строить её варианты.

**Параметры:** Как в стандарте.

**Возвращает:** Как в стандарте.

**Побочные эффекты:** Нет.

**Как работает:** Все шесть категорий фасетов есть (`ctype`, числовые, `collate`, `messages`, денежные, времени) с формами `_byname`. Программа может поставить свой фасет (`std::locale(loc, new MyFacet)`), объединять локали по категориям и назначать потокам. Именованной второй локали нет: `std::locale("de_DE")` бросает исключение, а не притворяется `"C"`.

**Примечания:** `<cctype>` классифицирует только ASCII (локаль `"C"`); для символов Unicode — `<cwctype>` (свойства из базы Unicode).

**Пример:**
```cpp
#include <locale>
#include <sstream>

struct Spaced : std::numpunct<char> {
    char do_thousands_sep() const override { return ' '; }
    std::string do_grouping() const override { return "\3"; }
};

std::string Big(long Value)
{
    std::ostringstream Out;
    Out.imbue(std::locale(Out.getloc(), new Spaced));
    Out << Value;
    return Out.str();   // "1 234 567"
}
```

## Широкие символы

### `wchar_t`, `<cwchar>`, `<cwctype>`, широкие потоки

**Краткое описание:** Полная поддержка широких символов поверх UTF-8.

**Параметры:** Как в стандарте.

**Возвращает:** Как в стандарте.

**Побочные эффекты:** Нет.

**Как работает:** `wchar_t` — 32 бита (кодовая точка). Широкие потоки (`wcout`, `wofstream`, `wstringstream`…) пишут и читают **UTF-8** через `codecvt`. `wctype("alpha")`, `towlower` и прочие отвечают по свойствам Unicode. `fwprintf`/`fwscanf` работают; числа форматирует тот же узкий движок.

**Пример:**
```cpp
#include <cwctype>
#include <string>

std::wstring Upper(std::wstring Text)
{
    for (wchar_t &C : Text) C = static_cast<wchar_t>(std::towupper(static_cast<std::wint_t>(C)));
    return Text;   // работает и для кириллицы
}
```

## Регулярные выражения

### `std::regex`

**Краткое описание:** Регулярные выражения с линейным временем поиска.

**Параметры:** Как в стандарте.

**Возвращает:** Как в стандарте.

**Побочные эффекты:** Нет.

**Как работает:** Движок — виртуальная машина Пайка: время поиска определяется формой входа, а не удачей, поэтому `(a+)+b` отвечает за микросекунды там, где перебирающие движки других библиотек работают секундами. Только обратные ссылки (они не регулярны) идут вторым путём — ограниченным перебором с бюджетом шагов, который при исчерпании бросает `regex_error` с `error_complexity` вместо зависания.

**Пример:**
```cpp
#include <regex>
#include <string>

bool IsDate(const std::string &Text) { return std::regex_match(Text, std::regex(R"(\d{4}-\d{2}-\d{2})")); }
```
