# typecase::size

## Назначение

Заголовок: [`typecase/size.h`](../../../src/userspace/typecase/include/typecase/size.h).
Реализация: [`src/size.cpp`](../../../src/userspace/typecase/src/size.cpp).

Кегль и ячейка, в которой стоит каждый символ. Шрифт рисует по своему em;
источник, который рисует по ячейке (оттиск, код отсутствующего символа),
заполняет ячейку; картинка ограничена ячейкой и em вокруг неё, поэтому ни
один глиф, даже из повреждённого шрифта, не попросит больше пикселей, чем
даёт размер. Сплошной текст, который не знает ячеек, берёт строку за
высоту ячейки и продвижение за ширину.

## Типы и функции

### `Size`

**Краткое описание:** Описывает кегль и ячейку.

**Параметры:**
- `Em` (`float`): пикселей на em.
- `Width`, `Height` (`std::int32_t`): ячейка в пикселях.
- `Baseline` (`std::int32_t`): рядов от верха ячейки до базовой линии.

**Возвращает:** Неприменимо: агрегат; `==` поэлементное.

**Побочные эффекты:** Нет.

**Пример:** См. `FitCell`.

### `FitCell`

**Краткое описание:** Возвращает кегль шрифта, заполняющий ячейку.

**Параметры:**
- `Face` (`const Font &`).
- `Width`, `Height` (`std::int32_t`): ячейка — первая перегрузка.
- `Height` (`std::int32_t`): только высота — вторая перегрузка; ширина — по пропорциям шрифта.

**Возвращает:** (`Size`). Первая: em, при котором продвижение «M» равно ширине; базовая линия — где строка шрифта (от выносного вверх до выносного вниз) стоит по центру высоты. Вторая: em, при котором строка шрифта равна высоте; ширина — продвижение «M» при нём, округлённое, не меньше 1; дальше как в первой.

**Побочные эффекты:** Нет.

**Типичное применение:** Сетка консоли: дисплей берёт `FitCell(Шрифт, Высота)` из настройки `text size`.

**Пример:**
```cpp
#include "typecase/size.h"

typecase::Size Console(const typecase::Font &Mono) { return typecase::FitCell(Mono, 16); }
```
