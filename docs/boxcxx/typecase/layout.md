# typecase::layout

## Назначение

Заголовок: [`typecase/layout.h`](../../../src/userspace/typecase/include/typecase/layout.h).
Реализация: [`src/layout.cpp`](../../../src/userspace/typecase/src/layout.cpp),
вопросы к раскладке — [`src/layout_ask.cpp`](../../../src/userspace/typecase/src/layout_ask.cpp).

Текст, разложенный в рамке: символы в начертаниях, к которым пришли их
стили ([fonts](fonts.md)), с кернингом и разрядкой, разбитые на строки и
выровненные, каждый глиф на своём месте; и ответы на вопросы к разложенному
тексту — какого он размера, где стоит каретка, какой символ ближе к
точке, где лежит отрезок, сам текст для копирования.

Строка высотой с самое высокое на ней: строка каждого стиля (кегль × высота
строки, или собственная строка шрифта), с выносными элементами посередине,
как ставит CSS. Высота строки — целое число пикселей, базовая линия — на
границе ряда пикселей, поэтому глифы ложатся на ряды так, как нарисованы.
По горизонтали каждое место — там, куда поставили продвижения, с точностью
до долей пикселя.

Подробности набора:

- табуляция — до следующей позиции через каждые восемь пробелов её стиля;
- пробел, которого нет ни в одном шрифте, — четверть em;
- мягкий перенос (U+00AD) не занимает места; если строка рвётся на нём, показывается дефис;
- пробелы в конце строки «висят» за её краем и не считаются в ширину;
- при обрезке с многоточием символы снимаются с конца строки вместе с пробелами перед многоточием; символ не отделяется от своих диакритических знаков.

Пока нет: лигатур и письменностей справа налево.

## Типы

### `LaidRun`

**Краткое описание:** Описывает группу глифов, набранных одинаково: одно начертание, один вид, одни чернила.

**Параметры:**
- `Face` (`std::shared_ptr<const Font>`): начертание; пусто — символы, которых нет ни в одном шрифте (каждый рисуется кодом, `MissingCell`).
- `Look` (`GlyphLook`): кегль, искусственный полужирный и наклон; `Phase` выставляет рисующий.
- `Ink` (`std::uint32_t`): чернила.

**Возвращает:** Неприменимо: агрегат.

**Побочные эффекты:** Нет.

**Пример:** См. `Layout::Glyphs`.

### `LaidGlyph`

**Краткое описание:** Описывает глиф на его месте.

**Параметры:**
- `Run` (`std::uint32_t`): номер в `Runs()`.
- `Glyph` (`std::uint32_t`): глиф начертания; в группе без начертания — сам символ.
- `X` (`float`): перо от левого края раскладки.
- `Y` (`float`): базовая линия от верха раскладки.
- `Character` (`std::uint32_t`): первый символ, который он показывает.

**Возвращает:** Неприменимо: агрегат.

**Побочные эффекты:** Нет.

**Пример:** См. `Layout::Glyphs`.

### `Area`, `LaidLine`, `LaidDecoration`, `Caret`

**Краткое описание:** Описывают прямоугольник раскладки, строку, линию под или через текст и положение каретки.

**Параметры:**
- `Area`: `X`, `Y`, `Width`, `Height` от левого верхнего угла раскладки.
- `LaidLine`: `Top`, `Height`, `Baseline` (от верха раскладки), `Left` (где стоит первый символ), `Width` (до конца последнего символа без висящих пробелов; у выровненной по ширине — ширина рамки), `Right` (где перо после всего, включая пробелы), `FirstGlyph`, `GlyphCount`, `From`, `To` (символы строки, включая невидимые в конце).
- `LaidDecoration`: `Of` (`Area`), `Ink`.
- `Caret`: `X`, `Top`, `Bottom`, `Line`.

**Возвращает:** Неприменимо: агрегаты.

**Побочные эффекты:** Нет.

**Пример:** См. `Layout::CaretAt`.

## Класс Layout

### `Layout::Of`

**Краткое описание:** Раскладывает текст в рамке шрифтами книги.

**Параметры:**
- `Set` (`const Text &`): текст.
- `In` (`const TextBox &`): рамка.
- `From` (`const Fonts &`): книга шрифтов.

**Возвращает:** (`Layout`) разложенный текст.

**Побочные эффекты:** Выделяет память; держит начертания, которыми набран текст, живыми, пока жива раскладка. Может бросить `std::bad_alloc`.

**Как работает:** Стиль каждого символа (текст и отрезки над ним) → начертание и глиф каждого символа (первое из начертаний стиля, у которого символ есть) → кернинг пар одного начертания в письменности первого символа → разрядка → разбиение на строки → высота строк → обрезка по рамке → расстановка с выравниванием.

**Пример:** См. [README](README.md).

### `Width` / `Height`

**Краткое описание:** Возвращают размер раскладки.

**Параметры:** Нет.

**Возвращает:** (`float`) размер рамки там, где рамка его задаёт, и размер строк там, где нет.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "typecase/layout.h"

bool Fits(const typecase::Layout &Laid, float Room) { return Laid.Width() <= Room; }
```

### `Lines` / `Glyphs` / `Runs` / `Decorations` / `Box`

**Краткое описание:** Возвращают строки, глифы, группы, линии оформления и рамку.

**Параметры:** Нет.

**Возвращает:** Константные ссылки на векторы `LaidLine`, `LaidGlyph`, `LaidRun`, `LaidDecoration` и на `TextBox`.

**Побочные эффекты:** Нет.

**Типичное применение:** Собственный рисовальщик текста (так делает Painter в `FillText`).

**Пример:**
```cpp
#include "typecase/layout.h"

// Сколько глифов нарисовано чернилами Ink.
std::size_t InInk(const typecase::Layout &Laid, std::uint32_t Ink)
{
    std::size_t Count = 0;
    for (const typecase::LaidGlyph &Each : Laid.Glyphs()) Count += Laid.Runs()[Each.Run].Ink == Ink;
    return Count;
}
```

### `Cut`

**Краткое описание:** Сообщает, что часть текста не видна.

**Параметры:** Нет.

**Возвращает:** (`bool`) строки не поместились в рамку или строка обрезана краем.

**Побочные эффекты:** Нет.

**Типичное применение:** Показать подсказку с полным текстом.

**Пример:**
```cpp
#include "typecase/layout.h"

bool NeedsTooltip(const typecase::Layout &Laid) { return Laid.Cut(); }
```

### `Characters` / `Count` / `Secret`

**Краткое описание:** Возвращают символы текста, их число и признак секрета.

**Параметры:** Нет.

**Возвращает:** `const std::u32string &`, `std::uint32_t`, `bool`.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "typecase/layout.h"

bool Empty(const typecase::Layout &Laid) { return Laid.Count() == 0; }
```

### `CaretAt`

**Краткое описание:** Возвращает, где стоит каретка перед символом.

**Параметры:**
- `Index` (`std::uint32_t`): символ; `Count()` — после последнего.

**Возвращает:** (`Caret`) вертикальная черта: `X`, `Top`, `Bottom`, строка.

**Побочные эффекты:** Нет.

**Как работает:** Перед символом, перед которым каретка не встаёт (диакритический знак), она уступает символу, к которому он относится. Перед невидимым символом (текст обрезан) — у места обрезки. На переносе между словами каретка стоит в начале следующей строки.

**Пример:**
```cpp
#include "typecase/layout.h"

float CaretX(const typecase::Layout &Laid) { return Laid.CaretAt(Laid.Count()).X; }
```

### `IndexAt`

**Краткое описание:** Возвращает символ, перед которым встанет каретка, ближайший к точке.

**Параметры:**
- `X`, `Y` (`float`): точка от левого верхнего угла раскладки.

**Возвращает:** (`std::uint32_t`) индекс от 0 до `Count()`.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "typecase/layout.h"

std::uint32_t Clicked(const typecase::Layout &Laid, float X, float Y) { return Laid.IndexAt(X, Y); }
```

### `Cover`

**Краткое описание:** Возвращает, где лежат символы отрезка.

**Параметры:**
- `From`, `To` (`std::uint32_t`): символы `[From, To)`.

**Возвращает:** (`std::vector<Area>`) по прямоугольнику на каждую строку, где они есть.

**Побочные эффекты:** Выделяет память.

**Типичное применение:** Подсветка выделения или найденного слова.

**Пример:**
```cpp
#include "typecase/layout.h"

std::size_t LinesOf(const typecase::Layout &Laid, std::uint32_t From, std::uint32_t To) { return Laid.Cover(From, To).size(); }
```

### `Next` / `Previous`

**Краткое описание:** Возвращают следующее и предыдущее место каретки.

**Параметры:**
- `Index` (`std::uint32_t`).

**Возвращает:** (`std::uint32_t`) места пропускают позиции внутри символа с диакритикой.

**Побочные эффекты:** Нет.

**Типичное применение:** Стрелки влево и вправо в поле ввода.

**Пример:**
```cpp
#include "typecase/layout.h"

std::uint32_t Right(const typecase::Layout &Laid, std::uint32_t At) { return Laid.Next(At); }
```

### `Copy`

**Краткое описание:** Возвращает символы отрезка в UTF-8 для копирования.

**Параметры:**
- `From`, `To` (`std::uint32_t`).

**Возвращает:** (`std::string`); у секретного текста — пустая строка.

**Побочные эффекты:** Выделяет память.

**Пример:**
```cpp
#include "typecase/layout.h"

std::string All(const typecase::Layout &Laid) { return Laid.Copy(0, Laid.Count()); }
```

## Функции

### `MissingCell` / `MissingAdvance`

**Краткое описание:** Возвращают ячейку, в которой символ без шрифта рисуется своим кодом, и его продвижение.

**Параметры:**
- `Character` (`char32_t`).
- `Em` (`float`): кегль.

**Возвращает:** `MissingCell` — (`Size`) высотой в em, базовая линия на 4/5 вниз, ширина по числу цифр кода; `MissingAdvance` — (`float`) ширина ячейки плюс десятая em.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "typecase/layout.h"

float Room(char32_t Character) { return typecase::MissingAdvance(Character, 16); }
```
