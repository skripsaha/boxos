# typecase::geometry_source

## Назначение

Заголовок: [`typecase/geometry_source.h`](../../../src/userspace/typecase/include/typecase/geometry_source.h).
Реализация: [`src/geometry_source.cpp`](../../../src/userspace/typecase/src/geometry_source.cpp),
линии рамок — `box_lines.cpp`, клинья — `wedges.cpp`.

Символы, вычисленные по ячейке, а не взятые из шрифта: линии рамок
(U+2500–U+257F), блоки и штриховки (U+2580–U+259F), мозаики квадрантов,
секстантов и октантов (`boxos_mosaic.h`), клинья из «Symbols for Legacy
Computing» (U+1FB3C–U+1FB6F) и точки Брайля (U+2800–U+28FF). Шрифт рисует их
по своему em, и линия следующей ячейки встречает эту там, где решил em;
нарисованная по ячейке линия выходит из каждой ячейки в одних и тех же
пикселях, поэтому рамки замыкаются, а блоки складываются плиткой при любой
форме ячейки.

Тонкая линия — десятая часть ширины ячейки, не меньше пикселя; толстая —
вдвое толще; двойная — две тонкие через тонкую. Край подъячейки — ближайший
пиксель к её доле ячейки, один для всех символов, поэтому мозаика и её
дополнение заполняют ячейку точно. Штриховки — узоры из четверти, половины
и трёх четвертей пикселей.

## Класс GeometrySource

### `Has` / `Draw`

**Краткое описание:** Сообщают, вычисляется ли символ по ячейке, и рисуют его.

**Параметры:**
- `Character` (`char32_t`), `At` (`const Size &`).

**Возвращает:** `Has` — `bool`; `Draw` — `std::optional<GlyphImage>` размером с ячейку.

**Побочные эффекты:** `Draw` использует собственный растеризатор (кривые, наклоны, точки сглажены).

**Пример:**
```cpp
#include "typecase/geometry_source.h"

bool Frame(char32_t Character) { return typecase::GeometrySource().Has(Character); }
```
