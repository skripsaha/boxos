# typecase::glyph_look

## Назначение

Заголовок: [`typecase/glyph_look.h`](../../../src/userspace/typecase/include/typecase/glyph_look.h).
Реализация: [`src/glyph_look.cpp`](../../../src/userspace/typecase/src/glyph_look.cpp).

Как глиф шрифта рисуется для текста: в каком кегле, с пером на какой
четверти пикселя, сделанный полужирным или наклонным, если в семействе нет
такого начертания, — и само рисование: картинка или контур, из которого
она покрывается.

Глифы не хинтуются: контур ложится на пиксели там, где его поставил
дизайн. Чтобы горизонтальные штрихи строчных не расплывались на два серых
ряда, кегль слегка подгоняется — высота строчных становится целым числом
пикселей над базовой линией на границе ряда, — и верх a, n, x, z получается
одним резким краем. По горизонтали масштаб и все продвижения сохраняются.

Искусственный полужирный: контур расширяется наружу со всех сторон — на
1/24 em в сумме при 9 пикселях на em и меньше, на 1/32 при 36 и больше, —
левый край и базовая линия сохраняются, продвижение становится длиннее на
столько же. Искусственный наклон: контур наклоняется на 12° вокруг базовой
линии, продвижение сохраняется.

## Типы и функции

### `GlyphLook`

**Краткое описание:** Описывает, как рисуется глиф для текста.

**Параметры:**
- `Em` (`float`): пикселей на em.
- `Phase` (`std::uint8_t`): перо на столько четвертей пикселя правее границы пикселя, 0–3.
- `Bold` (`bool`): сделать полужирным.
- `Slant` (`bool`): сделать наклонным.

**Возвращает:** Неприменимо: агрегат; `==` поэлементное.

**Побочные эффекты:** Нет.

**Пример:** См. `DrawGlyph`.

### `BoldGrowth`

**Краткое описание:** Возвращает, на сколько пикселей полужирный удлиняет продвижение при данном кегле.

**Параметры:**
- `Em` (`float`).

**Возвращает:** (`float`).

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "typecase/glyph_look.h"

float Extra() { return typecase::BoldGrowth(16); }
```

### `AdvanceOf`

**Краткое описание:** Возвращает продвижение глифа так, как его рисует вид, в пикселях.

**Параметры:**
- `Face` (`const Font &`), `Glyph` (`GlyphId`), `Look` (`const GlyphLook &`).

**Возвращает:** (`float`).

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "typecase/glyph_look.h"

float Width(const typecase::Font &Face, char32_t Character) { return typecase::AdvanceOf(Face, Face.Find(Character), {16, 0, false, false}); }
```

### `GlyphOutline`

**Краткое описание:** Возвращает контур глифа так, как его рисует вид, в пикселях относительно пера.

**Параметры:**
- `Face`, `Glyph`, `Look`: как у `AdvanceOf`.

**Возвращает:** (`Outline`) X вправо, Y вниз — ровно тот контур, из которого покрывается картинка; пустой для глифа без контура или нечитаемого.

**Побочные эффекты:** Выделяет память.

**Типичное применение:** Текст как контур (`painter::core::TextPath`).

**Пример:**
```cpp
#include "typecase/glyph_look.h"

bool Drawn(const typecase::Font &Face, char32_t Character)
{
    return !typecase::GlyphOutline(Face, Face.Find(Character), {32, 0, false, false}).Steps.empty();
}
```

### `DrawGlyph`

**Краткое описание:** Рисует глиф так, как задаёт вид.

**Параметры:**
- `Face`, `Glyph`, `Look`: как выше.
- `Limit` (`Bounds`): ни одна часть картинки не выходит за этот прямоугольник; без него — за два em вокруг пера и продвижения (повреждённый шрифт не попросит больше пикселей, чем даёт его кегль).
- `Pen` (`Rasterizer &`): растеризатор.

**Возвращает:** (`GlyphImage`).

**Побочные эффекты:** Использует память растеризатора.

**Пример:**
```cpp
#include "typecase/glyph_look.h"

typecase::GlyphImage Letter(const typecase::Font &Face, char32_t Character, typecase::Rasterizer &Pen)
{
    return typecase::DrawGlyph(Face, Face.Find(Character), typecase::GlyphLook{24, 0, false, false}, Pen);
}
```
