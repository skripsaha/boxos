# typecase::rasterizer

## Назначение

Заголовок: [`typecase/rasterizer.h`](../../../src/userspace/typecase/include/typecase/rasterizer.h).
Реализация: [`src/rasterizer.cpp`](../../../src/userspace/typecase/src/rasterizer.cpp).

Контур → картинка: для каждого пикселя — доля, покрытая чернилом,
вычисленная по краям контура как площадь, тем же покрытием, которым рисует
каждая рука BoxOS (`boxos_shape.h`): глиф покрывается так же, как кисть и
Painter покрывают фигуру. Кривые заменяются отрезками, отклоняющимися не
больше чем на 1/16 пикселя; пиксель целый там, где контуры обходят его
один раз и больше.

Точно для неперекрывающихся контуров. Где два контура пересекаются внутри
одного пикселя, этот пиксель получает сумму их долей (не больше целого) —
чуть больше чернила, чем у объединения, только там.

Растеризатор хранит рабочую память, выросшую до самого большого
нарисованного глифа; им пользуется один поток за раз.

## Типы

### `Bounds`

**Краткое описание:** Прямоугольник пикселей относительно пера, как его считает `GlyphImage`.

**Параметры:**
- `Left`, `Top` (`std::int32_t`): первый столбец и строка.
- `Right`, `Bottom` (`std::int32_t`): первый столбец и строка за ним.

**Возвращает:** Неприменимо: агрегат.

**Побочные эффекты:** Нет.

**Пример:** См. `Rasterizer::Draw`.

### `Rasterizer::Draw`

**Краткое описание:** Рисует контур в картинку покрытия.

**Параметры:**
- `Shape` (`const Outline &`): контур в единицах шрифта.
- `Scale` (`float`): пикселей на единицу по горизонтали.
- `Rise` (`float`): пикселей на единицу вверх.
- `Limit` (`Bounds`): за его пределы картинка не выходит.
- `Advance` (`float`): продвижение пера в пикселях (переносится в картинку).

**Возвращает:** (`GlyphImage`) не больше своего чернила.

**Побочные эффекты:** Может нарастить рабочую память.

**Пример:**
```cpp
#include "typecase/rasterizer.h"

typecase::GlyphImage Square(typecase::Rasterizer &Pen)
{
    typecase::Outline Box;
    Box.Steps  = {typecase::Step::Move, typecase::Step::Line, typecase::Step::Line, typecase::Step::Line};
    Box.Points = {{0, 0}, {10, 0}, {10, 10}, {0, 10}};
    return Pen.Draw(Box, 1.0f, 1.0f, typecase::Bounds{-2, -12, 12, 2}, 10.0f);
}
```
