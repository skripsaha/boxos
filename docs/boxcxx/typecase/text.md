# typecase::text

## Назначение

Заголовок: [`typecase/text.h`](../../../src/userspace/typecase/include/typecase/text.h).
Реализация: [`src/text.cpp`](../../../src/userspace/typecase/src/text.cpp).

Текст, который нужно набрать: символы, стиль, отрезки с другим стилем,
признак секрета, и рамка, в которой он раскладывается.

Каждое свойство стиля необязательно: чего не сказал отрезок — берётся из
текста, чего не сказал текст — из системы: семейство по умолчанию книги,
16 пикселей на em, насыщенность 400, прямое, без разрядки, собственная
высота строки шрифта, без линий, чернила самого текста. Символы считаются
по одному (символ — кодовая точка Unicode) от 0.

## Типы

### `Style`

**Краткое описание:** Описывает, как набран текст или отрезок; говорит только заданное.

**Параметры:** (все `std::optional`)
- `Family` (`std::string`): семейство или несколько через запятую, самое желанное первым: `"Inter, Noto Sans"`.
- `Size` (`float`): пикселей на em (ограничивается 1/64 … 8192).
- `Weight` (`std::uint16_t`): 1–1000; 400 — обычное, 700 — полужирное.
- `Italic` (`bool`).
- `LetterSpacing` (`float`): пикселей между символами.
- `LineHeight` (`float`): высота строки в долях кегля; без значения — собственная строка шрифта.
- `Underline`, `Strike` (`bool`): подчёркивание и зачёркивание.
- `Ink` (`std::uint32_t`): номер чернил рисующего; 0 — собственные чернила текста.

**Возвращает:** Неприменимо: агрегат.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "typecase/text.h"

typecase::Style Heading()
{
    typecase::Style Made;
    Made.Size   = 28;
    Made.Weight = 700;
    return Made;
}
```

### `Span`

**Краткое описание:** Описывает отрезок текста с другим стилем.

**Параметры:**
- `From`, `To` (`std::uint32_t`): символы `[From, To)`.
- `Style` (`typecase::Style`): что меняется.

**Возвращает:** Неприменимо: агрегат. Более поздний отрезок стоит над ранним там, где они пересекаются.

**Побочные эффекты:** Нет.

**Пример:** См. `Text`.

### `Text`

**Краткое описание:** Хранит текст для набора.

**Параметры:**
- `Characters` (`std::u32string`): символы.
- `Style` (`typecase::Style`): стиль всего текста.
- `Spans` (`std::vector<Span>`): отрезки.
- `Secret` (`bool`): показывать точками, никогда не копировать (пароль).

**Возвращает:** Неприменимо: агрегат.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "typecase/text.h"

typecase::Text Warning()
{
    typecase::Text Made = typecase::Text::Of("Внимание: диск заполнен");
    typecase::Span First{0, 8, {}};
    First.Style.Weight = 700;
    First.Style.Ink    = 1;   // чернила номер 1 рисующего (например, красные)
    Made.Spans.push_back(First);
    return Made;
}
```

### `Text::Of`

**Краткое описание:** Создаёт текст из строки UTF-8.

**Параметры:**
- `Utf8` (`std::string_view`).
- `Style` (`typecase::Style`): стиль, по умолчанию пустой.

**Возвращает:** (`Text`); байт, который не начинает и не продолжает символ, становится U+FFFD.

**Побочные эффекты:** Выделяет память.

**Пример:** См. `Text`.

### `TextAlign` / `TextOverflow`

**Краткое описание:** Называют выравнивание строк и судьбу текста, который не помещается.

**Параметры:**
- `TextAlign`: `Left`, `Center`, `Right`, `Justify` (по ширине; последняя строка абзаца — нет).
- `TextOverflow`: `Grow` (рамка растёт), `Clip` (не помещённое отрезается), `Ellipsis` (отрезается, и последняя показанная строка кончается многоточием).

**Возвращает:** Неприменимо: перечисления.

**Побочные эффекты:** Нет.

**Пример:** См. `TextBox`.

### `TextBox`

**Краткое описание:** Описывает рамку, в которой раскладывается текст.

**Параметры:**
- `Width` (`float`): ширина в пикселях; 0 — по самой длинной строке, без переносов.
- `Height` (`float`): высота; 0 — по строкам.
- `Align` (`TextAlign`): по умолчанию `Left`.
- `Wrap` (`bool`): переносить строки между словами, по умолчанию `true`.
- `MaxLines` (`std::uint32_t`): наибольшее число строк, 0 — любое.
- `Overflow` (`TextOverflow`): по умолчанию `Grow`.

**Возвращает:** Неприменимо: агрегат.

**Побочные эффекты:** Нет.

**Как работает:** Слово шире рамки переносится между символами. Перевод строки в тексте переносит всегда.

**Пример:**
```cpp
#include "typecase/text.h"

typecase::TextBox Title()
{
    typecase::TextBox Box;
    Box.Width    = 240;
    Box.MaxLines = 1;
    Box.Overflow = typecase::TextOverflow::Ellipsis;
    return Box;
}
```

## Функции

### `Utf8Of` / `CharactersOf`

**Краткое описание:** Переводят символы в UTF-8 и обратно.

**Параметры:**
- `Characters` (`std::u32string_view`) — для `Utf8Of`.
- `Utf8` (`std::string_view`) — для `CharactersOf`.

**Возвращает:** (`std::string`) / (`std::u32string`). Недопустимая кодовая точка (суррогат, больше U+10FFFF) пишется как U+FFFD; испорченный байт читается как U+FFFD.

**Побочные эффекты:** Выделяют память.

**Пример:**
```cpp
#include "typecase/text.h"

std::size_t Length(std::string_view Utf8) { return typecase::CharactersOf(Utf8).size(); }
```
