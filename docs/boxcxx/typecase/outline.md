# typecase::outline

## Назначение

Заголовок: [`typecase/outline.h`](../../../src/userspace/typecase/include/typecase/outline.h).

Форма глифа: замкнутые контуры из отрезков и квадратичных кривых. У
`Font::OutlineOf` — в единицах шрифта, Y вверх от базовой линии, перо в
X = 0; у `GlyphOutline` — в пикселях, Y вниз. Каждый контур начинается
шагом `Move` и замыкается к нему; чернила там, где контуры вообще обходят
точку (правило ненулевого обхода), поэтому перекрывающиеся контуры
закрашиваются один раз.

## Типы

### `Point`

**Краткое описание:** Точка контура.

**Параметры:**
- `X`, `Y` (`float`).

**Возвращает:** Неприменимо: агрегат.

**Побочные эффекты:** Нет.

**Пример:** См. `Outline`.

### `Step`

**Краткое описание:** Называет шаг контура.

**Параметры:**
- `Move`: новый контур в следующей точке.
- `Line`: отрезок к следующей точке.
- `Quad`: кривая, притянутая к следующей точке, до точки после неё.

**Возвращает:** Неприменимо: перечисление.

**Побочные эффекты:** Нет.

**Пример:** См. `Outline`.

### `Outline`

**Краткое описание:** Хранит контур глифа.

**Параметры:**
- `Steps` (`std::vector<Step>`).
- `Points` (`std::vector<Point>`): по одной на `Move` и `Line`, по две на `Quad`.

**Возвращает:** Неприменимо: агрегат.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "typecase/outline.h"

std::size_t Contours(const typecase::Outline &Of)
{
    std::size_t Count = 0;
    for (typecase::Step Each : Of.Steps) Count += Each == typecase::Step::Move;
    return Count;
}
```
