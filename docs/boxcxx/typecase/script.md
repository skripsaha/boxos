# typecase::script

## Назначение

Заголовок: [`typecase/script.h`](../../../src/userspace/typecase/include/typecase/script.h).
Реализация: [`src/script.cpp`](../../../src/userspace/typecase/src/script.cpp).

Письменность символа — настолько, насколько она нужна для набора: шрифт
может кернить латиницу, греческий и кириллицу каждый по-своему.

## Типы и функции

### `Script`

**Краткое описание:** Называет письменность.

**Параметры:**
- `Common`: то, что общее для всех письменностей — пробелы, цифры, пунктуация, символы; набирается как письменность вокруг.
- `Latin`, `Greek`, `Cyrillic`.
- `Other`: любая другая; шрифт спрашивается по умолчанию. Письменности справа налево и с меняющейся формой букв пока тоже `Other` и набираются слева направо буква за буквой.

**Возвращает:** Неприменимо: перечисление.

**Побочные эффекты:** Нет.

**Пример:** См. `ScriptOf`.

### `ScriptOf`

**Краткое описание:** Возвращает письменность символа.

**Параметры:**
- `Character` (`char32_t`).

**Возвращает:** (`Script`).

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "typecase/script.h"

bool Russian(char32_t Character) { return typecase::ScriptOf(Character) == typecase::Script::Cyrillic; }
```
