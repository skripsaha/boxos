# typecase::code_box

## Назначение

Заголовок: [`typecase/code_box.h`](../../../src/userspace/typecase/include/typecase/code_box.h).
Реализация: [`src/code_box.cpp`](../../../src/userspace/typecase/src/code_box.cpp).

Картинка символа, которого нет ни у одного источника: ячейка закрашена, а
из неё вырезан код символа мелкими шестнадцатеричными цифрами — четыре для
символа основной плоскости Unicode, шесть дальше, — чтобы по экрану можно
было прочитать, какого символа не хватает. Где цифры не помещаются — пустая
рамка: тонкая линия в пикселе от краёв ячейки, чтобы соседние отсутствующие
символы не сливались в полосу; слишком маленькая для неё ячейка
закрашивается.

## Функции

### `DrawCodeBox`

**Краткое описание:** Рисует отсутствующий символ его кодом в ячейке.

**Параметры:**
- `Character` (`char32_t`), `At` (`const Size &`).

**Возвращает:** (`GlyphImage`) размером с ячейку.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "typecase/code_box.h"

typecase::GlyphImage Unknown(char32_t Character) { return typecase::DrawCodeBox(Character, typecase::Size{16, 10, 16, 12}); }
```

### `DrawEmptyBox`

**Краткое описание:** Рисует пустую рамку отсутствующего символа без кода.

**Параметры:**
- `At` (`const Size &`).

**Возвращает:** (`GlyphImage`) тонкая линия в пикселе от краёв или закрашенная ячейка, если она слишком мала.

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "typecase/code_box.h"

typecase::GlyphImage Box() { return typecase::DrawEmptyBox(typecase::Size{16, 8, 16, 12}); }
```
