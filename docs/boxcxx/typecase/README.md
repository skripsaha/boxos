# Typecase

## Назначение

Typecase — наборщик текста BoxOS: символы → глифы → картинки. Он читает
шрифты TrueType, выбирает начертание как CSS, раскладывает текст по строкам
с кернингом, переносами и выравниванием, отвечает, где стоит каретка, и
рисует глифы в покрытие пикселей. Рисует на экран Painter: Typecase только
говорит, какой глиф где и какой он формы.

Исходники: `src/userspace/typecase`, архив `libtypecase.a`. Только
стандартный C++ (boxcxx): те же исходники собираются и на хосте для
проверки `tools/typecase_stand.sh`.

Кто пользуется:

- дисплей — текст элементов `painter::gui` и ячейки консоли (наборщик ячеек — цепочка источников);
- `painter::gui::Measure` — измерение текста заранее;
- `painter::core::Canvas::FillText` и `TextPath` — текст на собственном холсте программы.

Программе на `painter::gui` Typecase напрямую обычно не нужен: текст
элемента набирает дисплей. Он нужен, когда программа рисует текст на
своём холсте или читает свои шрифты.

## Модули

Текст:

- [text](text.md) — `Text`, `Style`, `Span`, `TextBox`: что набирать и в какой рамке.
- [layout](layout.md) — `Layout`: разложенный текст, каретка, выделение, копирование.
- [fonts](fonts.md) — `Fonts`: книга шрифтов, семейства, выбор начертания, запасные шрифты.
- [font](font.md) — `Font`: один шрифт TrueType — глифы, метрики, кернинг, начертание.
- [script](script.md) — `Script`: письменность символа для кернинга.

Глифы:

- [outline](outline.md) — `Outline`: контур глифа.
- [glyph_look](glyph_look.md) — `GlyphLook`: как глиф рисуется для текста; искусственный полужирный и наклон.
- [glyph_image](glyph_image.md) — `GlyphImage`: нарисованный глиф.
- [rasterizer](rasterizer.md) — `Rasterizer`: контур → покрытие пикселей.
- [glyph_cache](glyph_cache.md) — `GlyphCache`: кэш нарисованных глифов с бюджетом.

Ячейки (экран из клеток):

- [size](size.md) — `Size`, `FitCell`: кегль и ячейка.
- [glyph_source](glyph_source.md) — `GlyphSource`: то, что рисует символы.
- [font_source](font_source.md), [geometry_source](geometry_source.md), [symbol_source](symbol_source.md), [imprint_source](imprint_source.md) — источники: шрифт, геометрия ячейки, символы BoxOS, встроенный оттиск.
- [chain](chain.md) — `Chain`: источники по очереди.
- [code_box](code_box.md) — картинка отсутствующего символа: его код в рамке.

## Как набирается текст

1. Программа описывает текст (`Text`: символы, стиль, отрезки со своим стилем) и рамку (`TextBox`: ширина, высота, выравнивание, перенос, обрезка).
2. Книга шрифтов (`Fonts`) для каждого символа находит начертание: семейства, названные стилем, затем запасные, затем семейство по умолчанию, затем любое, у которого символ есть. Символ, которого нет ни в одном шрифте, рисуется своим кодом в рамке — текст никогда не исчезает.
3. `Layout::Of` расставляет глифы: кернинг (пары GPOS для письменности, иначе таблица `kern`), разрядка, переносы строк по правилам Unicode (UAX #14) между словами, внутри слова только если оно длиннее строки, на мягком переносе — с дефисом; выравнивание влево, по центру, вправо, по ширине; обрезка по числу строк и высоте с многоточием или без, либо рост рамки.
4. Painter рисует: каждый глиф один раз в своём размере и с точностью до четверти пикселя, кэширует и закрашивает.

Единицы раскладки — пиксели (кегль — пикселей на em). `painter::gui` задаёт
текст в точках и сам переводит их в пиксели масштабом экрана.

Пока нет: лигатур, письменностей справа налево и с меняющейся формой букв
(арабская, индийские), CFF-контуров (`.otf` типа `OTTO`), хинтинга.

## Пример

Разложить абзац в рамку шириной 280 пикселей и узнать его высоту.

```cpp
#include "painter/core/system_fonts.h"
#include "typecase/layout.h"
#include "typecase/text.h"

float HeightOf(std::string_view Paragraph)
{
    const auto Fonts = painter::core::SystemFonts();
    if (!Fonts || Fonts->Empty()) return 0;
    typecase::Style Body;
    Body.Size = 16;
    typecase::TextBox Box;
    Box.Width = 280;
    Box.Align = typecase::TextAlign::Justify;
    const typecase::Layout Laid = typecase::Layout::Of(typecase::Text::Of(Paragraph, Body), Box, *Fonts);
    return Laid.Height();
}
```

## Сборка

Программа, которая использует Typecase, линкуется с `libtypecase.a` (после
`libpainter.a`, если есть, и до `libboxcxx.a`). Пример — правило `spell.elf`
в [Makefile утилит](../../../src/userspace/utils/Makefile).

## Потоки

Книгой шрифтов, растеризатором и кэшем глифов пользуется один поток за
раз. Шрифты (`Font`) после чтения не меняются и разделяются через
`std::shared_ptr<const Font>`.
