# typecase::glyph_cache

## Назначение

Заголовок: [`typecase/glyph_cache.h`](../../../src/userspace/typecase/include/typecase/glyph_cache.h).
Реализация: [`src/glyph_cache.cpp`](../../../src/userspace/typecase/src/glyph_cache.cpp).

Нарисованные глифы, хранимые до следующего запроса: экран снова и снова
показывает те же несколько сотен символов в нескольких размерах. Один кэш
хранит их все и спрашивается тремя способами: символ в ячейке (рисует
цепочка источников), глиф шрифта для текста (по его виду) и рамка символа,
которого нет ни в одном шрифте.

Хранимое укладывается в бюджет байтов, заданный владельцем; сверх него
первой уходит картинка, которую спрашивали дольше всех назад; только что
спрошенная остаётся всегда — а пока кэш удерживается (`Hold`), остаются все
спрошенные с того момента, чтобы глифы строки можно было спросить по разу
и нарисовать все. Кэшем пользуется один поток за раз.

## Класс GlyphCache

### `GlyphCache`

**Краткое описание:** Создаёт кэш с бюджетом.

**Параметры:**
- `Budget` (`std::size_t`): наибольший объём картинок в байтах.

**Возвращает:** Неприменимо: конструктор (`explicit`).

**Побочные эффекты:** Нет.

**Пример:**
```cpp
#include "typecase/glyph_cache.h"

typecase::GlyphCache Kept(1u << 20);   // мегабайт картинок
```

### `GlyphCache::Get` / `GetMissing`

**Краткое описание:** Возвращают картинку символа, нарисованного цепочкой в ячейке, глифа шрифта для текста или кода отсутствующего символа.

**Параметры:**
- `Get(Chain &From, char32_t Character, const Size &At)`.
- `Get(const Font &Face, GlyphId Glyph, const GlyphLook &Look)`.
- `GetMissing(char32_t Character, const Size &Cell)` — рамка с кодом (`DrawCodeBox`).

**Возвращает:** (`const GlyphImage &`) действительна до следующего `Get`/`Clear` — или, если спрошена во время удержания, до `Release`.

**Побочные эффекты:** Рисует при промахе, может вытеснить старые картинки.

**Как работает:** Ключ — источник (номер цепочки или `Serial()` шрифта), код, кегль, ячейка и вид.

**Пример:**
```cpp
#include "typecase/glyph_cache.h"

float LineWidth(typecase::GlyphCache &Kept, const typecase::Font &Face, std::u32string_view Line)
{
    float Width = 0;
    Kept.Hold();
    for (char32_t Each : Line) Width += Kept.Get(Face, Face.Find(Each), {16, 0, false, false}).Advance;
    Kept.Release();
    return Width;
}
```

### `Hold` / `Release` / `Clear` / `Held`

**Краткое описание:** Удерживают все картинки, спрошенные с этого момента, отпускают их, очищают кэш и возвращают занятые байты.

**Параметры:** Нет.

**Возвращает:** `Held` — (`std::size_t`) байты картинок; остальные — `void`.

**Побочные эффекты:** Во время удержания кэш может превысить бюджет; после `Release` возвращается в него.

**Пример:** См. `Get`.
