# tools/stack_usage_held.txt — what the stack guard holds, and until when.
#
# Every line is a Caveat: a defect this tree still has, measured, named, and
# given the step of the Quill plan that removes it. While the defect is there
# tools/check_stack_usage.py says "caveat held" and the kernel is linked. When
# it is gone the line is a FAILURE until it is deleted — in the same commit as
# the step that removed it, which is how this file only ever gets shorter.
#
# A function line: <source>:<function>  <bytes>  <step>  <what the frame holds>
#   bytes are GCC 15.2.0's, default build keys; the frame may not grow past
#   them, and falling to 1024 or under lifts the caveat.
# The reach line:  reach  <bytes>  <step>  <the chain>
#   the heaviest chain from a storage request to the medium; it may not grow,
#   and falling to the budget (4096) lifts the caveat.
#
