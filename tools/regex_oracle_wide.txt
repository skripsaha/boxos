# Wide cases: pattern<TAB>subject, UTF-8 in the file, wide in the process.
#
# ‼ What is deliberately NOT here: anything that asks what KIND of character a
# non-ASCII one is. [[:alpha:]] over U+4E2D compares macOS's wide ctype against
# ours, which is Ф42-a's measured and intended divergence, not a regex
# question. Those live in phase238, where boxcxx's own tables answer.
#
# What IS here is everything the engine decides by itself: literals, ranges
# (including the ones that straddle the 256 boundary where the class
# representation changes from a bitmap to a pair), the dot, quantifiers,
# alternation, back-references, negated classes and the \u escape.
